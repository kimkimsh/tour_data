# 모두의 백제 (Modu Baekje)

이동 조건을 고르면 충남 공주·부여 백제 유적의 무장애 정보를 **판정과 근거까지 함께 펼쳐** 보여주고, 남은 빈칸을 **지자체 개선 우선순위로 되돌려 주는** 무장애 헤리티지 관광 안내 웹 서비스.

2026 관광데이터 활용 공모전 (① 웹·앱 개발 부문) 출품작 · 지역특화 충청남도.

> **현재 상태: 코드 0줄. 이 리포지토리에는 아직 문서만 있다.**
> 무엇을 만들지는 [`docs/spec/`](./docs/spec/)이 전부 정해 뒀다.

### 착수 전에 알아 두면 하루를 아끼는 것 세 가지

1. **셋업 순서가 두 문서에 나뉘어 있다.** 프로젝트 생성(`create-next-app`)은 [`10_build_order.md`](./docs/spec/10_build_order.md) Day 1~2에 있고, 그 뒤 명령들은 [`02_stack.md`](./docs/spec/02_stack.md) §4에 있다. **10번을 먼저 본다.**
2. **한국관광공사 API 키는 신청 후 대기가 있다.** 자동승인이지만 실제 호출까지 시간이 걸리고, 발급 직후에도 반영 지연이 있다 — [`03_external_data.md`](./docs/spec/03_external_data.md) §1.3. **가장 먼저 신청해 두고 다른 일을 한다.**
3. **`docs/plan/02_claims_and_validation.md` §5.1에 spec 결함 목록이 있다.** 착수 전에 한 번 훑는다. 그중 몇 개는 그대로 짜면 첫날 막힌다.

## 이 서비스가 다른 지점

- **판정의 근거를 전부 공개한다** — 무장애 항목의 원문 문장·원래 필드명·확인일·축별 기여값까지 화면에 펼친다.
- **빈칸을 추론하지 않는다** — "정보 없음"이라고 쓰고, 그것이 문화재 보존상 어쩔 수 없는 것인지 아직 입력되지 않은 것인지 구분한다. **뒤쪽 목록이 그대로 지자체 개선 우선순위가 된다.**
- **못 한 것을 못 했다고 쓴다** — 현장 실측 미실시, 전문가 검수 미실시, 자체 점검(인증 아님)을 해당 화면에 고정 표시한다.
- **실행 중에 외부 API를 부르지 않는다** — 모든 데이터는 수집 스크립트가 미리 적재한다.

자세한 논거는 [`docs/plan/01_product_case.md`](./docs/plan/01_product_case.md).
