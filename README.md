# 모두의 백제 (Modu Baekje)

이동 조건을 고르면 충남 공주·부여 백제 유적의 무장애 정보를 **판정과 근거까지 함께 펼쳐** 보여주고, 남은 빈칸을 **지자체 개선 우선순위로 되돌려 주는** 무장애 헤리티지 관광 안내 웹 서비스.

2026 관광데이터 활용 공모전 (① 웹·앱 개발 부문) 출품작 · 지역특화 충청남도.

**→ https://www.modubaekje.com**

---

## 지금 상태

**돌아가고 있다.** 공공데이터포털 API 11종(한국관광공사 8 · 기상청 3)에서 매일 밤 자료를 받아 Supabase에 넣고, 화면은 그것만 읽는다.

| | |
|---|---|
| 관광지 | **13곳** — 공주 4 · 부여 9 |
| 무장애 항목 | **30개** — 공공데이터포털 원문에서 판정하는 23개 + 다른 자료로 계산하는 7개 |
| 무장애 사실 | **390행** (13곳 × 30항목) · 이 중 **165행**이 「정보 없음」이 아니다 |
| 손으로 확인해 넣은 사실 | **86건** — 전부 출처와 확인일이 붙어 있고, 같은 자리의 수집값을 덮어쓴다 |
| 이동 조건 | **5가지** — 휠체어 이용 / 오래 걷기 어려움 / 눈이 잘 안 보임 / 귀가 잘 안 들림 / 유아차 동반 |
| 사진 · 오디오 해설 | 174장 · 156편 |
| 언어 | 한국어 · 영어 |

판정 모델은 v7이다. 「방문 가능 / 주의 / 다른 곳 권장」 셋으로 답하고, 고른 조건마다 한 줄씩 따로 답한다. **왜 그 답이 나왔는지는 같은 화면에서 펼칠 수 있다** — 원문 문장, 원래 필드 이름, 확인일, 무엇이 몇 점을 깎았는지까지.

## 이 서비스가 다른 지점

- **판정의 근거를 전부 공개한다.** 무장애 항목의 원문 문장·원래 필드명·확인일·축별 기여값까지 화면에 펼친다.
- **빈칸을 추론하지 않는다.** 「정보 없음」이라고 쓰고, 그것이 문화재 보존상 어쩔 수 없는 것인지 아직 입력되지 않은 것인지 구분한다. **뒤쪽 목록이 그대로 [지자체 개선 우선순위](https://www.modubaekje.com/ko/gap-report)가 된다.**
- **못 한 것을 못 했다고 쓴다.** 현장 실측 미실시, 전문가 검수 미실시, 자체 점검(인증 아님)을 해당 화면에 고정 표시한다.
- **실행 중에 외부 API를 부르지 않는다.** 화면이 읽는 것은 Supabase의 스냅샷 6개뿐이다. 공공데이터포털이 멈춰도 화면은 어제 자료로 그대로 뜬다.

자세한 논거는 [`docs/plan/01_product_case.md`](./docs/plan/01_product_case.md).

## 매일 저절로 도는 것

수집과 git 커밋이 **다른 곳에서** 돈다.

| | 어디서 | 언제 | 무엇을 |
|---|---|---|---|
| **수집** | Vercel cron, `icn1`(서울) | 04:00~04:59 KST | 공공데이터포털·기상청 → Supabase, 캐시 무효화 |
| **스냅샷 커밋** | GitHub Actions `snapshot.yml` | 04:30 KST | Supabase → `content/generated` → `main`에 커밋 |

**나뉘어 있는 이유가 있다.** 수집이 GitHub 러너에서 돌 때 `apis.data.go.kr`가 러너의 주소에서 TCP 연결을 받아 주지 않아 하루걸러 실패했다. 같은 호출이 서울 리전에서는 27~54ms에 답한다. 함수는 git에 커밋할 수 없으므로 커밋하는 쪽만 GitHub에 남겼다 — `git diff`가 「어제와 무엇이 달라졌나」를 답해 주고, 같은 파일이 e2e 테스트의 픽스처이기도 하다. 전말은 [`docs/work_log/19_ingest_moved_to_seoul.md`](./docs/work_log/19_ingest_moved_to_seoul.md).

## 처음 돌려 보려면

```bash
pnpm install
cp .env.example .env.local     # 값 채우기 — .env.example 안의 주석이 어디서 받는지 말해 준다
pnpm dev
```

**Supabase 없이 화면만 보려면** `MODU_DATA_SOURCE=fixtures`. `content/generated/*.json`을 읽는다. 이 모드에서는 방문자 제보가 동작하지 않는다.

**두 개는 모르면 하루를 버린다.**

1. **공공데이터포털 키는 「일반 인증키(Decoding)」쪽이다.** Encoding 쪽을 넣으면 `URLSearchParams`가 다시 인코딩해서 서버가 `resultCode 30 (등록되지 않은 서비스키)`로 거절한다. 이 메시지가 「키가 잘못됐다」로 읽혀서 키를 다시 발급받으러 가게 된다 — 키는 멀쩡하고 형태만 틀린 것이다.
2. **Supabase 익명 로그인은 두 군데서 따로 켠다.** `supabase/config.toml`은 로컬 개발용이고, 실제 프로젝트는 웹 대시보드에서 한 번 더 켜야 한다.

나머지 함정과 설정 절차는 [`docs/guide/`](./docs/guide/)에 있다. **[`05_operations.md`](./docs/guide/05_operations.md)가 평소에 보는 문서다** — 환경변수가 어디에 몇 개씩 있는지, 수집이 안 돌 때 어디를 보는지.

### 명령

| | |
|---|---|
| `pnpm dev` · `pnpm build` | 개발 서버 · 프로덕션 빌드 |
| `pnpm ingest` | 수집을 손으로 한 번. `--dry-run`은 파일에만 쓰고 데이터베이스를 안 건드린다 |
| `pnpm pull:snapshots` | Supabase의 스냅샷 6개를 `content/generated`로 내려받는다 |
| `pnpm probe` | 공공데이터포털 응답을 실제로 한 번 찍어 본다 |
| `pnpm validate:content` | 손으로 넣은 사실에 출처와 확인일이 다 있는지 |
| `pnpm check:contrast` | 색 대비. `build`가 먼저 이걸 돌린다 |
| `pnpm typecheck` · `lint` · `test` · `e2e` | 검사 |

### 검사

```
typecheck · lint · validate:content · check:contrast     통과
test                                                     271
e2e (Playwright + axe-core)                              47
```

CI(`.github/workflows/ci.yml`)가 푸시마다 같은 것을 돌린다.

**axe가 보는 것은 검사항목의 30~50%뿐이다.** 그래서 NVDA로 직접 들어 봤고, 눈으로도 axe로도 볼 수 없는 결함 58건이 거기서 나왔다 — 판정이 바로 뒤 낱말과 붙어 「방문 가능휠체어 이용 기준」으로 읽히고 있었다. CSS `gap`은 그려지는 것이지 문서에 적히는 것이 아니다. [`docs/work_log/18_nvda_manual_verification.md`](./docs/work_log/18_nvda_manual_verification.md).

## 아직 못 한 것

빈칸을 감추지 않는 것이 이 서비스의 주장이므로, 여기에도 적는다.

- **부여 나성 좌표** — 지도 핀과 실제 진입로(부여 왕릉원 매표소)가 2,108m 떨어져 있다. 주소가 「능산리 산15-1」이라 지오코딩이 안 된다. 국가유산청 도면이나 OpenStreetMap의 해당 성벽 구간이 후보다.
- **음성 해설 항목** — 무엇이 보이는지 말로 설명해 주는 것. 13곳을 채울 출처가 없어서 항목으로 만들지 않았고, 대신 **「이 서비스는 아직 조사하지 않았다」고 화면에 적어 뒀다.** 오디오 가이드는 전시 해설이라 같은 것이 아니다.
- **충남 기상특보 문구** — 파서를 전남 샘플에 맞춰 놨고 충남 문장 실물을 본 적이 없다. 틀리면 `unknown`으로 떨어지지 틀린 값을 말하지는 않는다.
- **관람 동선 `unknown` 둘** — 국립부여박물관(3층 연결 수단이 에스컬레이터뿐), 구드래조각공원. 이유는 둘 다 화면에 적혀 있다.
- **건물 단위 편의시설 데이터셋** — 건물별로 승강기를 따로 세는 데이터셋이 있는데 우리 키로는 안 열린다. 따로 신청하면 열릴 수 있다.
