## 핵심 전략 요약 (1등 가능성 극대화 3원칙)

### 1. KTO 정책 KPI 직결성
KTO가 보도자료·연차사업으로 직접 미는 키워드와 정확히 겹치는 주제는 심사위원 가점이 구조적으로 붙는다. 회피 영역(자전거·차박캠핑·트레킹·짐보관·AI 일정생성기 등)은 5년 연속 수상이 누적되어 심사단 식상도 ↑.
- 직결 키워드: **무장애(열린관광)·코리아둘레길 4,500km·디지털 관광주민증·인구소멸지역 활성화·KQ 인증·우수웰니스·반려동물 동반여행 신규 API**

### 2. 신규/저활용 KTO API의 "최초·깊이 활용" 서사
TourAPI 4.4(2026-02-10) 신표준 100% 적용 명시 + underused dataset(`TarRlteTarService1` 연관관광지 그래프, `TatsCnctrRateService` 집중률 예측, `PhokoAwrdService` 수상사진, `KorWithService2.detailWithTour2` 24+ 무장애 필드, `detailIntro2` 130+ 분기 필드, `areaBasedSyncList2` 신규 콘텐츠 추적)을 결합하면 "TourAPI를 가장 잘 쓴 팀" 서사 자동 형성 → 데이터 활용 점수 20점 + 완성도 30점 동시 공략.

### 3. 단일 페르소나 × 단일 시나리오 × 4개월 완성도
슈퍼앱 흉내(NOL/마이리얼트립/Triple과 카테고리 경쟁)는 4개월 안에 무조건 패배. 2018 럭스테이(짐 보관)·2022 JOYRIDE(자전거 동호회)·2024 SPOT(Set-Jetting) 모두 페르소나가 한 줄로 떠오르는 구조로 1등권 진입.
