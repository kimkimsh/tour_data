# 01. 모두의 동선 (모동) — 무장애 × 혼잡회피 × 시니어 동행 매처

> **한 줄 정의**: 휠체어·시각장애·임산부·영유아 동반 가족·65세+ 시니어가 **동선 차원의 진짜 무장애**(엘리베이터 작동·경사로 폐쇄·화장실 점검 등 실시간 검증)와 **한산한 시간대**를 동시에 만족하는 일정을 자동으로 짜주고, 같은 날·같은 코스에 가는 동행 보호자/가이드를 매칭하는 서비스.

## 1) 서비스 기획배경 및 필요성

### 1-1. 기획 배경
- KTO는 **「열린관광지」 사업**을 중점 정책으로 운영(2025년 누적 200+개소, 2026년 신규 30개소 + 무장애 연계권역 1개 신규). KWCAG 2.2 + 모바일 접근성 KS X 3253 + 디지털포용법·장애인차별금지법(장차법) 의무 강화.
- 2026 시점 65세 이상 인구 **1,000만 명 돌파**(통계청 추계). 시니어·이동약자 시장은 구조적 성장 중.
- 그러나 KTO 「모두의 여행」·Wheelmap·Wheelmate 등 기존 서비스는 모두 **정적 인증 정보** 수준. "엘리베이터가 지금 작동하는가? 경사로가 임시 폐쇄되었는가? 다목적 화장실이 점검중인가?"라는 실시간 검증 데이터는 부재.

### 1-2. 필요성
KTO TourAPI는 `KorWithService2.detailWithTour2` 엔드포인트로 무장애 24+ 필드(`braileblock` 점자블록, `helpdog` 안내견, `signguide` 수화안내, `lactationroom` 수유실, `restroom` 다목적화장실, `wheelchair` 휠체어대여 등)를 정형으로 제공하지만 **실제 활용 서비스가 거의 없음**. 또한 `TatsCnctrRateService`(관광지 집중률 예측) + 데이터랩 `locgoRegnVisitrDDList`(시군구 일자별 방문자) 와 결합한 사례는 0. **이 두 데이터를 결합하면 "무장애 + 한산한 시간"이라는 이중 제약을 만족하는 동선 자동 생성**이 가능. 어떤 OTA·RTO·민간 서비스에도 없는 차별 영역.

## 2) 서비스 개요

### 2-1. 한 줄 소개
"휠체어로도, 유아차로도, 지팡이로도 — **막히지 않고 한산한 동선만**으로 만든 하루 코스를 1초만에 만들어드립니다."

### 2-2. 주요 기능 (5개)
1. **무장애 동선 자동 생성** — 출발지/도착지/소요시간 입력 → KorWithService2 24+ 필드 + 지하철 엘리베이터 실시간 + 도로명주소 경사도 데이터로 휠체어/시각장애/시니어/유아차 4모드 동선 산출.
2. **혼잡 회피 시간대 추천** — TatsCnctrRateService 집중률 예측 + DataLab `locgoRegnVisitrDDList` 시군구 방문자(D-4 갱신, "주간/월간" 트렌드로만 제시) 결합 → "오늘 14시 vs 16시, 어느 쪽이 한산한가" 색상 코딩.
3. **현장 실시간 검증 UGC** — 사용자가 "엘리베이터 작동중/고장", "경사로 임시폐쇄" 사진+위치 신고 → 같은 코스의 후속 사용자에게 실시간 알림. 신고 보상은 디지털 관광주민증 적립.
4. **동행 매칭** — 같은 일자·코스를 가는 휠체어 사용자와 보호자/가이드를 양방향 매칭 (Liveblocks/Yjs CRDT 기반 그룹 일정 공유).
5. **AI 보조 요약** (LLM-as-Reranker, 비가시적) — 각 코스의 "이 동선이 적합한 이유" 1줄 요약을 RAG(`pgvector` + `text-embedding-3-small` + Claude Haiku 4.5 캐시)로 생성, 출처 카드 자동 부착(공공누리 1유형/3유형 자동 분기). **AI 기본법 2026.1.22 시행 대비 "AI 생성" 배지 + 스테일 데이터 경고** 자체 구현 — 이 자체가 ② 부문이 놓치는 차별점.

### 2-3. 서비스 차별성
- 기존 「모두의 여행」·Wheelmap = **POI 단위 정적 인증 정보**. 모동 = **동선·시간대·실시간 검증 통합 매처**.
- TourAPI 무장애 정보 + 집중률 예측 + 통신 데이터 **3축 결합은 사례 0**. (분석 결과 NEW)
- 동행 매칭은 비짓서울/마이리얼트립/Triple 모두 부재.
- KWCAG 2.2 4.5:1 명도비 + 44pt 터치 타깃 + 음성 우선 모드 자체 구현 → **접근성 인증 자체가 PT 발표 임팩트**.

### 3-1. 메인 KTO OpenAPI
| 활용 API | 사용 목적 | TourAPI 4.4 신표준 적용 |
| --- | --- | --- |
| **KorWithService2.detailWithTour2** | 무장애 24+ 필드 (점자블록·안내견·수화·수유실·휠체어대여·다목적화장실 등) | ★ |
| **KorService2.areaBasedList2** | 광역/시군구 관광지 베이스 (lDongRegnCd + lDongSignguCd) | ★★ (legacy areaCode 미사용 명시) |
| **KorService2.detailIntro2** | 음식·숙박 130+ 분기 필드 (kidsfacility, refundregulation, expagerangeleports) | ★ |
| **TatsCnctrRateService.tatsCnctrRateList** | 단일 관광지 미래 방문 추이 예측 (underused) | — |
| **DataLabService.locgoRegnVisitrDDList** | KT/SKT 통신 시군구 방문자 (4일 지연, 주/월 트렌드만) | — |
| **PhokoAwrdService.phokoAwrdList** | 공모전 수상 사진 (cpyrhtDivCd Type1만 필터) | ★ |
| **Odii.themeBasedList** | 무장애 코스 음성 가이드 (선택 코스에 GPS 트리거) | — |

### 3-2. 보조 데이터
- 서울교통공사 지하철 엘리베이터 실시간 (또타지하철 데이터) / 한국공항공사 무장애 시설
- 도로명주소 개발자센터 (좌표·경사도)
- 카카오맵 SDK (2026.2.2~12.31 80% 할인 → 50원/건 → **10원/건**) — 길찾기·동선 polyline
- VWorld 무료 + 상업이용 가능 — 비용 압박 시 대체
- 기상청 KMA APIHub (LCC X/Y 격자) — 비/폭염 시 동선 회피
- 한국관광 품질인증(KQ) 4,000개소 + 우수웰니스 88개소 — 인증 우선 정렬

### 3-3. 데이터 활용 방식
1. **사전 인덱싱**: TourAPI 26만 POI + KQ 인증 + 우수웰니스 + 무장애 정보 → PostGIS + pgvector(text-embedding-3-small) → BM25 + 벡터 하이브리드 검색.
2. **실시간 결합**: 사용자 입력(시각·청각·휠체어·유아차 4모드 + 동선 시작점/종료점/체류시간) → 후보 POI 100개 → 무장애 24필드 점수화 → 집중률 예측 + 통신 데이터 시간대별 가중치 → 카카오맵 길찾기 → 4개월 플래너 출력.
3. **UGC 검증 루프**: 사용자 신고(폐쇄/고장/점검) → modifiedtime 메타로 stale-data 가드 → 24시간 내 미검증 정보는 "미검증 X분 전" 표시.

## 8) 추천 기술 스택

- **프론트**: Next.js 15 + React 19 + Tailwind + shadcn/ui + next-intl (i18n) + Zustand + RHF + zod. 모바일은 동일 코드베이스(PWA) → 4개월에 무리 없음.
- **백엔드**: Node + NestJS / Hono. Postgres 16 + PostGIS + pgvector + Redis.
- **검색**: BM25(Postgres FTS / Meilisearch Cloud $59) + 벡터(pgvector) 하이브리드 + LLM-as-Reranker(Cohere Rerank or bge-reranker-v2-m3, 비가시적).
- **지도**: 카카오맵(80% 할인기 활용) + VWorld 백업.
- **인증·결제**: 미사용(예약 기능 없음 → 여행업 등록 회피).
- **AI**: Claude Haiku 4.5 (캐시 적극 활용) + text-embedding-3-small. 자체 워터마크 + AI 표시 배지.
- **호스팅**: Vercel(프론트) + NCP/AWS(백엔드).
- **협업·실시간**: Liveblocks 또는 Yjs CRDT.
- **분석/시각화**: deck.gl(휠체어 동선 polyline) + ECharts(혼잡도 캘린더 히트맵).

## 9) 한줄 PT 핵심 메시지 (최종심사 발표 15점 대비)

> **"한국에 휠체어로 다닐 수 있는 곳은 많습니다. 그러나 휠체어로 막히지 않고 한산한 시간에 다닐 수 있는 동선을 짜주는 서비스는 없었습니다. 모두의 동선이 그것을 해결합니다."**

페르소나 1명을 무대로 부르고 (휠체어 사용자 또는 65+ 시니어), 시연 30초로 동선 자동 생성 → UGC 검증 알림 → 동행 매칭까지 흘려보내는 데모. 발표 점수 13~14점 확보 가능.
