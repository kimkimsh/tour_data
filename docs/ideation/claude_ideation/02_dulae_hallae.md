## 1) 서비스 기획배경 및 필요성

### 1-1. 기획 배경
- **코리아둘레길 4,500km** = 한반도 외곽을 잇는 4개 길(해파랑길 770km·남파랑길 1,470km·서해랑길 1,800km·DMZ평화의길 524km)이 2024.09 전 구간 개통. 문체부·KTO가 향후 5년간 핵심 홍보 자산으로 미는 메가 IP.
- KTO는 두루누비(durunubi.kr) 자체 사이트·앱과 OpenAPI(15101974)를 운영하지만 GPS 트래킹·스탬프 인증 수준에 그침. **종주 도전·실시간 안전지수·구간별 응급 거점·기상 위험 자동 회피**까지 통합한 서비스는 부재.
- 2023 KTO 공모전 우수상 "걷기여행길 안전지수"는 RTO/지자체 정책 도구 수준에서 멈춤 — 사용자 앱으로 확장된 적 없음.

### 1-2. 필요성
- 50+ 트레킹 인구는 한국 둘레길 사용자의 65%(KTO 통계). 1인 종주자 비율 30%+. 이들에게 **"오늘 코스의 일기·노약자 위험·낙뢰·열파·곰 출몰·휴게소 위치"**를 한 번에 보여주는 서비스는 시장에 없음.
- 일본 시코쿠 88곳 헨로(遍路)·스페인 까미노 데 산티아고 같은 **장거리 도보 IP**는 종주 인증 + 응급 인프라 + 다국어 가이드가 결합해야 인바운드까지 흡수. 코리아둘레길은 IP만 있고 디지털 인프라가 비어있음.
- **2024.09 4,500km 전 구간 개통** = 시의성 폭발. 2026 공모전이 코리아둘레길 디지털 동반자를 처음 선정하는 무대가 될 가능성 높음.

## 2) 서비스 개요

### 2-1. 한 줄 소개
"4,500km 코리아둘레길을 안전하게, 깊이 있게, 끝까지. **한 발자국마다 GPS가 들려주는 한국의 이야기와 매 순간의 위험 알림이 함께 걷습니다.**"

### 2-2. 주요 기능 (6개)
1. **종주 진행률 + 인증 시스템** — 4개 둘레길 × 시군 구간별 누적 km + 두루누비 스탬프 인증 + 사진 EXIF 자동 회상 (Polarsteps 패턴, 한국 미적용).
2. **실시간 안전지수** — 기상청 KMA APIHub(LCC X/Y 격자) + 119 안전지도 + 국립공원공단 탐방로 통제 + 산림청 산불·홍수 위험 + TourAPI `TatsCnctrRateService` 혼잡 → 5등급 안전 신호등.
3. **GPS 트리거 자동 오디오 가이드** — KTO Odii(`storyLocationBasedList`) + 두루누비 GPX + lclsSystm1=HS(역사관광) 필터 → 코스 위 GPS가 도달하면 자동 재생. CLOVA Voice 100+ 한국어 음성 + 영·중·일 다국어. **AI 기본법 2026.1.22 대비 첫 3초 "AI 음성" 안내** 자체 구현.
4. **응급 거점 + 휴게소·식수·화장실 매핑** — 코스별 0.5km 단위로 119 안전센터·약국·휴게소·식수대·화장실·대피소 매핑. 응급 시 1탭 119 + GPS 좌표 자동 전송 + 한국관광 1330 연결(12개 언어).
5. **2-pane 데스크톱 UX** — 좌측 지도 + 우측 일정 (Wanderlog 표준이지만 한국 부재). PC에서 사전 계획 짜는 50+/외국인에게 우월. deck.gl + react split panes.
6. **회상 사진북 + 종주 인증서** — GPS 트랙 + 사진 EXIF + 음성 메모 자동 합성 → 종주 완료 시 KTO 공식 인증서 PDF 발급 (KTO 두루누비 협력 시 가능). SNS 공유 바이럴 트리거.

### 2-3. 서비스 차별성
- 두루누비 자체 앱 = GPS 트래킹·스탬프 수준. 둘레할래? = **종주 도전 + 실시간 안전 + 위치 트리거 오디오 + 응급 인프라 + 회상**의 통합.
- Odii × 두루누비 결합 사례 **0** — TourAPI 분석 매트릭스 콤보 #8 (NEW).
- 일본 헨로·스페인 까미노 모델을 한국에 처음 적용. 인바운드 외국인 트레커 시장 직격.
- 2-pane 데스크톱 UX는 한국 OTA(모바일 우선)에 부재 — 50+/외국인 사용성 차별.

## 3) 데이터 활용 방안 (KTO OpenAPI 필수 활용)

### 3-1. 메인 KTO OpenAPI

| 활용 API | 사용 목적 | TourAPI 4.4 신표준 적용 |
| --- | --- | --- |
| **두루누비 정보 서비스 (15101974)** | 4개 둘레길 × 코스 메타 + GPX 트랙 + 스탬프 | — |
| **Odii.storyLocationBasedList** | 위치 기반 오디오 스토리 (위도경도 반경) | — |
| **Odii.themeBasedList** | 4둘레길 × 역사·자연 테마 | — |
| **KorService2.locationBasedList2** | 코스 반경 20km 내 음식·숙박·문화 | ★ |
| **KorService2.lclsSystmCode2 (lclsSystm1=HS)** | 역사관광 240 소분류 정밀 필터 | ★★ (legacy cat1/2/3 미사용 명시) |
| **TatsCnctrRateService.tatsCnctrRateList** | 코스 시작점 관광지 미래 혼잡 예측 | — |
| **PhokoAwrdService.phokoAwrdList** | 둘레길 구간 수상 사진 (감성 비주얼) | ★ |
| **areaBasedSyncList2 (oldContentid)** | 신규 등록·갱신 둘레길 코스 자동 추적 | ★ |

### 3-2. 보조 데이터
- 기상청 KMA APIHub (단기예보 + 동네예보 + 산악기상)
- 119 안전지도 + 안전디딤돌 (응급 거점)
- 국립공원공단 OpenAPI (탐방로 통제·혼잡)
- 산림청 (산불경보·산림기상)
- 한국천문연구원 (특일 일출일몰)
- 카카오맵 SDK (경로 polyline) + VWorld 백업
- KORAIL/시외버스 (구간 종주 시 교통 연계)

### 3-3. 데이터 활용 방식
1. **사전 인덱싱**: 두루누비 GPX 4,500km × 50m 단위 그리드 + Odii 스토리 좌표 + lclsSystm1=HS POI + 응급거점 → PostGIS spatial index.
2. **실시간 결합**: 사용자 GPS → 반경 500m POI/스토리 자동 호출 → 기상청 격자 좌표(LCC X/Y) 변환(`pyproj`) → 5등급 안전 신호등 산출.
3. **위치 트리거 오디오**: GeoFencing(50m 반경) → 백그라운드 재생 → CLOVA Voice TTS 캐시.
4. **종주 인증**: 사용자 GPS 누적 + 두루누비 스탬프 OAuth(가능 시) → 누적 km + 4개 길 완주 시 PDF 발급.

### 4-1. 단기 (수상 후 6개월)

### 4-3. 장기
- 한국 K-도보 IP를 일본 헨로·스페인 까미노 수준 글로벌 위상으로 — TourAPI 다국어 8종 모두 활용.
- 종주 SDK + 안전 알림 SDK를 분리해 한국 모든 둘레길/걷기길에 라이센싱.

## 8) 추천 기술 스택

- **모바일**: React Native Expo SDK 53 (백그라운드 재생 + Geofencing 둘 다 안정). 또는 Flutter.
- **프론트**: Next.js 15 + Tailwind + deck.gl(2-pane 지도) + ECharts.
- **백엔드**: Node + Hono / Postgres + PostGIS + Redis.
- **GIS**: PostGIS spatial index + pyproj (KMA LCC X/Y ↔ EPSG:4326 변환).
- **지도**: 카카오맵 + VWorld 백업 (3D 지형 시 VWorld).
- **오디오**: CLOVA Voice (한·영·중·일) + 자체 캐시 CDN(Cloudinary).
- **AI**: Claude Haiku 4.5 (RAG 보조), pgvector + bge-m3.
- **오프라인**: SQLite + GPX 캐시 + 오디오 캐시.
