## 1) 서비스 기획배경 및 필요성

### 1-1. 기획 배경
- 행안부 지정 **인구감소지역 89개 지자체** = 5차 관광진흥기본계획 + KTO 「인구감소지역 관광 콘텐츠」 카테고리 + 89개 시·군 자체 정책 운영 중. 2026 공모전 양식이 **예시 문구로 "인구 감소지역 관광정보 제공 서비스"를 직접 명시** → 평가단 호감도 구조적 ↑.
- **KTO 디지털 관광주민증**: 11개 지자체와 협력 운영(2024~). 발급 후 사용자 경험은 단순 할인쿠폰 수준. "체류 시간 늘리기 → 카드 결제 가산 → 가맹점 데이터 적립 → 다음 방문 권한 레벨업"은 백지.
- **관광두레** 12년간 누적 147지역·998 사업체. 사업체별 분산 노출 + 통합 검색 도구 부재.

### 1-2. 필요성
- 인구감소지역 활성화는 정부 핵심 어젠다 + 5차 관광진흥기본계획의 지역특화 가점 명문화. 관광 분산·체류 유도가 평가위원의 명시적 호감 키워드.
- KTO 데이터랩 시군구 통신·카드 데이터(D-4~D-11 갱신)는 B2G 도구라 시민 앱 사례 거의 없음. **`AreaTarDemDsService.areaTarSjrnDsList`(체류 강도) + `AreaTarDemDsService.areaTarExpDsList`(소비 강도)** 2축 매트릭스를 사용자에게 직접 보여주는 서비스는 0.
- 체류형 미션 게이미피케이션은 **2018 럭스테이(짐 보관 → 사업화)·2022 짐캐리(공모전 최우수→사업화)** 사례처럼 단일 페르소나·단일 시나리오로 1등 권 진입한 패턴과 정렬. "인구감소지역에서 며칠 더 머물러야 다음 레벨" → 행동 변화 유도.

## 2) 서비스 개요

### 2-1. 한 줄 소개
"여행은 머무는 만큼 깊어집니다. 89개 지자체에 머무를수록 그 지역의 **체류 온도(℃)**가 오르고, **다음 단계의 숨은 마을·맛·체험이 열립니다.**"

### 2-2. 주요 기능 (6개)
1. **89지자체 체류 온도 매트릭스** — 사용자 카드 결제(데이터랩 신한카드 가공치) + 체류 시간 → 시군구별 누적 ℃ 점수. **개인 임팩트 + 지자체별 임팩트 동시 가시화**(deck.gl ArcLayer + H3 격자 + ECharts calendar heatmap).
2. **체류 미션 시스템** — 시군구별 큐레이션 미션(관광두레 998 사업체 체험 + 로컬100 + 우수웰니스 88개소 + 한국관광 100선) → 미션 클리어 시 디지털 관광주민증 등급 ↑ + 다음 방문 시 가맹점 추가 할인.
3. **체류-소비 강도 X-Y 매트릭스** — `AreaTarDemDsService` 2축으로 "오래 머물지만 적게 쓰는 지역(잠재 활성화 후보)" vs "짧고 진하게 쓰는 지역" 4분면 → 사용자에게 "당신 같은 사람이 더 머물면 좋을 곳" 추천.
4. **워케이션·한 달 살기 매처** — 89지자체 중 워케이션 시설(worcation.co.kr) 보유 + 빈집·한 달 살기 프로그램 + KQ 인증 숙박 매칭. 사용자 직무·체류일·예산 기반 매칭.
5. **데이터로 보는 임팩트 리포트 (월간)** — "당신의 체류로 인구감소 지역 결제액 N원 증가 / 사업체 N곳 방문" — KTO 데이터랩 카드 가공치 기반 월간 PDF 리포트. SNS 공유 시 바이럴 트리거 + 정책가에게도 어필.
6. **AI 추천 (LLM-as-Reranker, 비가시적)** — pgvector + Cohere Rerank로 "당신의 이전 체류 지역과 유사하면서 다양성 다른 곳" 추천. 생성 아닌 정렬 → AI 기본법 표시 의무 약함.

### 2-3. 서비스 차별성
- 디지털 관광주민증 + 관광두레 998 + 데이터랩 통신·카드 + `AreaTarDemDsService` underused **4축 결합 사례 0**.
- 기존 인구감소 관련 앱은 "지자체별 정보 제공" 수준. 89도 = **데이터로 임팩트 가시화 + 게이미피케이션 + 다음 레벨 잠금해제**의 행동 변화 OS.
- 워케이션 매처는 강원/제주 단독은 있어도 89지자체 메타 매처는 없음.
- 공모전 양식이 명시적으로 예시한 "인구 감소지역 관광정보 제공 서비스" — 양식의 예시를 그대로 만족하면서 깊이를 더한 서비스는 평가단에게 "정확히 의도 부합" 인상.

- 행안부 인구감소지역 89개 코드 + 사업체 등록부
- KTO 디지털 관광주민증 가맹점 데이터
- 관광두레 사업체 (tourdure.visitkorea.or.kr) 998개
- 한국관광 100선 + 로컬100 (mcst.go.kr/site/s_culture/local100)
- 우수웰니스 관광지 88개소 (2025 신규 11)
- 워케이션 시설 (worcation.co.kr)
- 카카오 OpenAPI (지도/로그인/내비)

### 3-3. 데이터 활용 방식
1. **사전 인덱싱**: TourAPI 89지자체 콘텐츠 + 사업체 998 + 로컬100 + 우수웰니스 + 데이터랩 시계열 → PostGIS + pgvector + ClickHouse(시계열).
2. **체류 온도 산정**: 사용자 GPS dwell time + 카드 결제(자가 입력 OR 가맹점 푸시) → 누적 ℃ 점수.
3. **다음 레벨 잠금해제**: 미션 완료 → 디지털 관광주민증 등급 갱신 → 다음 방문 시 추가 콘텐츠/할인.
4. **임팩트 리포트**: 월말 데이터랩 카드 가공치 + 사용자 행동 → 월간 PDF.

## 8) 추천 기술 스택

- **프론트**: Next.js 15 + Tailwind + shadcn/ui + deck.gl(매트릭스 시각화) + ECharts(임팩트 캘린더 히트맵).
- **모바일**: PWA 또는 RN Expo SDK 53.
- **백엔드**: Node + NestJS + Postgres + PostGIS + ClickHouse(시계열) + Redis.
- **AI**: pgvector + bge-m3 + Cohere Rerank (LLM-as-Reranker, 비가시적). Claude Haiku 4.5는 임팩트 리포트 자연어 요약만.
- **지도**: 카카오맵 + VWorld 백업.
- **인증**: KTO 디지털 관광주민증 OAuth + 카카오 로그인.
- **분석**: Plausible/Umami(자체호스팅, 개인정보 처리방침 가벼움).

## 9) 한줄 PT 핵심 메시지

> **"인구감소지역 89곳. 정책가들이 가장 걱정하는 숫자입니다. 한 사람이 한 번 더 머무르면 그 지역의 체류 온도가 0.1도 오릅니다. 89도가 그 ℃를 보여주고, 다음 방문이 더 깊어지게 만듭니다."**

발표 시연: 워케이셔너 한 명이 강원 양양에 5박 → 체류 온도 12.3℃ 상승 → 디지털 관광주민증 골드 → 다음 방문 시 양양 어부 마을 한정 미션 잠금해제 → 한 달 후 임팩트 리포트 PDF (양양 결제액 +37,000원, 사업체 4곳 방문). 발표 점수 13~14점 가능.
