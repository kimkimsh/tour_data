## 1) 서비스 기획배경 및 필요성

### 1-1. 기획 배경
- **백제역사유적지구** = 2015년 등재 유네스코 세계유산. 공주(공산성·송산리고분군) + 부여(관북리·부소산성·정림사지·능산리고분군·나성) + 익산(왕궁리·미륵사지) + 논산(돈암서원) 4도시 8개 유적군.
- **충남관광공사(CACF)는 2026 신규 RTO 특별상 추가 지역** (분석 결과 — 2025년 7개 → 2026년 8개로 확장, 대전·충남 신규). 신규 RTO이라 **경쟁이 적을 가능성 높음** + IJTO/BTO처럼 자체 강력 서비스 부재 → 차별화 여지 큼.
- **공주는 2024 야간관광 특화도시** 신규 선정. 공주·부여·논산은 **인구감소 89지자체에 포함** (공주·부여 모두 인구감소 관할). 충남 다도라(SaaS 스마트관광 전자지도) + 올담 데이터포털 활용 가능.

### 1-2. 필요성
- 백제역사유적지구 4도시는 행정 경계(충남·전북)로 인해 **통합된 디지털 도슨트 부재**. KTO 「대한민국 구석구석」·각 시군 사이트가 분산. 외국인이 4도시를 이어 다니는 디지털 가이드는 0.
- 자녀 동반 가족 (초등 3~6학년 한국사 학습 중) 시장 = 명확한 페르소나. 백제는 한국사 교육과정 핵심 — 부모가 "체험학습"으로 데려가는 행위 + 자녀에게 음성 도슨트로 학습 지원은 직관적 가치.
- 외국인 영·중·일 단기 인바운드 (서울 → 부여 → 공주 → 다시 서울 1박 2일 패키지) 시장 — Klook/KKday에 패키지 있어도 디지털 도슨트 부재.
- **유네스코 + 야간관광 + 인구감소 + 신규 RTO 사중 적층** = 한 컨셉으로 가점·정책·시의성 모두 충족 (가성비 최고, 분석 결과 D-3).

## 2) 서비스 개요

### 2-1. 한 줄 소개
"백제는 한 줄로 묶이지 않았습니다. **공주에서 부여, 익산, 논산까지 — GPS가 들려주는 이야기를 따라 자녀와 외국인 친구와 함께 천 년 전 왕국을 걸어보세요.**"

### 2-2. 주요 기능 (6개)
1. **4도시 통합 코스 빌더** — 공주·부여·익산·논산 8개 유적군 + 한국관광 100선(부여 부소산성 등) + 로컬100 → 1박 2일 / 2박 3일 자동 코스. 차량/대중교통/도보 모드별 KORAIL/시외버스 연계.
2. **GPS 트리거 다국어 음성 도슨트** — KTO Odii(`storyLocationBasedList`) + lclsSystm1=HS(역사관광) 240 소분류 + CLOVA Voice 한·영·중·일 4개 언어. 어린이용 쉬운 말 모드 + 어른용 전문 모드. **AI 기본법 첫 3초 "AI 음성 안내"** 자체 구현.
3. **공주 야간관광 코스** (2024 야간관광 특화도시) — 공산성 야간 조명 + 금강 야경 + 야시장. 시간대별 안전·교통·식음 매핑. 가족 + 커플 분리 모드.
4. **자녀 학습 모드** — 백제 왕계도 + 유물 사진(PhokoAwrd 수상 사진 cpyrhtDivCd Type1만) + 퀴즈 카드. 방문 인증 시 디지털 스탬프 + 학교 제출용 체험학습 PDF 자동 생성.
5. **외국인 인바운드 모드** — 영·중·일 음성 가이드 + KQ 인증 숙박 + 한국관광 1330 12개 언어 콜 연결 + K-ETA 안내 링크 + 환율/택스리펀드 안내.
6. **인구감소 임팩트 가시화** — 사용자 체류·결제(자가 입력) → 데이터랩 시군구 카드 가공치 + 충남 올담 데이터 결합 → 월간 임팩트 리포트 ("당신 방문으로 부여 결제 +N원"). 89도(度)와 부분 호환.

### 2-3. 서비스 차별성
- 4도시 통합 디지털 도슨트는 시장에 없음. 각 시군이 단편적 음성 가이드만 운영.
- TourAPI 신분류체계 lclsSystm1=HS(역사관광) 240 소분류 + Odii × 다국어 8종 결합 사례 0.
- 공주 야간관광(2024 신규)을 모바일 가이드와 결합한 사례 0.
- 자녀 학습 모드 + 체험학습 PDF 자동 생성은 가족 페르소나 직격 + 학부모에게 즉시 가치.
- **사중 적층 (유네스코 + 야간관광 + 인구감소 + 신규 RTO)** — 가점 +2 + RTO 특별상 + 정책 부합 + 시의성을 한 컨셉으로 동시 충족.

### 3-2. 보조 데이터 (충남 특화)
- **충남관광공사(CACF) 다도라 SaaS** — 충남 전자지도/스마트관광
- **올담 데이터포털** — 충남 시군별 맞춤 데이터
- **공주시 야간관광 OpenAPI** (있는 범위)
- KORAIL/시외버스 (서울 ↔ 천안 ↔ 공주·부여)
- 한국관광 1330 (12개 언어)
- 카카오맵 + VWorld 3D (백제 유적 3D)
- 기상청 KMA APIHub
- 한국관광 품질인증(KQ)

### 3-3. 데이터 활용 방식
1. **사전 인덱싱**: KTO TourAPI 4도시 + Odii 스토리 + 한국관광100선 + lclsSystm1=HS → PostGIS spatial index.
2. **GPS 트리거**: 50m geofence + 4개 언어 TTS 캐시.
3. **자녀 학습 모드**: 유물 사진(Type1 만) + 백제 왕계도 LOD + 퀴즈 카드 (정형 콘텐츠).
4. **체험학습 PDF**: 사용자 GPS 동선 + 사진 EXIF + 음성 메모 → 자동 합성. 학교 양식 호환.

## 8) 추천 기술 스택

발표 시연: 어머니와 초5 자녀가 부여 부소산성 도착 → GPS 트리거 어린이 모드 음성 + 백제 왕계도 카드 → 자녀가 퀴즈 정답 → 디지털 스탬프 → 다음 코스 정림사지 도보 800m → 야간 공주 공산성 코스 자동 합성 → 다음 날 체험학습 PDF 학교 양식으로 다운로드. 외국어 토글로 영문 시연. 발표 점수 13~14점 가능.

## 10) 사중 적층 효과 (이 주제만의 가성비 최대 후크)

이 주제는 단일 컨셉으로 다음 4개 가산을 동시 충족:

| 적층 | 충족 근거 | 점수 임팩트 |
| --- | --- | --- |
| **유네스코 세계유산** | 백제역사유적지구 (2015 등재) | 기획력 +1, 발전성 +1 |
| **야간관광 특화도시 (공주, 2024)** | KTO 정책사업 직결 | 기획력 +1, 시의성 +2 (PT) |
| **인구감소 89지자체** | 공주·부여 모두 인구감소 관할 | 시의성 +2 (PT) + 정책 호감 |
| **신규 RTO 특별상 (CACF, 2026)** | 충남 신규 RTO + 사업 협력 가능 | RTO 특별상 1순위 |
