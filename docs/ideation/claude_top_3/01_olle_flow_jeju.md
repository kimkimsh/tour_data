## 1) 서비스 기획배경 및 필요성

### 1.1 서비스 기획 배경

**제주는 한국 오버투어리즘 1번 무대다.** 2024년 제주 방문객 1,500만+ 중 70%가 동(東) 1번 도로(애월·함덕·우도) 4시 ~ 4시 시간대에 집중되며, 협재·올레 7코스·우도 같은 핫스팟은 주말 평균 혼잡도 80%를 넘는다. 동시에 제주 동부 산간(다랑쉬오름·송당리·김녕)·서쪽 비양도·중산간 마을은 사용자 발길이 거의 닿지 않아 **지역 소비·체류 양극화**가 심각하다.

기존 OTA(NOL·마이리얼트립·트립닷컴)는 "어디로 갈까"만 알려주고, VISIT JEJU 공식 앱은 정적 리스트 중심이며, 탐나오·제주올레재단은 코스만 제공한다. **"같은 취향이지만 덜 붐비는 대체지를 왜 그곳인지 설명하며 추천하는 OS"는 존재하지 않는다.**

제주관광공사(JTO)가 2024년부터 추진하는 **"분산 관광·체류형 관광·9미 9품 웰니스" 정책**은 이런 OS가 있어야만 데이터 기반 의사결정이 가능하다.

### 1.2 서비스 필요성

1. **정책 직결**: JTO 분산 정책 + 우수 웰니스 88개소(2025 신규) + 제주 데이터허브(REST+SPARQL) 활용 OS는 한국 0 사례
2. **데이터 인프라 1위**: 8개 RTO 중 제주만 자체 SPARQL endpoint 보유 — 한국 LOD 시맨틱 관광 첫 적용 명분
3. **시의성 직격**: 2026년 트렌드 5축 중 ① AI 에이전트·RAG ② 인구감소(제주 일부 시군 포함) ③ 오버투어리즘 분산 ④ 시멘틱 검색 모두 만족
4. **사용자 페르소나 명확**: 제주 4박+ 웰니스·취향 깊이 여행자 (1주 체류 워케이션·요가·미식·올레길 종주)

## 2) 서비스 개요

### 2.1 기획 서비스 소개 (한 줄)

> **"왜 그곳인가"를 5요소 점수 산식으로 화면에 노출하는 제주 분산·체류 큐레이션 OS — 같은 취향 대체관광지·9미 9품 웰니스 LOD 트리·체류 온도 게이미피케이션 결합**

### 2.2 주요 기능 (6개 핵심)

#### F1. 혼잡 예측 지도 + 신호등 마커
- TatsCnctrRateService(향후 30일 집중률 예측) + DataLabService(D-4 시군구 일일 방문자) + 제주 자체 유동인구 결합
- 4단계 신호등 색상: 🟢쾌적 / 🟡보통 / 🟠혼잡 / 🔴포화
- 시간대 슬라이더 — 6시 / 12시 / 18시 / 21시 4단계로 색상 갱신
- "지금" 표시는 실시간이 아니라 **예상 쾌적도** (DataLab D-4 지연 명시)

#### F2. 같은 취향 대체관광지 추천 — 5요소 점수 산식
사용자가 협재해변을 선택하면 **점수 산식이 화면에 그대로 보인다**:

```
대체지 점수 = 0.30 × 테마유사성  (lclsSystm2 분류 + 임베딩 유사도)
            + 0.25 × 혼잡완화도   (TatsCnctrRate 차이)
            + 0.20 × 이동가능성   (Kakao Maps 자동차/대중교통 거리)
            + 0.15 × 날씨적합성   (기상청 API 강수·강풍·기온)
            + 0.10 × 지역상생기여 (AreaTarDemDs 체류·소비 강도 미달 시 가산)
```

**산식이 화면에 노출** → 데이터 활용 적절성 20점 만점 직격. PT에서도 시연 가능.

#### F3. 9미·9품·웰니스 LOD 트리 큐레이션
- 사용자가 분류 트리에서 조건 조합: "9미(자리물회 + 빙떡) + 웰니스(요가·명상)"
- **lasso 폴리곤 UI**로 동쪽 해안 30km 같은 비정형 영역 정의 → 결과 자동 갱신
- 백엔드는 SPARQL 직호출 대신 **PostgreSQL JSONB + pgvector로 모사** (학습곡선 회피, 6월부터 SPARQL 옵션 토글)
- 우수웰니스 88개소(2025 신규 제주 비중) + KQ 인증 숙박 + 9품 마을 식당

#### F4. 체류 온도 게이미피케이션 + 디지털 관광주민증
- 사용자 GPS dwell time + 카드 결제(OAuth 또는 OCR) → 시군구 누적 ℃
- 다음 방문 시 **추가 콘텐츠 잠금해제** (동굴 카페·로컬 워크샵 초대권)
- 디지털 관광주민증 11개 운영 지자체 협력 추진 (제주 포함 시 즉시 연동)
- KTO 협력 무산 시 자체 등급 시스템 fallback

#### F5. 월간 임팩트 리포트
- "당신의 5월 체류로 제주 동쪽 시군 결제 +N원, 사업체 N곳 도움" PDF
- SNS 공유 트리거 (인스타그램 카드 자동 생성)
- 사용자 동기 부여 + 발전성 점수 직결 (개인 임팩트 → RTO 임팩트 연결)

#### F6. RTO 대시보드 (B2G)
- 분산 추천 횟수 / 대체지 클릭률 / 권역별 분산 기여 / 예상 소비 유도
- IJTO 직접 사용 가능 — 정책 효과 측정 → 발전성 만점 노림

### 2.3 서비스 차별성 (한 문단)

**기존 혼잡 회피 앱(G2 탐라유랑·Flow Jeju 단독안)은 "어디로 갈지"만 알려준다. 올레 플로우는 "왜 그곳인가"를 5요소 점수 산식으로 화면에 직접 노출하여 데이터 활용 적절성 20점을 산식 자체로 증명한다.** 동시에 체류 온도 게이미피케이션으로 사용자가 분산 행동을 반복하게 만들고, 9미·9품·웰니스 LOD 트리로 제주 4박+ 깊이 여행자 페르소나를 직격한다. VISIT JEJU·IJTO 데이터허브와 KTO TourAPI 12+개 endpoint를 한 점수 체계로 묶어 RTO 대시보드까지 연결하는 구조는 **한국 관광 앱 0 사례**. 카테고리 위치는 OTA(NOL/마이리얼트립)·VISIT JEJU 공식·탐나오·제주올레재단 어디와도 겹치지 않는 **"관광 흐름 분산 OS" 단독**.

### 2.4 지역 특화 (제주)

- **제주관광공사(JTO)** 분산 정책·우수 웰니스·디지털관광주민증 협력 추진 ← RTO 특별상 1순위
- **VISIT JEJU REST API + SPARQL endpoint + data.ijto.or.kr** (이통/카드/내비 3종) — 8개 RTO 중 유일한 자체 SPARQL 인프라
- **제주 9미 / 9품 / 9경** 분류체계는 제주에서만 의미 있는 LOD 시맨틱
- **IJTO 직접 협력 관계** — 베타 사용자 모집 + 데이터 검수 + 정책 환류 가능

> 단일지역 한정 + RTO 가점 +2 + IJTO 특별상 후보 1순위.

### 3.2 데이터 활용 방식

**3-Tier 캐시 아키텍처**:

```
[KTO API] ─일배치 ETL→ [PostgreSQL 16 + JSONB + pgvector]
                              ↓
[제주 자체 API] ─실시간→ [Redis 5분 캐시]
                              ↓
[Frontend] ←GraphQL/REST── [NestJS API Gateway]
```

- **점수 산식 계산은 PostgreSQL stored procedure**로 일배치 → 사용자 요청 시 Redis에서 즉시 응답 (200ms 이내)
- **임베딩**: text-embedding-3-large로 26만건 콘텐츠 + 9미·9품·웰니스 분류 → pgvector ANN 인덱스
- **혼잡도 fallback**: DataLab 11일 지연으로 인해 "예상 쾌적도" 표기 의무 (UI에 명시)
- **카드 결제 OAuth 거절 시**: 영수증 OCR fallback (Tesseract + GPT-4o-mini)
- **KOGL Type 1 출처 표시**: 모든 카드/PDF/SNS 공유에 "한국관광공사 / KOGL Type 1 / [URL]" 자동 삽입

### 3.3 데이터 활용 적절성 점수 자기평가 (20점 만점)

- **저활용 API 콤보**: AreaTar 3종(체류·다양성·자원수요) + TatsCnctrRate + 우수웰니스 = 한국 앱 0 → +5점
- **점수 산식 화면 노출**: 5요소 가중치를 사용자가 직접 보고 조절 가능 → +4점
- **SPARQL/LOD 시도**: PostgreSQL 모사 + 6월부터 SPARQL 토글 → +3점
- **다중 데이터 결합**: KTO 12+개 + 제주 자체 3종 + 기상청 + Kakao = 16+개 결합 → +5점
- **라이선스 준수**: KOGL Type 1 출처 표시 + Type 2 이미지 사전 분리 → +3점

**합계 20/20 추정**.
