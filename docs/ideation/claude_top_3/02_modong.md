## 1) 서비스 기획배경 및 필요성

### 1.1 서비스 기획 배경

**한국 무장애 관광 인프라는 "POI 단위 정적 인증"에 머무른다.** KTO 「모두의 여행」·Wheelmap·Wheelmate 모두 "이 관광지에 휠체어 진입 가능 O/X" 수준에서 멈춘다. 그런데 휠체어 사용자·시각장애인·유아차 동반 가족·시니어가 실제로 필요한 것은 "이 관광지가 접근 가능한가"가 아니라:

1. **여러 관광지를 잇는 동선이 모두 무장애인가** (한 곳만 접근 가능해서 의미 없음)
2. **이 시간대에 가도 혼잡하지 않아 휠체어 회전이 가능한가**
3. **현장에 가보니 엘리베이터가 고장났다면 다음 사용자도 알 수 있어야 한다**
4. **혼자 가기 어려운데 같은 일자·코스 가는 사람과 동행할 수 있는가**
5. **자녀 휠체어 + 부모 + 동반자 3명을 함께 고려하는 보호자 모드가 있는가**

**이 5개를 한 번에 푸는 앱은 한국에 없다.** 동시에 세 가지 정책 흐름이 같은 방향을 가리킨다:

- **고령화 사회**: 65세 이상 인구 1,000만+ (2025), 시니어 관광 시장 +20%/yr
- **AI 기본법(2026.1.22 시행)**: 고위험 AI 표시·접근성 의무 강화
- **KWCAG 2.2 (Korean Web Content Accessibility Guidelines)**: 4원칙·14가이드라인·33체크포인트 — 공공·민간 모두 권고 → 의무화 추세

### 1.2 서비스 필요성

1. **정책 직격**: KWCAG 2.2 + AI 기본법 + 고령화 3축이 만나는 단일 OS는 한국 0
2. **시장 공백**: 가족(휠체어 자녀+부모)·학교 체험학습 담당자·복지기관 가이드 등 **상업 OTA가 과소 대응**하는 페르소나
3. **기술 차별**: KorWithService2 24+ 무장애 필드 + TatsCnctrRate(혼잡 예측) + DataLab 결합 사례 **한국 0**
4. **사회적 가치 PT 임팩트**: 발표 점수 15점 직격 — "착한 기술" 서사로 심사관 신뢰도 직결

## 2) 서비스 개요

### 2.1 기획 서비스 소개 (한 줄)

> **휠체어·시각·청각·유아차·시니어 5모드 동선 자동 생성 + 혼잡 회피 + 실시간 검증 UGC + 동행 매칭 + 보호자/교사 모드를 결합한 무장애 관광 OS**

### 2.2 주요 기능 (7개 핵심)

#### F1. 무장애 동선 자동 생성 (5모드)
- **5개 모드**: 휠체어 / 시각장애 / 청각장애 / 유아차 / 시니어
- **결합 데이터**: KorWithService2 detailWithTour2 24+ 필드 + 도로명주소 경사도 + 지하철 엘리베이터 실시간(서울교통공사) + 한국공항공사 무장애
- **동선 검증**: 시작점 → 관광지 1 → 식당 → 관광지 2 → 숙박 모든 경로의 5모드별 통과 가능성 확인
- **fallback 추천**: 한 곳이 막히면 같은 테마·인접한 무장애 대체지 자동 제안 (TarRlteTarService1 활용)

#### F2. 혼잡 회피 시간대 추천
- TatsCnctrRate(향후 30일 집중률) + DataLabService(시군구 일일 방문자) 결합 색상 코딩
- 휠체어 회전 가능 시간대 표시 — 평일 오전 10~12시·평일 오후 3~5시 우선
- "이 시간대는 휠체어 1대 회전 가능" / "이 시간대는 유아차 통행 어려움" 명시

#### F3. 현장 실시간 검증 UGC (Waze 패턴)
- **G5 다도라에서 흡수**: 엘리베이터 고장·경사로 폐쇄·점자 블록 손상 사진 + 위치 신고
- 같은 코스 후속 사용자에게 푸시 알림 ("앞 사용자 보고: 엘리베이터 1번 고장")
- 신고 자동 검증 — 같은 위치 24시간 내 3건 이상 신고 시 코스 자동 재계산
- RTO·지자체에 일일 리포트 (B2G 가치)

#### F4. 동행 매칭 (Liveblocks/Yjs CRDT)
- 같은 일자·코스를 가는 휠체어 사용자와 보호자/가이드 양방향 매칭
- 매칭 풀 부족 위험 → **베타 100명 KTO 「모두의 여행」 사용자 + 장애인 단체 협업 모집**, 매칭 실패 시 1인 모드 자동 fallback
- 채팅·일정 공유 (CRDT로 실시간 동기화)

#### F5. 보호자 / 교사 모드 (X5 흡수 핵심 차별 요소)
- **가족 모드**: 휠체어 자녀 + 부모 + 동반자 3명 이동 난이도 통합 고려
- **교사 모드**: 학교 체험학습 담당자가 학생 30명(일부 휠체어·시각장애 포함) 안전 코스 생성
- **복지기관 모드**: 단체 5~20명 노인·장애인 일정·안전 통합 관리
- 모드별 양식 PDF 자동 생성 (학교 체험학습 보고서·복지기관 일정표)

#### F6. 음성 우선 UI + STT + 큰 글씨/고대비 (G5 흡수)
- KWCAG 2.2 **4.5:1 명도비** + **44pt 터치 타겟** 자체 구현 (PT 시연 임팩트)
- STT 음성 검색 ("휠체어로 갈 수 있는 경주 식당 알려줘")
- TalkBack/VoiceOver 100% 호환
- "AI 생성" 표시 의무 (AI 기본법 2026.1.22 시행 대비)

#### F7. 데이터 갭 리포트 (RTO 대시보드, B2G)
- detailWithTour2 누락 POI 자동 식별 → "이 관광지는 무장애 정보 입력 안 됨"
- 사용자 제보 + UGC 검증 결과 → RTO에 **접근성 개선 후보지 시각화** (히트맵)
- 발전성 점수 직결: B2G 가치 입증

### 2.3 서비스 차별성 (한 문단)

**KTO 「모두의 여행」·Wheelmap·Wheelmate는 모두 POI 단위 정적 인증에 그친다. 모동은 동선·시간대·실시간 검증·동행·보호자모드의 5축 통합 매처로 한 단계 위로 올라간다.** KorWithService2 + TatsCnctrRate + DataLab 3축 결합 사례는 한국 0. 동행 매칭과 보호자/교사 모드는 가족·학교·복지기관 시장(상업 OTA가 과소대응)을 직격하며, KWCAG 2.2 자체 구현 + AI 표시 배지(2026.1.22 시행 대비)는 **"착한 기술" 서사를 PT 발표 점수로 직결**시킨다. 데이터 갭 리포트는 RTO B2G 발전 경로를 즉시 보여줘 발전성 점수도 확보. 2026 트렌드 중 "사회적 가치·접근성·고령화"를 한 컨셉으로 충족.

### 2.4 지역 특화 (경북 GTC 추천 / 충남 CACF 대안)

**경북 우선 추천 사유**:
- 신라·유교 헤리티지(경주·안동) + 무장애 결합 = X5 헤리티지 그래프 코어 살림
- 경북 Metaport (메타버스 통합 플랫폼) 협력 가능성 — 무장애 콘텐츠 확장
- 경주 외국인 비중 높음 → 다국어 모드 자연 확장 명분

**충남 대안 사유**:
- DADORA SaaS (8+ 시군 채택) + 충남 알담(Alldam) 자체 플랫폼과 결합 강력
- UNESCO 백제(공주·부여) + 무장애는 강력한 사회적 명분
- G5 다도라 스페이스 컨셉 흡수 자연스러움

> 단일지역 한정 + RTO 가점 +2 + GTC 또는 CACF 특별상 후보.
> **5월 베타는 단일 RTO**, 9월 시연 영상은 전국 확장 로드맵 명시.

### 3.2 데이터 활용 방식

**5모드별 점수 산식**:

```
모드별 통과 점수 = 0.40 × 진입가능성    (휠체어: wheelchair 필드 / 시각: braileblock·audioguide)
              + 0.25 × 동선연속성    (이전·다음 POI까지 무장애 경로)
              + 0.20 × 시간대 적합도 (TatsCnctrRate 휠체어 회전 가능)
              + 0.10 × 편의시설 충족 (restroom·elevator·room)
              + 0.05 × UGC 검증     (최근 30일 사용자 신고 가중)
```

- **fallback 우선순위**: 무장애 80%+ → 유사 테마 인접지(TarRlteTarService1) → KQ 인증 숙박 + UGC 검증된 곳
- **데이터 보완**: detailWithTour2 빈약 시군 → KQ 인증 4,000개소 + UGC + 단체 협업 데이터로 보강
- **PIPA 위치동의**: "휠체어 사용자 위치 + 동행 매칭 좌표 공유" 별도 동의서 명시
- **AI 생성 표시**: 동선 자동 생성·STT 음성 검색에 "AI 생성" 배지

### 3.3 데이터 활용 적절성 점수 자기평가 (20점 만점)

- **저활용 API**: KorWithService2 detailWithTour2 + TatsCnctrRate + DataLab 3축 한국 0 → +5점

## 4) 서비스 발전 방향

### 4.1 단기 (출시 ~ 6개월)

- **베타 100명 모집** (5월) — KTO 「모두의 여행」 사용자 + 장애인 단체(한국장애인관광협회·시각장애인복지관) 협업
- **단일 RTO 출시** (경북 또는 충남) → 데이터 갭 리포트 RTO 첫 보고
- **AI 기본법 2026.1.22 시행 대비** 투명성 표시 자체 구현 → 출시 시점 즉시 준수

### 4.2 중기 (6개월 ~ 18개월)

- **전국 확장** — 5모드 동선 자동 생성 알고리즘은 단일 RTO 학습 후 전국 확대 (KorWithService2 자체가 전국 커버)
- **다국어 4종** (영문·일문·중문 간체·번체) — 외국인 무장애 시장 직격, EngService2/JpnService2/ChsService2 활용
- **B2B 단체 패키지** — 학교·복지기관·여행사 단체 일정 자동 빌더 + 양식 PDF
- **반려동물 모드** (KorPetTourService2 detailPetTour2) — 시니어 동반견 정보 추가

### 4.3 장기 (18개월~)

- **공공 조달 입찰** — KWCAG 2.2 자체 구현 + KTO 데이터 결합 = 공공 입찰 강력
- **AI 챗봇 모드** — 휠체어 사용자가 음성으로 일정 짜기 ("내일 오전 휠체어로 갈 수 있는 경주 식당과 박물관")
- **국제 인증** — WAI-ARIA 2.2 + WCAG 2.2 AAA 준수 → 해외 무장애 인증 마크

### 4.4 기대효과
