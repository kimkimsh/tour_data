## 1) 서비스 기획배경 및 필요성

### 1.1 서비스 기획 배경

**워케이션은 지난 3년간 가장 빠르게 자라는 한국 관광 카테고리다.** 2025년 강원도 데스커 양양·WorkOnTheBeach 등 워케이션 인프라가 폭발적으로 늘었고, 강원 방문의 해 캠페인 시작 후 2025년 11월 기준 **월 430만 명 추가 방문자**를 기록했다. 그런데 기존 워케이션 플랫폼(워케이션닷씨오·로컬스티치 등)은 **숙소·코워킹 리스트 중심**에 그친다. "어디 가야 와이파이가 빠르고, 퇴근 후 6시에 갈 만한 웰니스가 있고, 비수기에 강원 어느 시군에 가야 진짜 분산에 기여하는지" 데이터로 답하는 서비스는 없다.

동시에 한국 관광 정책의 4개 흐름이 강원 워케이션에서 만난다:

1. **강원 방문의 해 (2025-2026)**: GWTO 정책 사용자 확보 인센티브 강력
2. **인구감소지역 89지자체 정책**: 강원 18시군 중 다수 포함 — 생활인구 정책 직격
3. **디지털 관광주민증 11개 운영 지자체**: 강원 일부 포함, 협력 가능
4. **우수 웰니스 88개소 (2025 신규)**: 강원 비중 높음, 워케이션 + 웰니스 결합 강력

### 1.2 서비스 필요성

1. **정책 직격**: 강원 방문의 해 + 인구감소 89 + 디지털 관광주민증 + 우수웰니스 4축 모두 만족 — 한국 0
2. **시장 공백**: B2C(개인 워케이션 일정) + B2B(기업 단체 패키지) + B2G(GWTO 대시보드) 3면 통합 OS는 한국 0
3. **저활용 API 콤보**: AreaTarDemDs(체류 강도) + AreaTarDiv(다양성) + AreaTarResDem(자원수요) 3개 미활용 + 두루누비 + 우수웰니스 = 7+ API 융합 → 데이터활용 만점 노림
4. **시의성 5중 적층**: 강원 방문의 해 + 생활인구 정책 + 인구감소 + 디지털관광주민증 + 우수웰니스 = 시의성 만점

## 2) 서비스 개요

### 2.1 기획 서비스 소개 (한 줄)

> **강원 18시군 워크핏 점수 + 퇴근 후 웰니스 스케줄러 + 체류 온도 게이미피케이션 + 기업용 패키지 빌더 + GWTO 대시보드 결합 워케이션 OS**

### 2.2 주요 기능 (6개 핵심)

#### F1. 워크핏 지역 점수 (강원 18시군)
화면에 가중치를 직접 노출하는 산식:

```
워크핏 점수 = 0.20 × 와이파이 인프라  (코워킹·숙소 와이파이 100Mbps+ 비율)
           + 0.15 × 데스크 가용성    (1인용 책상·모니터·콘센트 데이터)
           + 0.15 × 코워킹 밀도     (반경 5km 내 코워킹 개수)
           + 0.10 × 교통 접근성     (서울/수도권 4시간 내)
           + 0.10 × 날씨 안전성     (폭설·강풍 빈도)
           + 0.10 × 식음 다양성     (KorService2 contentTypeId=39)
           + 0.10 × 의료 접근성     (24시간 응급실 거리)
           + 0.10 × 야간 안전       (조명·치안 데이터)
```

- 18개 시군 모두 점수 + 색상 코딩 지도
- 사용자가 가중치 조절 시 실시간 재정렬

#### F2. 퇴근 후 웰니스 스케줄러 (18시 이후)
- **G4 강원더풀에서 흡수**: 18시 이후 자동 캘린더 배치
- 온천·숲길·산책·명상·로컬식당·야간관광 (우수웰니스 88개소 활용)
- 주말은 **두루누비·캠핑·해양·축제**로 자동 확장
- 사용자 선호 (요가/온천/등산) 학습 → 다음 주 추천 개인화 (pgvector 임베딩)

#### F3. 체류 온도 게이미피케이션 + 디지털 관광주민증
- **C3 89도에서 흡수**: GPS dwell time + 결제 → 강원 18시군 누적 ℃
- 다음 방문 시 잠금해제 콘텐츠 (로컬 워크샵·할인권·시군 명예시민증)
- 디지털 관광주민증 강원 미포함 시 KTO 협력 추진 + 자체 등급 시스템 fallback
- 5℃ → "강원 입문자" / 30℃ → "강원 친구" / 60℃ → "강원 가족" 등급

#### F4. 비수기 체류 추천 (생활인구 정책 직격)
- AreaTarDemDs (체류 강도) + AreaTarDiv (다양성) + AreaTarResDem (자원 수요) 3종 융합
- "체류 강도 낮지만 자원 수요 있는 시군 우선" → 인구감소 강원 시군 우선 추천
- GWTO 정책 호감 직결, 발전성 20점 만점 노림
- 정선·태백·삼척·영월 등 비수기 시군 강조

#### F5. 기업용 워케이션 패키지 빌더 (B2B)
- 인원 (5~50명) / 예산 / 기간 (3박4일·5박6일·2주) / 회의 횟수 입력
- 자동으로 **체류안 3개 옵션** 제안 (예약/결제 미포함, 외부 링크만)
  - 옵션 A: 양양 데스커 + 코워킹 + 오션뷰 (회의 강조)
  - 옵션 B: 평창 한옥 + 자연 + 워라밸 (휴양 강조)
  - 옵션 C: 정선 + 인구감소 시군 + 로컬 (사회적 가치 강조)
- 4개월 빌드 후순위 — MVP는 일정 추천만, 외부 링크는 9월 출시

#### F6. 월간 임팩트 리포트 + GWTO RTO 대시보드
- **개인 임팩트**: "당신의 5월 체류로 강원 N시군 결제 +M원, 사업체 N곳 도움"
- **RTO 대시보드** (B2G):
  - 비수기 분산 효과 (성수기 vs. 비수기 분산률)
  - 시군별 체류일·결제 추정
  - 로컬 상권 연결률 (체인 vs. 로컬 비율)
  - 우수 웰니스 자원 노출 횟수
- GWTO 직접 사용 가능, 강원 방문의 해 정책 효과 측정 도구

### 2.3 서비스 차별성 (한 문단)

**기존 워케이션 플랫폼(워케이션닷씨오·로컬스티치 등)은 숙소·코워킹 리스트 중심에 그친다. 스테이일드는 워크핏 점수 산식을 화면에 노출해 "왜 이 시군인가"를 데이터로 증명하고, 체류 온도 게이미피케이션으로 사용자가 비수기·인구감소 강원 시군에 머물도록 행동을 유도한다.** AreaTarDemDs/Div/ResDem 3개 저활용 API + 두루누비 + 웰니스 + 데이터랩의 7+ API 융합은 한국 0 사례. **B2C(개인 일정) + B2B(기업 패키지) + B2G(RTO 대시보드) 3면 구조**로 발전성 20점 만점 노림. 2025-2026 강원 방문의 해 + 생활인구 정책 + 인구감소 89지자체(강원 다수 포함) + 디지털 관광주민증 11개 지자체 + 우수웰니스 88개소 5중 적층은 시의성 만점.

### 2.4 지역 특화 (강원 GWTO)

- **GWTO 강원관광재단** 워케이션 인프라 직접 협력 (데스커 양양 등)
- **2025-2026 강원 방문의 해 캠페인**과 직결 — 정책 측정 도구로 자리 매김
- **강원 18시군** 모두 단일 데이터 모델 — 인구감소 시군(영월·정선·태백·삼척·고성·양구·인제) 우선 추천
- **단일지역 한정 + RTO 가점 +2 + GWTO 특별상 후보**
- 89지자체 전국 메타는 중기 로드맵으로 분리 (2027년 강원 검증 후 충남·경북·전남 확장)

### 3.2 데이터 활용 방식

**3-Tier 데이터 파이프라인**:

```
[KTO API + 강원관광재단] ─일배치 ETL→ [PostgreSQL 16 + JSONB + pgvector]
                                          ↓
[기상청 + 통신 데이터]    ─실시간→     [Redis 5분 캐시]
                                          ↓
[Frontend B2C/B2B/B2G]   ←GraphQL──    [NestJS API Gateway]
```

- **워크핏 점수 일배치 계산**: 8개 가중치 → 18시군별 점수 → Redis 캐시 (200ms 응답)
- **퇴근 후 스케줄러**: 사용자 선호 임베딩 + 18시 이후 우수웰니스 ANN 검색 (pgvector)
- **체류 온도 계산**: GPS dwell + 결제 데이터 → 시군별 ℃ 누적 (Postgres trigger)
- **비수기 추천 알고리즘**: AreaTarDemDs(체류 낮음) ∩ AreaTarResDem(수요 있음) ∩ AreaTarDiv(다양성 우수) 교집합

### 3.3 데이터 활용 적절성 점수 자기평가 (20점 만점)

- **저활용 API 7+ 콤보**: AreaTar 3종 + 두루누비 + 우수웰니스 + DataLab + 의료관광 한국 0 → +5점
- **워크핏 점수 화면 노출**: 8개 가중치 사용자 조절 가능 → +4점
- **3면(B2C/B2B/B2G) 데이터 활용**: 같은 데이터를 3개 페르소나에 다른 방식 적용 → +4점
- **다중 외부 결합**: KTO + 강원관광재단 + 기상청 + 통신 빅데이터 = 4축 → +4점
- **라이선스 준수**: KOGL Type 1 출처 + 강원관광재단 협력 협약 → +3점

**합계 20/20 추정**.

## 4) 서비스 발전 방향

### 4.1 단기 (출시 ~ 6개월)

- **베타 100명 모집** (5월) — GWTO 협력 + 데스커 양양 입주 사용자 + 디지털노마드 커뮤니티
- **강원 방문의 해 캠페인 연계** — GWTO 공식 채널 노출, 정책 효과 측정 첫 리포트 제공
- **B2B MVP** — 일정 추천만 (외부 링크), 5~10인 기업 시범 케이스 3건

### 4.2 중기 (6개월 ~ 18개월)

- **89지자체 전국 확장** — 강원 검증 후 충남·경북·전남 순차 적용 (C3 89도 코어 흡수)
- **B2B 패키지 빌더 정식 출시** — 외부 OTA(아고다·NOL) 어필리에이트 + 단체 결제
- **외국인 디지털 노마드 모드** — EngService2 다국어 + 제주·부산 확장
- **반려동물 워케이션** (KorPetTourService2) — 시니어 + 반려견 동반 1주 체류

### 4.3 장기 (18개월~)

- **공공 조달**: GWTO·KTO·문체부 정책 분산 KPI 공식 측정 도구 입찰
- **기업 복지 플랫폼 연동**: 카카오워크·웨이브온·네이버웍스 등 기업 SaaS 플러그인
- **글로벌 확장**: 일본 가루이자와·후쿠오카 + 동남아 발리·치앙마이 워케이션 OS

### 4.4 기대효과
