# 문턱없는 경북 헤리티지 그래프 - 무장애·오디오·역사 동선 추천

## 한 줄 제안
경북의 신라, 유교, 산림, 로컬 문화유산을 휠체어, 유아차, 시니어, 청각·시각 보조 필요 여부에 맞춰 안전하게 방문할 수 있도록 무장애 정보와 오디오 해설, 대체 동선을 연결하는 포용 관광 서비스.

## 제출 추천도
5순위 대상 후보이지만 최종심사에서 강하게 먹힐 수 있는 사회적 가치형 주제다. 화려한 AI보다 접근성, 고령화, 가족여행, 무장애 관광이라는 실용성이 강하고, KTO의 `KorWithService2`를 가장 직접적으로 쓰는 주제라 데이터 활용 설명이 선명하다.

| 심사항목 | 대응 전략 |
| --- | --- |

| 데이터 활용 20 | 무장애 여행 상세 API를 핵심으로 하고 국문 관광정보, 오디, 관광사진, 국가유산 데이터를 결합한다. |
| 발전성 20 | 경북에서 검증 후 전국 열린관광지와 관광약자 여행 표준 서비스로 확장 가능하다. |

## 기획 배경 및 필요성
관광 약자는 여행지에 도착하기 전부터 정보 부족을 겪는다. 휠체어 접근 가능 여부, 엘리베이터, 점자블록, 도우미견, 수유실, 장애인 화장실, 주차장, 경사, 이동거리 같은 정보는 일반 지도 앱에서 흩어져 있거나 빠져 있다. 특히 경북의 유적지, 사찰, 서원, 고택, 산림 관광지는 가치가 높지만 동선 난이도를 모르면 방문을 포기하기 쉽다.

KTO 무장애 여행 정보는 관광약자별 상세 필드를 제공한다. 여기에 오디오 해설과 관광사진, 국가유산 정보를 결합하면 "갈 수 있는 문화유산 여행"을 만들 수 있다. 문턱없는 경북 헤리티지 그래프는 관광지를 많이 보여주는 앱이 아니라, 각 사람에게 실제로 가능한 역사 동선을 만든다.

## 핵심 사용자
| 사용자 | 문제 | 제공 가치 |
| --- | --- | --- |
| 휠체어 이용자 | 관광지 접근 가능 여부를 현장에 가서야 알게 됨 | 휠체어, 경사, 화장실, 주차장 기반 적합도 |
| 유아차 가족 | 수유실, 유아 의자, 긴 이동거리 정보 부족 | 영유아 가족 프로필에 맞는 코스 |
| 시니어 여행객 | 긴 보행, 계단, 휴식 부족이 부담 | 짧은 동선, 휴식 지점, 오디오 해설 |
| 청각·시각 보조 필요 관광객 | 해설, 안내, 표지 정보 접근이 어려움 | 자막, 큰 글씨, 오디오, 점자·안내 정보 표시 |
| 경북 RTO | 무장애 관광 개선 지점을 데이터로 보기 어려움 | 누락 정보와 접근성 개선 후보 대시보드 |

## 주요 기능
1. 접근성 프로필 기반 추천
   - 휠체어, 유아차, 시니어, 시각, 청각, 도우미견, 장시간 보행 어려움 등을 선택한다.
   - 관광지별로 "방문 가능", "주의 필요", "대체 추천"을 표시한다.

2. 무장애 헤리티지 동선
   - 경주 역사권, 안동 유교권, 영주 선비권, 김천·상주 열린관광지 등을 테마별로 묶는다.
   - 관광지가 좋더라도 접근성 필드가 부족하거나 위험하면 근처 대체 관광지를 제안한다.

3. 위치 기반 오디오 해설
   - Odii와 관광 스토리 데이터를 활용해 걷기 어려운 사용자가 화면을 오래 보지 않아도 정보를 들을 수 있게 한다.
   - 청각장애 사용자를 위해 요약 자막과 큰 글씨 모드를 제공한다.

4. 보호자·교사 모드
   - 가족, 복지기관, 학교 체험학습 담당자가 여러 명의 이동 난이도를 고려해 안전한 코스를 만들 수 있다.
   - 수학여행이나 현장체험학습으로 발전할 수 있어 사업화 범위가 넓다.

5. 접근성 데이터 갭 리포트
   - `detailWithTour2`에 정보가 누락된 관광지를 표시하고, 사용자 제보와 현장 확인이 필요한 항목을 정리한다.
   - RTO에는 관광약자 서비스 개선 후보지를 보여주는 대시보드로 제공한다.

## 5페이지 제안서 압축 구성
1. 1페이지: 관광약자의 정보 장벽과 경북 지역성
2. 2페이지: 접근성 프로필 기반 사용자 여정
3. 3페이지: 무장애 API 중심 데이터 활용표
4. 4페이지: 주요 기능, 차별성, 접근성 UI 원칙

## 차별성
- AR이나 메타버스 중심의 화려한 역사관광이 아니라 "실제로 갈 수 있는가"를 먼저 해결한다.
- KTO 무장애 API의 전용 상세 필드를 서비스 핵심 로직으로 사용하므로 데이터 활용성이 명확하다.
- 관광약자, 가족, 시니어는 상업 서비스가 과소 대응하는 시장이며 공공성과 실용성을 동시에 가진다.
- 경북의 신라, 유교, 선비, 산림 콘텐츠와 잘 맞아 지역특화 설명이 쉽다.

## 리스크와 대응
| 리스크 | 대응 |
| --- | --- |
| 접근성 데이터가 일부 누락될 수 있음 | 정보 없음, 확인 필요, 방문 가능을 명확히 구분하고 사용자 제보로 보완한다. |
| 경로 자체의 경사도 데이터 부족 | MVP는 관광지 단위 적합도와 짧은 동선부터 제공하고, 고도/경사 데이터는 고도화 단계로 둔다. |
| 위치정보 규제 | 수동 위치 선택과 코스 미리보기 중심으로 시작하고, 실시간 안내는 출시 전 신고 계획을 포함한다. |
| 의료적 안전 책임 | "보조 정보"임을 명확히 표시하고, 공식 데이터 기준일과 현장 확인 필요성을 고지한다. |

## 기대효과
- 관광약자와 가족의 경북 문화유산 접근성을 높인다.
- RTO는 무장애 관광 개선 우선순위를 데이터로 파악한다.
- KTO는 무장애 여행 API의 사회적 활용 우수사례를 확보한다.
- 접근성 높은 UI 자체가 최종심사의 이용 편의성과 실용성에서 강점이 된다.
