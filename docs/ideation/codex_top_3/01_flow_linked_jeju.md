## 기획 배경과 필요성
제주는 관광 수요가 충분하지만 특정 명소와 시간대에 방문객이 집중된다. 성산일출봉, 협재·함덕 해변, 인기 카페권, 동문시장 같은 지점은 주차, 대기, 주민 불편, 자연 훼손을 만들고, 반대로 인접한 로컬 명소와 상권은 충분히 연결되지 않는다.

기존 여행 앱은 "가볼 만한 곳"을 추천하지만, 현장에서 목적지가 붐비거나 날씨가 바뀌었을 때 어디로 흐름을 바꾸면 되는지 설명하지 못한다. KTO API와 제주 자체 데이터는 이미 관광지, 위치, 분류, 방문자 추세, 집중률 예측, 연관 관광지, 제주 올레·9미·9품 데이터를 제공한다. 이 서비스는 그 데이터를 단순 목록이 아니라 "지금 이 사용자를 어디로 분산시킬 것인가"라는 의사결정 엔진으로 바꾼다.

## 주요 기능
1. **예상 쾌적도 지도**
   - KTO `TatsCnctrRateService`, `DataLabService`, 제주 빅데이터를 결합해 관광지와 권역을 쾌적, 보통, 혼잡, 과밀 4단계로 표시한다.
   - 데이터랩 방문자 데이터의 D-4 지연, 카드 데이터 D-11 지연을 고려해 "실시간 혼잡도"가 아니라 "예상 쾌적도"로 표현한다.

2. **같은 취향 대체 관광지 추천**
   - 사용자가 목적지를 선택하면 `lclsSystm1~3`, 위치, 연관 관광지, 날씨 적합도, 혼잡 완화 효과를 기준으로 대체지를 제안한다.
   - 대체지는 "덜 유명한 곳"이 아니라 원래 목적과 같은 욕구를 충족하는 곳으로 정의한다.

3. **제주 시맨틱 큐레이터**
   - 고급 조건: 올레 코스 인접, 9미·9품, 웰니스, 무장애, KQ 인증 숙박, 해녀·로컬 테마를 조합한다.
   - MVP에서는 조건 필터 UI로 시작하고, 2차 고도화에서 VISIT JEJU SPARQL 쿼리 빌더를 내부 엔진으로 붙인다.

4. **일정 붕괴 방지 리플랜**
   - 비, 강풍, 혼잡, 운영시간 변경, 이동시간 초과 시 현재 위치와 남은 시간을 기준으로 2~4시간 대체 동선을 다시 만든다.
   - "무리하지 않는 코스"를 우선해 편의성과 안정성을 높인다.

5. **지역상생 동선 점수**
   - 관광지 하나가 아니라 음식점, 카페, 시장, 산책 코스까지 이어지는 동선을 제안한다.
   - 추천 카드에 쾌적도, 이동 가능성, 날씨 적합도, 지역 분산 기여도를 함께 표시해 데이터 활용 근거를 화면에 드러낸다.

6. **제주 관광 흐름 대시보드**
   - 과밀 회피 추천 수, 대체지 클릭률, 권역별 분산 기여, 예상 소비 유도, 추천 실패율을 시각화한다.
   - 최종 PT에서 "관광객 앱 + RTO 운영 도구"라는 발전성을 보여주는 핵심 화면이다.

## 제안서 5페이지 압축안
1. 제주 오버투어리즘과 현장 일정 붕괴 문제.
2. 사용자 여정: 인기 목적지 선택 → 혼잡 경고 → 대체 동선 → 리플랜.
3. KTO API와 제주 데이터 결합 구조, 점수 산식.
4. 지역특화/RTO 대시보드/기존 앱 대비 차별성.
5. MVP 일정, 법적 리스크 대응, 전국 확장 방향.

## 리스크와 완화책
| 리스크 | 영향 | 완화 |
| --- | --- | --- |
| 데이터랩·카드 데이터 지연 | 실시간 혼잡도라고 주장하면 신뢰 리스크가 생긴다. | "예상 쾌적도"로 명명하고 데이터 기준일을 명시한다. |
| SPARQL 학습곡선 | 4개월 내 구현 부담이 커질 수 있다. | MVP는 REST+내부 태그 필터로 완성하고, SPARQL은 고도화 엔진으로 단계 적용한다. |
| 대체 추천 불신 | 사용자가 유명지를 포기하지 않을 수 있다. | 추천 이유를 테마 유사도, 이동시간, 쾌적도, 주변 소비처로 설명한다. |
| 위치정보 규제 | GPS 기반 서비스는 위치정보법 이슈가 있다. | 수동 위치 입력과 1회성 위치 권한으로 시작하고, 출시 전 위치기반서비스사업자 신고를 계획한다. |
| 이미지 라이선스 | Type3 이미지 변형 시 저작권 문제가 생긴다. | `cpyrhtDivCd` 저장, Type3 크롭·필터 금지, 출처 표시를 기본 정책으로 둔다. |

## 발전 방향
- 제주에서 검증 후 부산 해변권, 강원 산악권, 경북 역사권처럼 혼잡·분산 이슈가 있는 RTO로 확장한다.
- RTO용 대시보드는 B2G SaaS로 분리해 권역별 분산 추천 성과와 관광 수요지수를 보여준다.
- 인바운드 외국인용으로 `EngService2`, `JpnService2`, `ChsService2`를 붙여 "제주 4박 이상 깊이 여행" 큐레이터로 확장한다.

## PT 핵심 메시지
> 제주에는 가볼 곳이 부족한 것이 아닙니다. 사람이 한곳으로 몰리는 것이 문제입니다. Flow Linked Jeju는 관광객의 한 번의 선택을 제주 전체의 더 나은 흐름으로 바꿉니다.
