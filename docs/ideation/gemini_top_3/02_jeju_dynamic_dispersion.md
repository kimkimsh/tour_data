# [TOP 2] 제주 플로우 & 큐레이터 (오버투어리즘 분산형 대안관광 스케줄러)

> **통합 배경**: 기존 에이전트 제안 중 '플로우 제주', '탐라유랑', '올레 링크드 제주'의 강점(흐름 분산 로직, 실시간 혼잡도 히트맵, SPARQL 시맨틱 정밀 추천)을 고도화하여 제주 특화 빅데이터 플랫폼으로 승화시켰습니다.

## 1. 서비스 한 줄 정의
제주도의 실시간 혼잡도를 분석하여 유명 관광지 대신 **취향이 일치하는 한적한 로컬 대체 명소와 주변 상권 동선**을 정밀하게 제안하는 오버투어리즘 해결형 스케줄러.

## 2. 타겟 페르소나 및 지역
- **타겟**: 붐비는 곳을 피하고 싶은 제주 렌터카/뚜벅이 여행객, 딥 다이브 로컬 체험을 원하는 2회차 이상 방문객.
- **지역**: **제주도 특화** (제주관광공사 IJTO 특별상 완벽 타겟팅).

## 3. 주요 기능 (간이기획)
1. **빅데이터 혼잡도 맵 & 리플랜 알림**: KTO 집중률 예측과 지역 통신 데이터를 렌더링해 특정 지역이 과밀 상태일 때 즉각적으로 우회 동선(리플랜) 제안.
2. **SPARQL / 신분류체계 기반 대체지 추천**: 유명 카페나 해변이 혼잡할 경우, 단순 거리순이 아닌 **LOD(Linked Open Data)** 기반 테마 유사도(예: "숲이 있는 카페", "해녀가 운영하는 식당")가 높은 롱테일 관광지 추천.
3. **분산 기여(지역상생) 마일리지**: 대안 관광지를 방문하여 인구 분산과 지역 로컬 상권 소비에 기여한 유저에게 디지털 인증 배지 및 지역 혜택(제주 탐나오 쿠폰 연동 등) 제공.
4. **시간보장형 반나절 코스**: 제주공항/제주항 도착·출발객의 남은 버퍼 시간을 계산하여 짐 부담 없이 안전하게 다녀올 수 있는 대안 루트 안내.

## 4. 공모전 전략 및 활용 데이터
- **핵심 무기**: "데이터 가치를 넘어 서비스로 실현"한다는 공모전 슬로건을 가장 명확히 관통. 제주 관광의 최대 페인포인트인 오버투어리즘을 데이터로 해결.
- **연계 데이터**:
  - `TatsCnctrRateService` (집중률 방문자 추이 예측), `AreaTarDivService` (지역별 관광다양성).
  - VISIT JEJU SPARQL / REST API 및 제주데이터허브 빅데이터.
  - `KorService2` 신분류체계 데이터.
- **기대 점수**: 데이터 활용과 기획력 측면에서 최상위 평가. 특별상 확보 1순위.
