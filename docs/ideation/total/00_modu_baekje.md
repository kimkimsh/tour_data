## 1) 서비스 기획배경 및 필요성

### 1.1 서비스 기획 배경

**한국 무장애 관광 인프라는 "POI 단위 정적 인증"에 머물러 있다.** KTO 「모두의 여행」, Wheelmap, Wheelmate는 모두 "이 관광지가 휠체어 진입 가능한가"라는 단일 POI 질문에 멈춘다. 그러나 휠체어·유아차·시각장애·외국인이 실제 백제역사유적지구를 방문할 때 마주치는 질문은 다음 5개다:

1. **여러 유적이 단차 없이 이어지는 동선이 시간 예산(반나절~2박 3일)에 맞게 있는가** — 한 곳만 접근 가능해서는 의미가 없고, 시간 단위가 1박 2일에 고정돼서도 안 된다.
2. **현장에 가보니 엘리베이터가 고장났다면 다음 사용자도 알 수 있는가** — 엘리베이터·경사로 정적 정보의 60% 이상이 6개월 이상 미갱신.
3. **자녀가 백제 역사를 이해하고 학교에 제출할 체험학습 자료를 만들 수 있는가**
4. **외국인이 다국어 GPS 오디오로 백제를 이해할 수 있는가** — 부여 부소산성·공주 공산성에 위치 트리거 다국어 도슨트 부재.
5. **충남 RTO·지자체가 "어느 시군의 무장애 정보가 부족한가"를 데이터로 볼 수 있는가** — KorWithService2 detailWithTour2 누락 POI 시각화 도구 부재.

세 가지 정책 흐름이 동시에 같은 방향을 가리킨다 — (a) **고령화** : 65세 이상 1,000만 명 돌파(2025), 시니어 관광 시장 +20%/yr, (b) **AI 기본법(2026.1.22 시행)** : 생성형 AI 결과물 표시·접근성 의무, (c) **KWCAG 2.2 + 디지털포용법 + 장차법 제20·21조** : 정보접근권은 권고에서 의무로 전환되는 추세.

### 1.2 서비스 필요성

| 축 | 시장 공백 | 본 서비스의 응답 |
|---|---|---|

## 2) 서비스 개요

### 2.1 기획 서비스 소개 (한 줄)

> **충남 공주·부여 백제역사유적지구를 장애 유형(휠체어·시각·청각·인지·시니어·유아차·만성질환)과 시간 예산(반나절~2박 3일)에 맞춰 동선·도슨트·다이어리·현장 검증을 한 화면에 묶은 무장애 헤리티지 관광 OS — 「모두의 백제 (Modu Baekje)」**

### 2.2 기획 서비스 주요 기능 (5개 핵심 — MVP)

#### F1. 무장애 토털 가이드 OS — 6 Sub-Feature 통합

> **설계 원칙** — 무장애 서비스의 가치는 "갈 수 있는 곳을 분류해주는 것"이 아니라 **"갈 때 함께 따라가는 것"**. 따라서 F1은 ① POI 무장애 상세 카드 + ② 상세 베리어프리 경로 안내 + ③ SOS·보조기기·콜택시·AAC + ④ 시간 예산 6단 + ⑤ 페르소나별 후기·GPX 환류 + ⑥ 예측 가능 백제(발달·인지) **6 sub-feature를 한 화면에 통합**한다.

##### F1 입력 — 페르소나 + 시간 예산 + 시즌 + 음성 진입점

- **P1 휠체어·시니어** : P1a 휠체어/도우미견(단차·경사·엘리베이터·회전 공간) + P1b 시니어/만성질환(피로도·낙상·휴식 간격·큰 글씨·폭염·미세먼지 회피)
- **P2 시각·청각** (UX 반대 성격) : P2a 시각(음성·점자·도우미견·고대비·STT) + P2b 청각(자막·시각 알림·수어 1차 사용자 토글)
- **P3 가족·자녀** : 유아차·수유실·어린이 학습. **하위 옵션** — 인지·발달장애·자폐·치매 초기를 "쉬운글·낮은 자극·짧은 동선·픽토그램" 옵션으로 흡수 (P5 페르소나 신설 X — 페르소나 과다 회피)
- **P4 단체 인솔자** : 학교·복지기관·발달장애 단체. 인솔자 화면·일괄 발급·단체 합본 PDF
- **외국인 4언어 횡단** (P1~P4 위에 겹침) : 영·일·중·국문, 1330·영사콜센터·응급 다국어
- **시간 예산 슬라이더** : 분 단위 입력. 6단 프리셋 (반나절·당일·1박2일·2박3일·다회차·시즌 패스)
- **시즌 토글 (MVP 부분)** : 백제문화제(9-10월)·야간관광(여름 저녁)·여름 폭염 회피
- **음성 검색 진입점** : *"휠체어로 갈 수 있는 반나절 공산성 코스 찾아줘"* — STT (Naver Clova / Whisper) → KWCAG 2.2 시연 첫 컷

##### F1.A — POI 무장애 상세 카드

각 POI 카드는 다음 모든 요소를 포함 — 사용자가 "갈까 말까"가 아니라 **"어떻게 갈까"** 를 결정 가능하게 한다.

| 카드 영역 | 내용 |
|---|---|
| **상단 라벨** | 4단계 (방문 가능 ≥75 / 주의 50~74 / 정보 없음 / 대체 추천) + **부재 사유 2분류** : (a) 본질 제약(사적지 계단 — 문화재 보존 사유) / (b) 운영자 미입력(F5 갭 리포트 우선) |
| **출입구별 사진 + 경사도** | 정문·후문·북문 각 출입구 사진 + 카카오맵·VWorld 경사도 + UGC 검증 횟수 |
| **휠체어 회전 가능 영역 지도** | 평탄 구간 폴리곤 + 단차 위치 마커 + 회전 직경 표기 |
| **점자블록 / 음성 안내 시스템 경로** | KorWithService2 `braileblock` · `audioguide` · `guidesystem` 시각화 (P2a 핵심) |
| **휴식 인프라** | 벤치 / 그늘 / 실내 휴게 / 에어컨 / 화장실 간격 (P1b 만성질환·시니어 직격) |
| **장애인 화장실** | 행안부 「장애인 화장실」 표준 데이터 + KorWithService2 `restroom` |
| **응급 인프라** | 응급의료기관 + AED — 500m / 1km cutoff |
| **페르소나×필드 매트릭스** | 5×21 (페르소나별 critical 4 / 보조 4 / 무관 13 자동 정렬) |
| **현장 사진 미리보기** | KTO PhotoGalleryService1 + UGC + Odii 어른 모드 메타데이터 |

##### F1.B — 상세한 베리어프리 경로 및 방법 안내

> 실시간 GPS 음성 내비 대신 **사전 검수된 무장애 가이드를 현장에서 단계별로 참조**하는 정적 안내. 오프라인 작동 + GPS 위치 송신 최소화.

- **POI별 동선 단계 카드** : 각 POI 진입~퇴장을 5~12개 단계로 사전 분할. 예 — *"1단계: 공산성 서문 진입 (평탄 30m, 점자블록 유) → 2단계: 우측 광장 휠체어 회전 가능 영역(직경 3m) → 3단계: 휴식 벤치 1번 (그늘) → 4단계: 만하루 진입로 (경사 6° 우회로) → ..."*
- **단계별 사진·도면 시각 안내** : KTO PhotoGalleryService1 + UGC 사진 + 단순 평면 도면 (텍스트 좌표·거리 표기) — 출발 전 한눈에 미리보기
- **5채널 정적 출력** : 지도·사진·쉬운글·픽토그램·TTS 읽기까지 모두 사전 준비
- **출입구별 접근법 분리** : 정문 계단·후문 경사로·엘리베이터 위치
- **구간별 장애요소 표기** : 경사·턱·노면·폭·횡단보도·쉼터
- **대체 경로** : 우천·혼잡·공사·휠체어 회전 곤란 시 우회안
- **페르소나별 소요·피로도** : 휠체어·시각·유아차·저자극 기준 (F1.D 5슬롯 가중 분배)
- **오프라인 다운로드** : POI 1개당 가이드 패키지(사진+텍스트+점자+GPX)를 디바이스에 영속 저장
- **검증 동선 GPX 환류** (F1.E 연동) : 검수 통과 GPX는 사용자가 카카오맵·구글맵·네이버맵에서 따라가기 가능

##### F1.C — SOS · 보조기기 · 장애인콜택시 + AAC 도움요청 카드

- **SOS 버튼** (모든 화면 우상단 고정) : 한 번 탭으로 119 + 1330 + 영사콜센터 다국어 직결 + 동반자 GPS 전송 (PIPA 명시 동의 후)
- **보조기기 대여 + 사전 예약** : KorWithService2 `wheelchair` + 한국장애인개발원 + 충남 시군 보건소·복지센터 대여 데이터
- **장애인콜택시 호출** : 한국교통안전공단 + 공주시·부여군 콜택시 — 전화 딥링크 (API 발급은 발전방향)
- **AAC 도움요청 문장카드 5종** : *"도움이 필요해요 / 아파요 / 소리가 너무 커요 / 길을 잃었어요 / 화장실이 필요해요"* — 픽토그램·쉬운글·다국어·음성 TTS 동시 출력. 청각·인지·발달·외국인·시니어 동시 충족. 한국보완대체의사소통학회 공개 AAC 셋 + KS 픽토그램 재활용. F1.F-6과 데이터 공유.

**5슬롯 분배 알고리즘** : 시간 예산 = `POI 체류 + 이동 + 휴식 + 식사 + 숙박` 5슬롯에 페르소나 가중치로 분배 (P1b 시니어 휴식 25%·P3 가족 식사 20%·외국인 도슨트 30%·P4 인솔 +15%·P3 인지·발달 옵션 휴식 30%).

**무장애 적합도 산식 — 4 Layer 구조** :

```
적합도 = ( Layer A · Layer B ) × Layer C × Layer D

Layer A — POI 본질 7축 (합 1.00)
   0.30 × 진입 가능성       (KorWithService2 detailWithTour2: wheelchair · exit · elevator)
   0.18 × 동선 연속성       (이전·다음 POI 무장애 + 카카오맵·VWorld 경사도)
   0.15 × 편의시설          (restroom · auditorium · room · lactationroom · stroller)
   0.12 × 휴식 인프라       (벤치·그늘·실내휴게·에어컨 / BF 인증 데이터)
   0.10 × 시간대 적합도     (TatsCnctrRate + 기상청 특보 + 에어코리아)
   0.08 × 사회적 안전       (응급실·AED 500m / 1km cutoff)
   0.07 × UGC 검증          (최근 30일, 신고자 신뢰도 점수 가중)

Layer B — 페르소나×필드 가중치 매트릭스 (5×21)
   페르소나별 critical 필드 4개 ×4 / 보조 ×2 / 무관 ×1
   다중 페르소나 선택 시 critical AND 통과 강제 (교집합 패널티)

Layer C — 인증·법적 보정 (multiplicative 1.00 ~ 1.30)
   BF 인증 등급 ×(1.00 / 1.05 예비 / 1.10 일반 / 1.15 우수)
   KTO 열린관광지 선정 ×1.10
   한국관광 품질인증 KQ ×1.05

Layer D — 신뢰도 감쇠 (정적 정보 갱신일 기반)
   KTO 갱신일 ≤ 90일 ×1.00 / ≤ 365일 ×0.90 / > 365일 ×0.75
   + UGC 검증 횟수 보강 + "최종 확인 YYYY-MM-DD" 화면 표시

결과: 0~100점 + 4단계 라벨
```

**fallback** : 적합도 70% 미만 → KorService2 `lclsSystmCode2` 동일 카테고리 + TarRlteTarService1 인접 대체지 자동 추천. 시간 예산 초과 시 가까운 POI로 자동 압축.

##### F1.E — 페르소나별 후기 분리 + 무장애 동선 GPX 환류

- **페르소나별 후기 분리** : 휠체어·시각·청각·인지·발달·외국인·가족 후기를 별도 탭으로 (단일 평점 X). "휠체어 후기 4.5/5 vs 시각 후기 3.2/5" — 페르소나마다 신뢰도가 다름을 명시.
- **무장애 동선 GPX 다운로드** : F4 PDF 출력 시 GPX도 함께 출력. 검수 큐 통과한 동선만 환류.
- **개인 무장애 프로필 영속** (로컬 저장만, 서버 X — PIPA 회피) : 한 번 입력한 페르소나·시간 예산이 모든 카드에 즉시 적용.

##### F1.F — 예측 가능 백제 (발달·인지 친화 모드)

> **설계 원칙** — 발달·인지장애를 페르소나 옵션 토글이 아닌 **별도 기능 sub-feature**로 격상. 명칭 "예측 가능 백제"는 KWCAG 2.2 § 3.2(예측 가능성) 원칙명과 직접 정합. P3·P4 활성화 시 1탭 프리셋으로 7요소 일괄 동작.

- **F1.F-1 픽토그램 일정 카드** : "오늘 할 일" 6~8개를 KS X ISO 7001 + 정부24 공공 픽토그램 + 보건복지부 사회보장 안내 픽토그램(3개 셋 재활용)으로 시각화. 6 POI × 8단계 = 48 픽토그램 자체 큐레이션.
- **F1.F-2 단계 안내 카드 (1단계 1행동)** : 한 화면에 "지금 1단계 + 다음 1단계 미리보기"만. 이전 단계 숨김으로 인지 부하 최소화.
- **F1.F-3 예측 가능 동선 + 60초 카운트다운** : 폭염·UGC 검수 통과 알림이 들어와도 즉시 변경하지 않고 60초 카운트다운 + 변경 후 모습 사전 미리보기 + Odii 쉬운글 음성. 자폐 panic meltdown 회피 (KWCAG § 3.2 직격).
- **F1.F-4 자극 강도 조절 (Sensory Calm)** : 음성·진동·시각 깜빡임·BGM 4축 슬라이더 + "조용 모드" 1탭 프리셋. KWCAG § 2.3.1(광과민) + 모바일 OS Reduce Motion API 정합.
- **F1.F-5 보호자 동반 화면** (GPS 추적 X) : 보호자가 본인 폰에서 동반자의 단계 카드 ID만 동기. 위치 좌표는 송신 X — 위치정보법 제9조의2 + PIPA 부담 회피.
- **F1.F-6 친숙 캐릭터 + AAC 예외 카드** : 백제 마스코트 일러스트 6컷 (5월 OT 외주 발주) + AAC 5종 (도움·아픔·소음·길 잃음·화장실, 한국보완대체의사소통학회 공개 셋). 발달장애 당사자의 비음성 1차 의사 표현. F1.C와 데이터 공유.
- **F1.F-7 발달장애 단체 모드** (P4 인솔자 직격) : 30명 → 10명×3그룹으로 묶어 그룹별 픽토그램 카드 일괄 인솔. F4 단체 합본 PDF로 종이 카드 배포 가능. 학생 1:N 실시간 동기는 발전방향.

> **F1.F의 콘텐츠 자체 제작은 백제 마스코트 6컷만**. 기타 콘텐츠는 모두 공공·학회 공개 셋(KS·정부24·보건복지부·한국장애인개발원·국립특수교육원·AAC 학회) 재활용.

#### F2. GPS 트리거 다국어·다채널 오디오 도슨트

- **위치 진입 시 자동 재생** — Odii.storyLocationBasedList(`xCoord`/`yCoord`/`radius`)로 반경 진입 시 백제 스토리 자동 호출. WAI-ARIA 2.2 `aria-live="polite"`로 스크린리더 동기.
- **3 모드 분리** : 어린이 모드(쉬운 말, 퀴즈 연동) / 어른 모드(전문 해설, 국가유산청 메타데이터 결합) / **쉬운글 모드** (P3 인지·발달·자폐 옵션 / P1b 시니어 인지저하) — 7세 어휘·짧은 문장·1단계 1행동
- **4채널 동시 출력** :
  - **음성** (Odii 원음 + AI 합성 보조 — "AI 음성 안내" 배지 의무)
  - **자막** (음성을 텍스트로 동시 출력, P2b 청각 직격)
  - **점자 호환 텍스트** (.brf 또는 UTF-8 plain, 한국점자도서관·한국점자규정 준수, P2a 시각 직격)
  - **수어 영상** (6 POI 샘플 MVP, 서울관광재단 다누림·국립국어원 한국수어사전 협력. 전 POI는 발전방향)
- **다국어 4종** : 국문·영문·일문·중문 간체 — KTO 다국어 원문 우선 + 자체 번역은 보조 표시 + "AI 번역" 배지 (AI 기본법 2026.1.22)

#### F3. 현장 배리어 제보 + 관리자 검수 + 후속 사용자 경고 (Waze UGC)

- 사용자가 엘리베이터 고장·공사·임시 폐쇄·화장실 이용 불가를 **사진 근거 + 선택형 양식**으로 제보 (자유 텍스트 최소화).
- **자동 재계산 X / 관리자 검수 큐 O** : 운영자(충남 CACF + 본 팀)가 검수 큐에서 1차 검증 → 검증 통과 시 후속 사용자에게 푸시 알림 + 대체 경로 제안 (TarRlteTarService1 인접지). 자동 재계산은 사용자 풀 누적 + UGC 신뢰도 점수 도입 후 발전방향.
- **신고자 신뢰도 점수** 누적 → UGC 오염·중복·악의적 제보 자동 필터.
- 위치정보법 **제9조의2**(위치기반서비스 신고)에 따라 신고 완료 후 운영, GPS 동의서 별도 명시.

#### F4. 다중 출력 다이어리 — 무장애 헤리티지 교육 산출물 (차별 1축)

- **방문 인증** : QR 또는 GPS 진입 검증
- **5축 결합 콘텐츠** : (1) 국가유산청 지정문화재 공식 해설 + (2) Odii 어린이/쉬운글/어른 모드 자동 퀴즈 + (3) 가족 사진·음성 메모 + (4) **접근성 동선 기록** + (5) 국가유산청 어린이 학습 콘텐츠
- **6 출력 채널** (페르소나·기간 따라 자동 선택) :
  - (a) **학생용 학교 제출 PDF** — 충남교육청 체험학습 양식 정합
  - (b) **교사용 루브릭** — 학년별 백제 교과 단원 매핑 + 단체 인솔 보고서 (P4 B2B 가치)
  - (c) **점자 호환 텍스트** (.brf, 한국점자규정 준수, P2a 시각)
  - (d) **쉬운글 PDF** — 7세 어휘 + 픽토그램 (P3 인지·발달 옵션 / P1b 시니어)
  - (e) **무장애 동선 GPX** — UGC 검수 통과 동선만 환류 (F1.E 연동)
  - (f) **단체 합본 PDF** (P4) — 학급 30명 다이어리 통합 + 표지 + 인솔 보고서
- **누적 다이어리 v0** (MVP) : 같은 사용자가 N회 방문 시 로컬에 회차·날짜·POI·동선·사진·퀴즈 영속 저장 → 학년 1년 누적 보고서 가능. 시즌 패스·시민 패스 발급은 발전방향.
- **출처 표기** : 국가유산청 공공누리 1·4유형 + KTO Odii Type1 + 충남교육청 양식 출처 자동 카드 삽입.

#### F5. RTO 데이터 갭 리포트 (충남 CACF 대시보드, B2G)

- detailWithTour2 누락 POI 자동 식별 → "공주 시 무장애 정보 입력 누락 12건 / 부여 군 9건" 시각화
- 사용자 제보 빈도 + UGC 검증 결과 → **접근성 개선 후보지 시군구별 히트맵** (lDongSignguCd 기준)
- 일/주/월 리포트 자동 생성 → 충남문화관광재단(CACF) + 다도라/올담과 정기 공유
- **B2G 가치를 발전성 점수(20점)로 직결**

### 2.3 서비스 차별성 (6축 + 시간 예산 차원)

KTO 「모두의 여행」·Wheelmap·Wheelmate가 멈춘 **POI 단위 정적 분류**를 본 서비스는 **6축 + 시간 예산 차원**으로 끌어올린다 :

1. **무장애 토털 가이드** (F1) — 6 sub-feature 통합
2. **다채널 도슨트** (F2) — 음성·자막·점자·수어 4채널 동시 출력
3. **실시간 검증** (F3) — Waze 패턴 + 관리자 검수 큐 + GPX 환류
4. **무장애 헤리티지 교육 산출물** (F4) — 6 출력 채널 + 국가유산청 해설 + 교사 루브릭
5. **B2G 데이터 갭 리포트** (F5) — 충남 RTO 즉시 가치
6. **시간 예산 적응 차원** (F1.D 횡단) — 반나절~2박 3일 4단계

> **6축 중 가장 강한 차별축 = (4) 무장애 헤리티지 교육 산출물.** PT 발표에서 즉시 이해되는 "결과물". 단순 사진/퀴즈 PDF가 아니라 **국가유산청 공식 해설 + Odii 다채널 + 무장애 동선 GPX + 6 채널 출력** 결합으로 *"무장애 여행이 자녀의 교육 산출물로 남고, 다음 사용자가 그대로 따라갈 수 있는 검증된 코스로 환류된다"*. 적정성·실용성·발표 3개 점수(70점) 동시 직격.

KTO 「모두의 여행」·Wheelmap·Wheelmate 어디에도 **다채널 도슨트(점자·수어 동시) · 헤리티지 메타데이터 · 시간 예산 적응 · 검증 동선 GPX 환류 · 인지·발달 옵션이 모두 부재** (공식 사이트 검증 기준).

### 2.4 서비스 내 지역 특화 (충남)

**왜 충남 단일인가** :
- **백제역사유적지구(유네스코 세계유산)** — 공주(공산성·송산리 고분군·정지산) + 부여(관북리·부소산성·정림사지·능산리·나성)
- **공주 야간관광 특화도시** — 공산성 야경·금강·부여 야시장 야간 모드 흡수
- **다도라(DADORA)** — 충남 스마트관광 전자지도 SaaS, RTO 갭 리포트와 자연스럽게 통합
- **올담(alldam)** — 충남 데이터포털, 시군 무장애 보조 데이터 보강
- **충남은 2026 공모전 RTO 특별상 8개 권역 중 하나** — 단일 지역 한정 출시 시 가점 +2 + CACF 특별상 후보

**왜 경북·다른 RTO를 안 골랐나** : 경북은 메타버스/XR 강점이지만 4개월 안 AR 콘텐츠 제작 리스크 큼. 제주는 자체 OpenAPI(REST+SPARQL)가 풍부해 KTO API 차별성이 약화. 충남은 KTO API 의존도 중간 + 명확한 유네스코 IP + 야간관광 특화도시 + 다도라/올담 RTO 협력 자산 = **무장애 헤리티지에 가장 정합적**.

**MVP 대상 6 POI (공주·부여 각 3)** :
- **공주** : 공산성(史 477) / 무령왕릉과 왕릉원(史 13) / 국립공주박물관
- **부여** : 부소산성(史 5) / 정림사지(史 301) + 정림사지박물관 / 국립부여박물관

### 3.2 데이터 활용 방식

#### (1) F1.A POI 무장애 상세 카드 — KorWithService2 detailWithTour2 21필드 매핑

**중요** — KorWithService2의 `areaCode2`/`categoryCode2` 및 legacy `areaCode`/`sigunguCode`/`cat1`/`cat2`/`cat3` 파라미터는 **2025-12-31까지만 활용 가능**. 본 서비스는 2026년 출시이므로 **`ldongCode2` + `lclsSystmCode2` 신규 체계만 사용**.

#### (2) F1.D 동선 빌더 — KorService2 신분류체계 정밀 검색
