## 1) 서비스 기획배경 및 필요성

### 1.1 서비스 기획 배경

**한국 무장애 관광 인프라는 "POI 단위 정적 인증"에 머물러 있다.** KTO 「모두의 여행」, Wheelmap, Wheelmate는 모두 "이 관광지가 휠체어 진입 가능한가"라는 단일 POI 질문에 멈춘다. 그러나 휠체어 사용자·유아차 동반 가족·시각장애인·외국인이 실제 백제역사유적지구를 방문할 때 마주치는 질문은 다음 5개다:

1. **여러 유적이 단차 없이 이어지는 동선이 시간 예산(반나절~2박 3일)에 맞게 있는가** — 한 곳만 접근 가능해서는 의미가 없고, 시간 단위가 1박 2일에 고정돼서도 안 된다.
2. **현장에 가보니 엘리베이터가 고장났다면 다음 사용자도 알 수 있는가** — 엘리베이터·경사로 정적 정보의 60% 이상이 6개월 이상 미갱신 상태다.
3. **자녀가 백제 역사를 이해하고 학교에 제출할 체험학습 자료를 만들 수 있는가** — 휠체어 자녀를 둔 가족·일반 자녀 동반 가족 공통의 페인포인트.
4. **외국인이 다국어 GPS 오디오로 백제를 이해할 수 있는가** — 현재 부여 부소산성·공주 공산성에 위치 트리거 다국어 오디오 도슨트는 운영되지 않는다.
5. **충남 RTO·지자체가 "어느 시군의 무장애 정보가 부족한가"를 데이터로 볼 수 있는가** — KorWithService2 detailWithTour2 누락 POI 시각화 도구가 한국에 없다.

세 가지 정책 흐름이 동시에 같은 방향을 가리킨다 — (a) **고령화** : 65세 이상 1,000만 명 돌파(2025), 시니어 관광 시장 +20%/yr, (b) **AI 기본법(2026.1.22 시행)** : 생성형 AI 결과물 표시·접근성 의무, (c) **KWCAG 2.2 + 디지털포용법 + 장차법 제20·21조** : 정보접근권은 권고에서 의무로 전환되는 추세.

## 2) 서비스 개요

### 2.1 기획 서비스 소개 (한 줄)

> **충남 공주·부여 백제역사유적지구를 장애 유형(휠체어·시각·청각·인지·시니어·유아차·만성질환)과 시간 예산(반나절~2박 3일)에 맞춰 동선·도슨트·다이어리·현장 검증을 한 화면에 묶은 무장애 헤리티지 관광 OS — 「모두의 백제 (Modu Baekje)」**

### 2.2 기획 서비스 주요 기능 (5개 핵심 — MVP)

#### F1. 무장애 토털 가이드 OS — 5개 Sub-Feature 통합 (단순 4단계 카드를 넘어선 현장 동반 도구)

> **설계 원칙** — 무장애 서비스의 가치는 "갈 수 있는 곳을 분류해주는 것"이 아니라 **"갈 때 함께 따라가는 것"**. 따라서 F1은 ① POI 무장애 상세 카드 + ② **상세한 베리어프리 경로 및 방법 안내**(사전 준비, v3.1) + ③ 현장 SOS·보조기기·콜택시(v3.1 핵심만) + ④ 시간 예산 6단 + ⑤ 페르소나별 후기·GPX 환류 + ⑥ **쉬운 백제 모드(발달·인지장애 전용, v3.1 신규)** — **6개 sub-feature를 한 화면에 통합**한다.

##### F1 입력 — 4 페르소나 (다중 선택) + 시간 예산 + 시즌 + 음성 진입점

- **P1 휠체어·시니어** — **P1a 휠체어/도우미견** : 단차·경사·엘리베이터·회전 공간 / **P1b 시니어·만성질환** : 피로도·낙상·휴식 간격(≤30분 강제)·큰 글씨·심혈관/호흡기 폭염·미세먼지 회피
- **P2 시각·청각** (내부 분리, UX 반대 성격) — **P2a 시각** : 음성 우선·점자블록·도우미견·고대비·STT 음성 검색 / **P2b 청각** : 자막·시각 알림·**수어 1차 사용자 토글**(자막은 보조)
- **P3 가족·자녀** — 유아차·수유실·어린이 학습. **하위 옵션**: 인지·발달장애·자폐 스펙트럼·치매 초기를 "**쉬운글 · 낮은 자극 · 짧은 동선 · 픽토그램 일정 카드 · 예측 가능 안내**" 옵션으로 흡수 (별도 P5 페르소나 신설 X — 페르소나 과다 회피, 옵션 토글로 처리)
- **P4 단체 인솔자** — 학교·복지기관·발달장애 단체. 인솔자 화면·일괄 발급·단체 합본 PDF
- **횡단 — 외국인 4언어** (P1~P4 위에 겹침) : 영·일·중·국문, 1330·영사콜센터·응급 다국어
- **시간 예산 슬라이더** : 분 단위 입력. 6단 프리셋 (반나절·당일·1박 2일·2박 3일·다회차·시즌 패스)
- **시즌 토글 (MVP 부분)** : 백제문화제(9-10월)·야간관광(여름 저녁)·여름 폭염 회피(실내 박물관 우선) — KorService2 `searchFestival2` + 기상청 특보 + 다도라 시즌 일정 결합
- **F1 진입점 — 음성 검색 자체 구현** (KWCAG 2.2 시연 첫 컷, P1·P2a 접근성 직격) : _"휠체어로 갈 수 있는 반나절 공산성 코스 찾아줘"_ / _"내일 오후 부여에서 자녀와 갈 수 있는 곳 찾아줘"_ — STT 입력이 PT 발표 첫 장면.

##### F1.A — POI 무장애 상세 카드 (단순 4단계 라벨이 아니라 풍부한 현장 정보)

각 POI 카드는 다음 모든 요소를 포함한다 — 사용자가 "갈까 말까"가 아니라 "**어떻게 갈까**"를 결정 가능하게 한다.

| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상단 라벨**                        | 4단계 — 방문 가능(≥75) / 주의 필요(50~74) / 정보 없음(현장 확인 필요) / 대체 추천. **부재 사유 2분류 라벨 동시 표시** : (a) 본질 제약 — "사적지 계단으로 휠체어 진입 불가 — 문화재 본질 보존 사유" / (b) 운영자 미입력 — "F5 갭 리포트 우선 후보" |
| **출입구별 사진 + 경사도 표시**      | 정문/후문/북문 등 각 출입구마다 사진 + 카카오맵 / VWorld 경사도 데이터 + 사용자 UGC 검증 횟수                                                                                                                                                     |

| **점자블록 / 음성 안내 시스템 경로** | KorWithService2 `braileblock` · `audioguide` · `guidesystem` 시각화 (P2a 핵심)                                                                                                                                                                    |
| **휴식 인프라**                      | 벤치 / 그늘 / 실내 휴게 / 에어컨 / 화장실 간격 표기 (P1b 만성질환·시니어 직격)                                                                                                                                                                    |

##### F1.B — 상세한 베리어프리 경로 및 방법 안내 (사전 준비 + 현장 참조 — 실시간 내비 X)

> **설계 원칙 (v3.1 변경)** — 4개월 MVP에서 실시간 GPS 50m 단위 내비는 카카오 모빌리티 길찾기 + WAI-ARIA `aria-live` + Whisper STT 동기 운영 부담이 과대 → **사전에 검수된 무장애 가이드를 현장에서 단계별로 참조**하는 정적 안내로 대체. 부수 효과: 오프라인 작동 + GPS 위치 전송 최소화로 위치정보법 부담 감소.

- **음성 검색 진입점 (자체 STT)** : 페이지 진입 시 _"휠체어로 갈 수 있는 반나절 공주 코스"_ 음성 검색 → STT (Naver Clova / Whisper) → F1.D 시간 예산 모드로 전달. 음성 검색은 일회성 입력이라 실시간 내비보다 부담 작음 — 유지.
- **현장 도움 카드** : 현장에서 길을 잃었을 때 즉시 표시 가능한 단계 카드 (F1.C SOS와 연결).

##### F1.E — 페르소나별 후기 분리 + 무장애 동선 GPX 환류

##### F1.F — 예측 가능 백제 (발달·인지 친화 모드, v3.1 신규)

> **설계 원칙 (Subagent A + Codex v3.1 합의)** — v3에서 인지·발달장애를 P3 가족 페르소나의 옵션 토글로 흡수했으나 이는 **입력 차원**일 뿐 **기능 차원**이 아니다. 자폐 스펙트럼·지적장애·발달장애·치매 초기 사용자에게는 별도 화면 모드가 필요. **P5 별도 페르소나 신설은 금지** (Codex v3 비평 — 페르소나 5+ 입력 UX 복잡도 위험), 대신 P3 가족 + P4 단체가 활성화하는 **"인지지원 sub-feature"** 로 F1 안에 격상. 명칭은 **"예측 가능 백제"** — KWCAG 2.2 § 3.2(예측 가능성) 원칙명과 직접 정합 (PT에서 "법령 정합" 서사 직격) + "쉬운"의 낙인 위험 회피. 한국 디지털포용법 후속 입법(인지 접근성)의 다음 축을 선도.

- **F1.F-1 픽토그램 일정 카드** : "오늘 할 일" 6~8개를 **KS X ISO 7001 + 정부24 공공 픽토그램 + 보건복지부 사회보장 안내 픽토그램** 셋 재활용으로 시각화. 6 POI × 평균 8단계 = **48 픽토그램 자체 큐레이션** (자체 제작 X). 글 대신 그림으로 일정 인지 — 자폐 자녀·치매 초기 시니어·발달장애 단체 인솔 동시 충족.
- **F1.F-2 단계 안내 카드 (1단계 1행동)** : 한 화면에 "지금 1단계 + 다음 1단계 미리보기"만. **이전 단계는 숨김** — 인지 부하 최소화. F1.B 단계 카드보다 더 단순화한 버전.
- **F1.F-3 예측 가능 동선 + 60초 카운트다운** : 폭염 회피·F3 UGC 검수 통과 알림이 들어와도 **즉시 동선을 바꾸지 않고 60초 카운트다운 후 변경** + 변경 후 모습 사전 미리보기 + Odii 쉬운글 음성 _"1분 뒤에 길이 바뀌어요. 새 길은 이렇게 생겼어요"_. 자폐 panic meltdown 회피 (KWCAG 2.2 § 3.2 예측 가능성 직격).

> - **한국보완대체의사소통학회** AAC 공개 셋 (도움 카드 5종 재활용)
> - Odii 쉬운글 모드 (F2와 데이터 공유)
>
> 자체 제작은 백제 마스코트 일러스트 6컷만 (5월 OT 외주). 기타 콘텐츠는 모두 공공·학회 공개 셋 재활용 → 4개월 MVP 콘텐츠 부담 회피.

> **F1.F가 다른 sub-feature와 연동** :
>
> - **F1.A POI 카드** : 21필드 카드를 **3축으로 압축** ("갈 수 있다 / 휴식 1곳 / 화장실 1곳" + 픽토그램). 부재 사유 라벨은 캐릭터 말풍선
> - **F1.B 베리어프리 경로 안내** : 단계 카드를 더 짧게 (1단계 1행동) + 변경 시 60초 카운트다운 강제 (F1.F-3)
> - **F1.C SOS** : AAC 5종 카드(F1.F-6)가 SOS 메뉴 안에 통합 — 음성 전달 어려운 사용자가 비음성으로 도움 요청
> - **F2 4채널 출력 (Odii)** : 음성=쉬운글 + 자막 단순화(한 문장 ≤12자) + 점자 그대로 + 수어 그대로. BGM·효과음 자동 차단 (F1.F-4)
> - **F4 다이어리** : (d) 쉬운글 PDF가 **픽토그램 다이어리로 격상** — 사진+픽토그램+한 줄 설명. (f) 단체 합본 PDF는 F1.F-7 단체 모드 산출물

> **국내 최초 헤리티지 관광 발달·인지 친화 모드** (KTO 「모두의 여행」·서울관광재단 다누림·Wheelmap·Wheelmate 공식 사이트 검증 기준 — 모두 부재).

#### F2. GPS 트리거 다국어·다채널 오디오 도슨트 (Odii 활용 + 점자·수어·쉬운글 보강)

- **위치 진입 시 자동 재생** — Odii.storyLocationBasedList(`xCoord`/`yCoord`/`radius`)로 반경 진입 시 백제 스토리 자동 호출. WAI-ARIA 2.2 `aria-live="polite"`로 스크린리더 동기.
- **3 모드 분리** : 어린이 모드(쉬운 말, 퀴즈 연동) / 어른 모드(전문 해설, 국가유산청 지정문화재 메타데이터 결합) / **쉬운글 모드 (P3 인지·발달·자폐 옵션 / P1b 시니어 인지저하)** : 7세 어휘·짧은 문장·1단계 1행동·예측 가능 안내.
- **4채널 동시 출력** :
  - **음성** (Odii 원음 + AI 합성 보조 — "AI 음성 안내" 배지 의무, AI 기본법 2026.1.22 대응)
  - **자막** (음성을 텍스트로 동시 출력, P2b 청각 직격)
  - **점자 호환 텍스트** (.brf 또는 UTF-8 plain, 한국점자규정 준수, P2a 시각 직격) — MVP 가능
  - **수어 영상** (6 POI 샘플만 자체 제작 또는 서울관광재단 다누림·국립국어원 한국수어사전 활용, **수어 1차 사용자 P2b 토글**) — 6 POI 샘플은 MVP, 전 POI는 발전방향
- **다국어 4종** : 국문(KorService2) + 영문(EngService2) + 일문(JpnService2) + 중문 간체(ChsService2). 자체 번역은 보조 표시 + "AI 번역" 배지. 문화공공데이터광장 「전국 다국어 가이드 시설」 교차검증.

#### F3. 현장 배리어 제보 + 관리자 검수 + 후속 사용자 경고 (Waze 패턴 UGC, MVP 강도 조정)

- 사용자가 엘리베이터 고장·공사 구간·임시 폐쇄·화장실 이용 불가를 **사진 근거 + 선택형 양식**으로 제보 (자유 텍스트 최소화 — UGC 오염 방지).
- **MVP 단계 — 자동 재계산 X / 관리자 검수 큐 O** : 운영자(충남 CACF + 본 팀)가 검수 큐에서 1차 검증 → 검증 통과 시 후속 사용자에게 **푸시 알림 + 대체 경로 제안** (TarRlteTarService1 인접지). 자동 재계산은 **사용자 풀 누적 + UGC 신뢰도 점수 도입 후 발전방향**으로 이전 — 4개월 안 사용자 풀·책임 소재 미확보 상태에서 잘못된 자동 재계산은 사용자 안전 사고 책임 발생 위험.
- **신고자 신뢰도 점수** 누적 (검증 통과 비율 → 점수 가중) → UGC 오염·중복·악의적 제보 자동 필터.
- 위치정보법 **제9조의2** (위치기반서비스 신고)에 따라 신고 완료 후 운영, GPS 동의서 별도 명시 (PIPA 처리방침).

#### F4. 다중 출력 다이어리 — 무장애 헤리티지 교육 산출물 (학교/점자/쉬운글/GPX/단체합본/누적 v0, 차별 1축)

- **방문 인증** : QR 또는 GPS 진입 검증.
- **5축 결합 콘텐츠** : 단순 사진/퀴즈 PDF가 아니라 **(1) 국가유산청 지정문화재 공식 해설** + (2) Odii 어린이/쉬운글/어른 모드 스토리에서 자동 생성된 백제 퀴즈 + (3) 가족 사진·음성 메모 + (4) **접근성 동선 기록**(어떤 무장애 경로로 어떤 휴식 간격으로 갔는가) + (5) **국가유산청 어린이 학습 콘텐츠**(heritage.go.kr) — 일반 체험학습 앱과 결정적으로 분기.
- **6 출력 채널** (페르소나·기간 따라 자동 선택) :
  - **(a) 학생용 학교 제출 PDF** — 충남교육청 체험학습 양식 정합
  - **(b) 교사용 루브릭** — 학년별 백제 교과 단원 매핑 + 단체 인솔 보고서 (P4 교사 페르소나 직격, B2B 가치)
  - **(c) 점자 호환 텍스트 출력** — .brf 또는 UTF-8 plain, 한국점자규정 준수 (P2a 시각 직격) — **MVP 가능**
  - **(d) 쉬운글 PDF** — 7세 어휘 + 픽토그램 + 짧은 문장 (P3 인지·발달 옵션 / P1b 시니어) — **MVP 가능**
  - **(e) 무장애 동선 GPX 파일** — 다음 사용자가 그대로 따라갈 수 있는 검증된 무장애 코스. UGC 검수큐 통과 동선만 GPX 환류 → F1.E와 연동
  - **(f) 단체 합본 PDF** (P4 교사·복지) — 학급 30명 다이어리를 1개 통합 PDF로 자동 합본 + 표지 + 인솔 보고서
- **누적 다이어리 v0 (MVP)** : 같은 사용자가 N회 방문 시 로컬에 회차·날짜·POI·접근성 동선·사진·퀴즈 영속 저장 → 학년 1년 단위 누적 보고서 출력 가능. 시즌 패스·시민 패스 발급은 발전방향.
- **출처 표기** : 국가유산청 공공누리 1·4유형 + KTO Odii Type1 + 충남교육청 양식 출처 — 자동 출처 카드 삽입 (저작권법 + AI 기본법 2026.1.22 정합).
- **PT 시연 핵심 장면** — "할아버지가 들려주신 무령왕 이야기" 음성 메모 + 무장애 동선 GPX + 국가유산청 해설 + 점자 텍스트 동시 출력 = 학교 제출용 + 다음 시각장애 사용자가 그대로 따라갈 수 있는 검증된 코스 환류.

#### F5. RTO 데이터 갭 리포트 (충남 CACF 대시보드, B2G)

- detailWithTour2 누락 POI 자동 식별 → "공주 시 무장애 정보 입력 누락 12건 / 부여 군 9건" 시각화.
- 사용자 제보 빈도 + UGC 검증 결과 → **접근성 개선 후보지 시군구별 히트맵** (lDongSignguCd 기준).
- 일/주/월 리포트 자동 생성 → 충남문화관광재단(CACF) + 다도라 / 올담 데이터포털과 정기 공유.
- **B2G 가치를 발전성 점수(20점)로 직결**.

### 2.3 서비스 차별성 (6축 통합 + 시간 예산 차원)

KTO 「모두의 여행」·Wheelmap·Wheelmate가 멈춘 **POI 단위 정적 분류**를 본 서비스는 **6축 + 시간 예산 차원**으로 끌어올린다 :

1. **무장애 토털 가이드** (F1) — 단순 4단계 라벨이 아니라 **6 sub-feature 통합** (POI 무장애 상세 카드 + **상세 베리어프리 경로·방법 안내**(사전 준비) + SOS·보조기기·콜택시 + 시간 예산 6단 + 페르소나별 후기·GPX 환류 + **쉬운 백제 모드** 발달·인지장애 전용)
2. **다채널 도슨트** (F2) — Odii 위치기반 자동 재생 + 다국어 4종 + **음성·자막·점자·수어 4채널 동시 출력**
3. **실시간 검증** (F3) — Waze 패턴 + 관리자 검수 큐 + 후속 사용자 경고 + 검수 통과 동선 GPX 환류
4. **무장애 헤리티지 교육 산출물** (F4) — 다이어리 6 출력 채널 (학교/점자/쉬운글/GPX/단체합본/누적 v0) + 국가유산청 공식 해설 + 교사 루브릭
5. **B2G 데이터 갭 리포트** (F5) — 충남 RTO에 즉시 가치 + 시즌 환류
6. **시간 예산 적응 차원** (F1.D 횡단) — 반나절·당일·1박 2일·2박 3일 4단계 MVP + 다회차·시즌 패스·1년 학년 패스 발전방향

> **6축 중 가장 강한 차별축 = (4) 무장애 헤리티지 교육 산출물.** 동선·혼잡·UGC는 데이터 활용 적절성 점수(20점)를 만들고, 다이어리는 **PT 발표에서 즉시 이해되는 "결과물"** 이다. 단순 사진/퀴즈 PDF는 흔하지만, 본 서비스는 **국가유산청 공식 해설 + Odii 다채널 모드(음성·자막·점자·수어) + 가족 사진·음성 + 무장애 동선 GPX 기록 + 6 채널 출력**(학교/점자/쉬운글/GPX/단체합본/누적) 결합으로 일반 체험학습 앱과 분기한다 — **"무장애 여행이 자녀의 교육 산출물로 남고, 다음 사용자가 그대로 따라갈 수 있는 검증된 코스로 환류된다"**. 적정성·실용성·발표 3개 점수(70점)를 동시에 끌어올린다.

**KorWithService2 detailWithTour2 + Odii GPS + 다국어 4종 + 국가유산청 + BF 인증·장애인편의시설 현황 + DataLab/TatsCnctr + 응급의료/AED + 충남교육청 양식 + 한국관광 1330·영사콜센터**의 9축 결합 — KTO 「모두의 여행」(POI 단위 정적 분류) · Wheelmap·Wheelmate(글로벌 휠체어 POI) 어디에도 **다채널 도슨트(점자·수어 동시) · 헤리티지 메타데이터 · 시간 예산 적응 · 검증 동선 GPX 환류 · 인지·발달 옵션이 모두 부재**(공식 사이트 검증 기준). "유네스코 백제 + KWCAG 2.2 자체점검 + AI 기본법 + 충남 RTO B2G + 시간 예산 적응" 5축은 PT 적정성 점수(30점) 직격.

### 2.4 서비스 내 지역 특화 (충남 — 필수 항목)

**왜 충남 단일인가** :

- **백제역사유적지구(유네스코 세계유산)** — 공주(공산성·송산리 고분군·정지산 유적) + 부여(관북리 유적·부소산성·정림사지·능산리 고분군·나성) — 명확한 헤리티지 IP.
- **공주 야간관광 특화도시** — 공산성 야경·금강·부여 야시장을 야간 모드 핵심 콘텐츠로 그대로 흡수.
- **다도라(DADORA)** — 충남 스마트관광 전자지도 SaaS, 본 서비스의 RTO 갭 리포트와 자연스럽게 통합 가능.
- **올담(alldam)** — 충남 데이터포털, 공주·부여 시군 무장애 보조 데이터 보강.
- **충남은 2026 공모전 RTO 특별상 8개 권역(부산·대전·광주·세종·충남·경북·강원·제주) 중 하나** (info.pdf p.6) — 단일 지역 한정 출시 시 가점 +2 + CACF 특별상 후보.

**왜 경북 / 다른 RTO를 선택하지 않는가** : 경북은 메타버스/XR 강점이지만 4개월 안에 AR 콘텐츠 제작 리스크 큼. 제주는 자체 OpenAPI(REST+SPARQL)가 풍부해 KTO API 활용 차별성이 약화됨. 충남은 KTO API 의존도 중간 + 명확한 유네스코 IP + 야간관광 특화도시 + 다도라/올담 RTO 협력 자산 = **무장애 헤리티지에 가장 정합적**.

**MVP 대상 6 POI (공주·부여 각 3)** :

- **공주** : 공산성(史 477) / 무령왕릉과 왕릉원(史 13) / 국립공주박물관
- **부여** : 부소산성(史 5) / 정림사지(史 301) + 정림사지박물관 / 국립부여박물관

**확장 후보 (발전방향)** : 공주 한옥마을·송산리 고분군 / 부여 능산리 고분군·궁남지·백제문화단지 / 익산(미륵사지·왕궁리 유적) / 논산.

### 3.2 데이터 활용 방식

#### (1) F1 적합도 카드 — KorWithService2 detailWithTour2 21필드 직접 활용

매뉴얼 (`docs/api_manual/1737596514908/한국관광공사_개방데이터_활용매뉴얼(무장애여행)_v4.3.docx`) 응답 필드 직인용 :

| 카테고리         | 응답 필드 (영문 키)                                                                                                             | 본 서비스에서의 의미                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **공통 5**       | `parking` · `route` · `publictransport` · `ticketoffice` · `promotion`                                                          | 주차·접근로·대중교통·매표소·홍보물 무장애                            |
| **지체장애 7**   | `wheelchair` · `exit` · `elevator` · `restroom` · `auditorium` · `room` · `handicapetc`                                         | 휠체어 임대·출입구·엘리베이터·장애인 화장실·관람석·전용 객실         |
| **시각장애 7**   | `braileblock` · `helpdog` · `guidehuman` · `audioguide` · `bigprint` · `brailepromotion` · `guidesystem` (+ `blindhandicapetc`) | 점자블록·도우미견·안내인·오디오 가이드·큰 글씨·점자 안내·안내 시스템 |
| **청각장애 4**   | `signguide` · `videoguide` · `hearingroom` · `hearinghandicapetc`                                                               | 수어 안내·영상 안내·청각 보조 객실                                   |
| **영유아가족 3** | `stroller` · `lactationroom` · `babysparechair` (+ `infantsfamilyetc`)                                                          | 유아차 임대·수유실·유아 의자                                         |

**호출 예시** (공주시 부소산성 무장애 상세 — `contentId=988449`는 매뉴얼 샘플 ID, 운영 시 실제 ID로 치환) :

```
GET https://apis.data.go.kr/B551011/KorWithService2/detailWithTour2?
    serviceKey={KEY}&MobileOS=ETC&MobileApp=ModuBaekje&_type=json&contentId=988449
```

**중요 — 신구 코드 체계 전환** : KorWithService2의 `areaCode2` / `categoryCode2` 오퍼레이션과 legacy `areaCode` / `sigunguCode` / `cat1` / `cat2` / `cat3` 파라미터는 **2025-12-31까지만 활용 가능** (매뉴얼 § areaCode2 명시). 본 서비스는 2026년 출시이므로 **`ldongCode2` + `lclsSystmCode2` 신규 체계만 사용**한다.

#### (2) F1 동선 빌더 — KorService2 신분류체계 정밀 검색

충남 공주·부여 백제 유적의 lclsSystm 분류 매핑 (매뉴얼 부속 `신분류체계정보 관광타입정보 연계 정의서.xlsx` 직인용) :

| 카테고리                      | lclsSystm1    | lclsSystm2        | lclsSystm3 (예시)       | contentTypeId |
| ----------------------------- | ------------- | ----------------- | ----------------------- | ------------- |
| 공산성·부소산성·무령왕릉      | `HS` 역사관광 | `HS01` 역사유적지 | (12개 소분류 중 매칭)   | 12 (관광지)   |
| 정림사지 등 종교성지          | `HS`          | `HS03` 종교성지   | (4개)                   | 12            |
| 국립공주박물관·국립부여박물관 | `VE` 문화관광 | `VE07` 전시시설   | (6개)                   | 14 (문화시설) |
| 백제문화제                    | `EV` 축제     | `EV01` 축제       | `EV010100` 문화관광축제 | 15 (축제)     |
| 백제관·한옥스테이 (숙박)      | `AC` 숙박     | `AC03` 펜션/민박  | `AC030200` 한옥스테이   | 32 (숙박)     |

호출 예시 (공주시 — `lDongRegnCd=44` 충청남도 + `lDongSignguCd=150` 공주시) :

```
GET https://apis.data.go.kr/B551011/KorService2/areaBasedList2?
    serviceKey={KEY}&MobileOS=ETC&MobileApp=ModuBaekje&_type=json
    &lDongRegnCd=44&lDongSignguCd=150&lclsSystm1=HS&lclsSystm2=HS01
    &contentTypeId=12&arrange=C&numOfRows=50
```

**KorWithService2 contentTypeId 제약** : 매뉴얼 § 무장애 안내 — 무장애 서비스는 **12 / 14 / 15 / 28 / 32 / 38** 6종만 지원 (음식점 39 · 여행코스 25 미지원). 본 서비스는 식음료 무장애 정보를 다음과 같이 보강한다 — KorService2 detailIntro2의 contentTypeId별 분기 필드: **관광지 12 `chkbabycarriage`(유모차 대여) / 음식점 39 `kidsfacility`(어린이놀이방)** (매뉴얼 § detailIntro2 표 직인용 — 음식점 39에는 `chkbabycarriage` 필드 자체가 존재하지 않으며 `kidsfacility`만 존재).

#### (3) F2 GPS 트리거 다국어 도슨트 — Odii 위치기반

매뉴얼 (`docs/api_manual/1720672146251/한국관광공사_개방데이터_활용매뉴얼(오디)_v4.1.docx`) 특이 사항 :

- **좌표 파라미터 명이 다른 서비스와 다름** — `xCoord` / `yCoord` (KorService2의 `mapX` / `mapY`가 아님).
- **`langCode` 파라미터** — `ko` / `en` / `ja` / `zh-CN` 등으로 다국어 분기.
- **신분류체계(lclsSystm) 미사용** — 자체 `themeNm` 등 코드 체계 활용.

호출 예시 (공주 공산성 진입 시 영어 백제 스토리 자동 호출) :

```
GET https://apis.data.go.kr/B551011/Odii/storyLocationBasedList?
    serviceKey={KEY}&MobileOS=ETC&MobileApp=ModuBaekje
    &langCode=en&xCoord=127.1247&yCoord=36.4654&radius=500
```

#### (4) F2 외국인 다국어 카드 — 4언어 contentTypeId 매핑

다국어 매뉴얼은 contentTypeId 코드 체계가 국문과 다르다 — **국문 12(관광지) ↔ 다국어 76**, **국문 14(문화시설) ↔ 다국어 78**, **국문 15(축제) ↔ 다국어 85**, **국문 32(숙박) ↔ 다국어 80** (다국어 v4.4 매뉴얼 § Table 4 직인용). 본 서비스는 외국인 모드 진입 시 자동 매핑 변환을 거쳐 EngService2 / JpnService2 / ChsService2 호출.

#### (5) F1 시간대 적합도 + 야간관광 — TatsCnctrRateService

매뉴얼 § `tatsCnctrRateList` 직인용 — `areaCd` (legacy 지역코드, 충남=34) + `signguCd` (예: 부여 34800) + `tAtsNm` (관광지명) 기반 향후 30일 집중률.

```
GET https://apis.data.go.kr/B551011/TatsCnctrRateService/tatsCnctrRateList?
    serviceKey={KEY}&MobileOS=ETC&MobileApp=ModuBaekje
    &areaCd=34&signguCd=34800&tAtsNm=부소산성
```

> 주의 — TatsCnctrRateService는 매뉴얼 기준 legacy areaCd / signguCd를 사용한다. lDong 5자리 체계가 아닌 별도 코드 체계임. 본 서비스는 두 체계 매핑 테이블을 내부 유지.

#### (6) F5 RTO 대시보드 — DataLabService 일일 방문자

매뉴얼 § `locgoRegnVisitrDDList` 직인용 — `startYmd` / `endYmd` (YYYYMMDD) 필수. KT 내국인 + SK텔레콤 외국인 이동통신 기반. 매뉴얼이 명시한 한계 — **"방문 목적을 정확히 알 수 없으므로 '방문자'는 '관광객'과 동일하게 정의되지 않음"**. 본 서비스는 이 한계를 화면에 명시하고 추세 분석 보조로만 사용한다.

#### (7) — (v3 갱신) F1 5 sub-feature · F2 4채널 · F4 6채널 데이터 결합 패턴

> v3에서 F1을 5 sub-feature로 풍부화하고 F2를 4채널 동시 출력으로 확장했으므로, 각 sub-feature가 어떤 KTO API + 외부 데이터를 결합하는지를 다음 (8)~(14)에서 패턴별로 명시한다.

- **공공누리 출처 표시** — KorService2/KorWithService2의 `cpyrhtDivCd`가 `Type1`(제1유형 — 출처표시) 또는 `Type3`(제1유형 + 변경금지)로 반환. 화면에 출처 자동 표기. 국가유산청 데이터는 KOGL Type 1, 충남 올담은 KOGL 4유형(데이터별 확인).

> P2a 시각 + 도우미견 + 외국인 영문 동시 선택 → F1 진입점 STT 음성 검색 _"Find me a barrier-free Baekje half-day course in Buyeo with audio guide and helpdog-friendly POIs"_ → KorWithService2 `helpdog` · `braileblock` · `audioguide` · `bigprint` 4 critical 필드 매트릭스 통과 POI만 필터 → Odii 영문 음성 + **점자 호환 텍스트** 동시 출력 → F1.B 단계별 음성 내비 (도로명주소 영문 음성 안내) → F4 출력에서 .brf 점자 텍스트 다운로드.

### D.5 보조 시연 4 — F1.F 자폐 스펙트럼 자녀 + 부모 (v3.1 D.7 흡수·확장)

> 부여 정림사지에 자폐 스펙트럼 초등 5학년 자녀와 부모 도착. F1.F **"예측 가능 백제 모드"** 1탭 활성. **F1.F-1 픽토그램 일정 카드**가 "오늘 6단계: ① 정림사지 입구 → ② 5층 석탑 → ③ 박물관 → ④ 점심 → ⑤ 휴식 → ⑥ 출발"을 KS 픽토그램으로 표시. **F1.F-2 단계 카드**는 "지금: ② 5층 석탑 보기 / 다음: ③ 박물관 들어가기"만 표시 — 이전 단계 숨김. 진입로 우회 발생 → **F1.F-3 예측 가능 동선**이 60초 카운트다운 + Odii 쉬운글 음성 _"1분 뒤에 길이 바뀌어요. 새 길은 이렇게 생겼어요"_ + 변경 후 사진 미리보기. **F1.F-4 자극 강도 "조용 모드"** 활성으로 BGM 차단·진동만. 자녀가 화장실이 급함 → **F1.F-6 AAC 예외 카드 5종** 중 "화장실이 필요해요" 픽토그램 카드를 부모에게 1탭으로 제시 (음성 전달 부담 X). **F1.F-5 보호자 동반 화면**으로 부모가 본인 폰에서 자녀의 단계 진행 확인 (GPS 좌표는 송신 X — 위치정보법 제9조의2 신고 부담 회피).

### D.6 보조 시연 5 (v3.1 신규) — F1.F-7 발달장애 성인 단체 30명 + 인솔자 2명

> 충남 발달장애인지원센터 성인 30명 + 인솔자 2명 부소산성 단체 외출. 인솔자가 F1.F **단체 모드** 진입 → 30명을 10명씩 3개 그룹으로 묶어 그룹별 픽토그램 일정 카드 발급. F4 **단체 합본 PDF**가 사전 출력되어 종이 카드로도 배포 가능. 진행 중 그룹 2의 1명이 단계에서 멈춤 → 인솔자 화면이 즉시 표시 → 인솔자가 도착해 **F1.F-6 AAC 예외 카드** 5종 중 "도움" 카드를 함께 보고 의사 확인. F4 합본 PDF + GPX로 다음 발달장애 단체가 동일 검증 동선 재사용 — 충남 CACF B2G 가치 직격.
