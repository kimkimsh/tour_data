## Codex 원본 응답

### 1. 통합 컨셉 (Headline)

- 한 줄 정의: **무장애 백제길 동선·도슨트·다이어리**
- 단일 RTO: **충남**
  - 백제역사유적지구, 공주·부여, 공주 야간관광, 다도라·올담까지 지역 자산이 구체적이다.
  - 경북보다 "4개월 MVP로 보여줄 현장·스토리·데이터 결합"이 선명하다.
- 핵심 페르소나 4명:
  - 휠체어 이용자·시니어
  - 시각·청각 접근성이 필요한 관광객
  - 유아차·초등 자녀 동반 가족
  - 교사·복지기관 단체 인솔자
- MVP 핵심 기능 5개:
  - 접근성 프로필 기반 백제권 동선 생성
  - 혼잡 회피·시간대 추천
  - GPS 트리거 Odii 다국어 도슨트
  - Waze식 접근성 제보·검증
  - 체험학습 다이어리 PDF + 보호자/교사 모드
- 발전방향으로만 둘 기능:
  - 동행 매칭
  - RTO 데이터 갭 대시보드 고도화
  - AR/3D 문화유산 체험

### 2. 쳐낼 항목과 이유

- 원천 A: **동행 매칭 F4는 MVP 제외**
  - 4개월 안에 사용자 풀, 안전 책임, 신고·CS 체계를 검증하기 어렵다. 발표에서는 "중장기 커뮤니티 기능"으로만 둔다.
- 원천 B: **6대 페르소나 중 RTO·지자체는 사용자 페르소나에서 제외**

- 원천 C: **전국 단위 확장 제거**
  - 1차 심사에서는 지역특화가 강점이다. 공주·부여 백제권에 집중해야 완성도와 시연력이 산다.

### 3. 4대주제별 1페이지 골자

#### 1) 기획배경
- 한국 무장애 관광은 POI 정보는 늘었지만, 실제 이동 가능한 동선·혼잡·현장 검증 정보가 부족하다.
- 충남 백제권은 유네스코 역사교육 여행지라서 장애인, 시니어, 가족, 학교 단체가 함께 쓰는 사회적 의미가 크다.
- 정책 흐름은 3축이다: KWCAG 2.2·디지털포용법·장차법, AI 기본법의 생성형 AI 표시 의무, 지역관광·스마트관광 데이터 활용 강화.

#### 2) 서비스 개요
- 정의: 공주·부여 백제역사유적지구를 접근성 프로필에 맞춰 이동하고, 듣고, 기록하는 무장애 여행 앱.
- 기능: 접근성 동선, 혼잡 회피, Odii 도슨트, UGC 검증, 체험학습 다이어리.
- 차별성: 정적 무장애 POI 조회가 아니라 "갈 수 있는 길", "피해야 할 시간", "남길 수 있는 결과물"을 연결한다.
- 충남 특화: 백제역사유적지구, 공주 야간관광, 다도라 전자지도, 올담 데이터포털을 보조 데이터로 연결한다.

#### 3) 데이터 활용 방안
- KorWithService2 detailWithTour2: wheelchair, elevator, restroom, braileblock, audioguide, signguide, stroller 등 접근성 필드 매핑
- KorService2 검색·상세: 관광지, 문화시설, 행사, 숙박 등 기본 POI 확보
- KorService2 ldongCode2/lclsSystmCode2: 2026 기준 행정동·분류 체계 적용
- DataLabService: 방문 수요·관심도 기반 시간대 추천
- TatsCnctrRate: 주요 지점 혼잡 회피
- TarRlteTarService1: 인근 연계 관광지 추천
- LocgoHubTarService1: 지자체 관광자원 보강
- Odii API themeBasedList/GPS 스토리: 위치기반 오디오 도슨트
- Eng/Jpn/Chs 다국어 API: 외국인용 기본 정보 제공
- 보조: 다도라·올담·국가유산청 데이터로 백제권 콘텐츠 검수

#### 4) 발전 방향
- 단기: 공주·부여 핵심 20개 POI, 5모드 동선, 다이어리 PDF, KWCAG 핵심 기준 시연.
- 중기: 충남 전역 확장, UGC 신뢰도 점수, 교사·복지기관 단체 관리, RTO 데이터 갭 리포트.
- 장기: 타 RTO 확산, 동행 매칭, AR/3D 체험, B2G SaaS화.
- B2G 가치: "어디에 엘리베이터·화장실·안내 체계가 부족한지"를 투자 우선순위 데이터로 제공한다.

### 4. 차별화 포인트

가장 강한 축은 **체험학습 다이어리**다. 동선·혼잡은 데이터 활용 점수를 만들고, 다이어리는 PT에서 바로 이해되는 결과물이다. "무장애 여행이 교육 산출물로 남는다"는 점이 다른 POI 조회형 앱과 갈린다.

**시연 시나리오** :
휠체어 할아버지와 초등 손녀가 공산성에 도착한다. 앱은 경사·화장실·혼잡을 피해 백제 동선을 바꾸고, GPS 도슨트가 어린이 설명을 재생한다. 손녀는 사진·퀴즈·음성메모로 PDF 다이어리를 제출한다.

### 5. 위험 + 완화

- **데이터 빈약** : KorWithService2가 음식점·여행코스를 제외하므로 MVP는 관광지·문화시설 중심으로 제한하고 UGC를 데이터 갭으로 표시한다.
- **다국어 품질** : 핵심 POI 20개만 우선 검수하고, 자동 번역·생성형 AI 사용 시 표시한다.
- **위치정보 규제** : GPS 트리거는 명시 동의, 최소 저장, 익명 통계, 로컬 알림 중심으로 설계한다.
- **접근성 시연 부담** : KWCAG 2.2 전체 인증이 아니라 명도 4.5:1, 44pt 터치, 키보드, 스크린리더 핵심 플로우를 확실히 시연한다.
- **UGC 오염** : 선택형 제보, 사진 근거, 중복 확인, RTO 검수 큐로 신뢰도를 관리한다.
