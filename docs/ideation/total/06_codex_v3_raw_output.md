## Codex v3 응답 (원본 그대로)

### 1. 두 강화 일관성

- 같은 방향이다. "모두 접근 가능"을 장애 유형의 깊이와 여행 시간의 폭으로 확장하는 것이므로 콘셉트 정합성은 강해진다.
- 4개월 MVP는 깊이를 우선한다. 기간은 "시간 예산" UI만 일반화하고, 시즌패스·다회차 운영은 발전방향으로 둔다.
- 충남 RTO 특별상 방어력은 상승한다. 다만 무장애 인증·장애 페르소나를 과장하면 실증 부담이 커져 PT 리스크가 생긴다.

### 2. 배리어프리 강화 비평

1. 인지·발달장애는 P5 신설보다 P3/P4 하위 모드가 안전하다.
2. KWCAG 후보 명시는 PT 신뢰도는 높지만 "자체점검"과 구분해야 한다.
3. AI 표시 자체검증은 2026 시행 법제와 맞아 발표 임팩트가 크다.
4. 점자 PDF는 MVP 가능, 수어 영상은 핵심 6 POI 샘플만 가능하다.
5. 점수는 1차 +1, PT +1~2 가능. 단 인증 과장은 감점 위험이다.

### 3. 기간 포괄 강화 비평

1. 한 줄에서 1박2일은 빼고 "시간 예산 맞춤"으로 일반화한다.
2. 시즌패스·멤버십은 발전방향. MVP에 넣으면 운영모델이 무거워진다.
3. 누적 다이어리는 PDF보다 재방문·학교 활용성 점수에 더 유리하다.
4. 시간 범위 데이터 확장은 데이터 만점 방어에 도움, 단독으론 부족하다.
5. 시연은 1박2일 고정 대신 반나절→1박2일 전환 장면이 좋다.

### 4. 동시 적용 위험 TOP 5

1. **4개월 MVP 범위 과밀**: 장애유형 확장 + 기간 확장 + UGC + PDF + RTO 대시보드가 동시에 무거움.
2. **시연 분량 과다**: 접근성·AI 표시·기간 선택·다이어리·RTO까지 넣으면 핵심 메시지가 흐려짐.
3. **페르소나 과다**: P5까지 늘리면 입력 UX와 발표 설명이 복잡해짐.
4. **콘텐츠 제작 부담**: 쉬운글, 점자 PDF, 수어 영상, 다국어 검수는 API보다 사람 일이 큼.
5. **데이터 결합 복잡도**: 시간 예산·혼잡·날씨·접근성·교육 기록을 모두 실시간화하면 안정성 리스크가 큼.

### 5. MVP / 발전방향 권고

**MVP에 넣을 것**:
1. 한 줄 정의를 "시간 예산 맞춤"으로 수정
2. 반나절·당일·1박2일·2박3일 선택 UI
3. 인지·발달장애는 "쉬운글/낮은 자극/짧은 동선" 옵션으로 흡수
4. KWCAG 2.2 핵심 플로우 자체점검 + axe-core 리포트
5. AI 생성 코스·번역·음성 안내 표시 로그
6. 점자 PDF 샘플 1종 + 쉬운글 PDF
7. 누적 다이어리 v0: 방문 회차, 사진, 퀴즈, 동선 기록 저장

**발전방향으로 보낼 것**:
1. 공식 KWCAG/WA 인증 획득 완료
2. 전 POI 수어 영상 제작
3. 시즌 패스·다회차 멤버십 결제/운영
4. 복지기관·학교 단체 구독 SaaS
5. 자동 코스 재계산 고도화
6. 인지·발달장애 별도 P5 풀 UX
7. 익산·논산·유네스코 12권역 확장

### 6. 채점 자기평가 변화

- 1차 기획력: 28 → 29. "무장애"가 휠체어 중심에서 인지·발달·쉬운글까지 확장됨.
- 1차 완성도: 26 유지. 범위가 넓어져 가산보다 리스크 상쇄가 큼.
- 데이터 활용: 20 유지. 시간 범위 확장은 만점 방어 근거를 보강한다.
- 발전성: 19 → 20. 누적 다이어리·시즌패스·다회차가 확장성 서사를 강화한다.
- **1차 총점: 95 → 96 예상**.

- PT 적정성: 29 유지. 메시지는 강해지지만 설명량 관리가 필요하다.
- PT 완성도: 26 유지. 수어·점자·인증을 과장하지 않아야 한다.
- PT 실용성: 24 → 25. 누적 다이어리와 시간 예산 선택이 체감 효용을 높인다.
- 발표 점수: 14 → 14~15. "시간 예산 슬라이더 + 쉬운글 PDF"가 잘 보이면 +1.
- **PT 총점: 93 → 94~95 예상**.

### 7. 한 줄 정의 v3 후보

1. **모두의 백제는 충남 공주·부여 백제유산을 장애 유형과 시간 예산에 맞춰 동선·도슨트·다이어리로 연결하는 무장애 헤리티지 관광 OS다.** ← 채택
2. 휠체어·시각·청각·인지약자·가족·외국인이 반나절부터 2박3일까지 안전하게 백제를 여행하고 기록하는 무장애 헤리티지 플랫폼.
3. 충남 백제역사유적지구의 접근성 데이터, 쉬운 해설, 시간 맞춤 코스, 체험학습 기록을 결합한 포용 관광 서비스.
