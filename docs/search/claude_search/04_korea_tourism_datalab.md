# 한국관광 데이터랩(KTDL) 완전 가이드

> 본 문서는 한국관광공사가 운영하는 **한국관광 데이터랩**(Korea Tourism Data Lab, https://datalab.visitkorea.or.kr) 의 공식 자료, 공공데이터포털 메타정보, 보도자료, 보고서 등을 종합한 사실 기반 조사 리포트이다. (조사 시점: 2026-05)

- **공식 URL**: https://datalab.visitkorea.or.kr
- **운영 주체**: 문화체육관광부 / 한국관광공사
- **소개 페이지**: https://datalab.visitkorea.or.kr/datalab/portal/bdp/getHowPlatformForm.do
- **메타 정보(데이터 갱신주기)**: https://datalab.visitkorea.or.kr/datalab/portal/getMetaInfoList.do
- **공공데이터포털 등록 API**: https://www.data.go.kr/data/15101972/openapi.do (관광빅데이터 정보서비스 GW)

## 1. 플랫폼 개요

| 항목 | 내용 |
|---|---|
| 출범 시점 | 2020년 4월 (관광 빅데이터 통합 플랫폼) |
| 운영 주체 | 한국관광공사(KTO) |
| 핵심 슬로건 | "고객에게 '필요'한 데이터 수집·생산, '가치'있는 데이터 분석·예측, '체감'하는 데이터 활용·개방" |
| 이용료 | 전면 무료 |
| 회원 가입 | 일반 분석은 비회원 가능, '마이 데이터랩' 등 맞춤 기능은 회원 가입 필요 |
| 주 사용자 | 관광기업, 지자체, 학계, 연구기관, 일반 시민, 개발자 |
| 다국어 | 한국어 메인 (영문 별도) |

### 1.1 플랫폼 구성 사상
- 민간 빅데이터(통신·카드·내비) + 공공 통계(관광공사·문화관광연구원)를 한 곳에서 융합 분석
- 시각화 대시보드 + 원천 데이터 다운로드(CSV/EXCEL) + 오픈 API 동시 제공
- 사용자 수준별(초급/중급/고급) 기능 분리 — 초급은 자동 인사이트, 중급은 '마이 데이터랩', 고급은 원자료 다운로드 및 API 호출

출처: https://datalab.visitkorea.or.kr/datalab/portal/bdp/getHowPlatformForm.do, https://touredu.visitkorea.or.kr/common/C202201046/0000/0

## 2. 6대 메뉴 구조

데이터랩은 다음 6개 대분류 메뉴로 구성된다.

| 대분류 | 주요 하위 콘텐츠 |
|---|---|
| 1) 지역별 분석 | 전국 현황, 지역별 관광현황, 인기관광지 현황, 인구감소지역 현황, 관광수요지수, 관광지별 분석 |
| 2) 국가별 분석 | 방한여행 현황(통계), 방한여행 현황(빅데이터), 방한 항공 운항현황, 세계여행 현황, 글로벌 SNS 트렌드 |
| 3) 관광산업 분석 | 관광사업체 인허가 현황, 숙박업종 세부현황, 관광 VOC 현황 |
| 4) 테마별 분석 | 축제, MICE, 의료관광, 야간관광, 한류관광, 캠핑, 해양관광 |
| 5) 빅데이터 | 이동통신(KT/SKT) 방문자수, 신용카드(신한) 지출액, 내비게이션(TMAP) 검색건수 |
| 6) 관광통계 / 실태조사 | 방한 외래관광객 통계, 국민 해외관광객, 관광수지, 국민여행조사, 외래관광객조사, MICE 산업통계 |

출처: https://datalab.visitkorea.or.kr/, https://datalab.visitkorea.or.kr/datalab/portal/getMetaInfoList.do

### 3.3 데이터 정의상 한계 (공식 명시)

- "방문자"는 거주·통근·통학 등 일상생활권을 벗어나 한 장소에 일정 시간 이상 머문 사람으로, **관광객과 동일 정의가 아님** (방문 목적을 통신 데이터로 식별 불가).
- 일별 unique visitor 기준이라 한 사람이 여러 날 머물면 각 일자별로 중복 카운트됨.
- 신용카드 데이터는 신한카드 가입자 기준 가공 통계 → 전체 지역 소비를 100% 반영하지 않음.
- 내비게이션 데이터는 TMAP 사용자 기준 검색건수(목적지 입력) → 실제 방문 여부와 무관.

출처: https://www.data.go.kr/data/15101972/openapi.do

## 4. 핵심 데이터 카테고리 상세

### 4.1 빅데이터 — 이동통신(KT/SKT)
- **지표**: 광역시도/시군구별 방문자 수, 거주지 분포, 체류시간, 성별·연령대 분포
- **활용 예**: 인구감소지역 방문자 추세, 축제 효과 측정, 외국인 방한 지역별 분포
- **분석 단위**: 일/주/월/연, 광역시·도 / 시·군·구

### 4.2 빅데이터 — 신용카드(신한)
- **지표**: 지역별/업종별 관광지출액, 매출 건수, 방문자 1인당 지출액, 외국인/내국인 구분
- **업종 분류**: 숙박, 음식, 쇼핑, 레저, 운수, 여행사, 문화서비스 등
- **분석 단위**: 일/월/연, 광역·기초지자체

출처: https://datalab.visitkorea.or.kr/site/portal/ex/bbs/View.do?cbIdx=1135&bcIdx=306873

### 4.3 빅데이터 — 내비게이션(TMAP)
- **지표**: 지역별 목적지 검색건수, 관광지 순위, 시간대별 검색 트렌드
- **데이터 출처**: TMAP 모빌리티 (월 사용자 1,500만+ 규모)
- **활용 예**: 지역 관광지 인기도 변화, 신규 관광지 발굴, 시즌별 핫플레이스 추적

출처: https://news.sktelecom.com/208894 (2024년 티맵 검색 22.2억회), https://datainsight.tmap.co.kr/

### 4.4 관광통계 (공공)
- **방한 외래관광객**: 월별/국가별/성별/연령별/입국항·목적별 통계
- **국민 해외관광객**: 출국 통계
- **관광수지**: 관광수입·지출 (한국은행 BoP 기반)
- **외래관광객조사**: 방한 동기, 만족도, 재방문 의향, 활동, 지출 (KCTI 분기/연)
- **국민여행조사**: 국내여행 행태 (KCTI 분기/연)

## 6. 오픈 API — 관광빅데이터 정보서비스 GW

| 항목 | 사양 |
|---|---|
| 등록처 | 공공데이터포털 https://www.data.go.kr/data/15101972/openapi.do |
| 분류 | 문화체육관광 - 관광 |
| API 타입 | REST |
| 응답 형식 | JSON + XML |
| 비용 | 무료 |
| 갱신 주기 | 실시간 |
| 트래픽(개발) | 1,000건/일 (개발계정, 자동승인) |
| 트래픽(운영) | 활용사례 등록 후 확장 가능(심사) |
| 인증 | 공공데이터포털 일반 인증키 |
| 명세 | Swagger UI 제공 + 참고 zip 다운로드 |

### 6.1 제공 정보
KT(내국인)·SKT(외국인) 이동통신 데이터 기반의 광역/기초지자체별 방문자 수 정보. (방문자 정의·일별 중복 카운트 한계 명시)

출처: https://www.data.go.kr/data/15101972/openapi.do

### 6.2 활용 단계 (전형적 절차)
1. 공공데이터포털 회원가입 → 인증키 발급
2. 개발계정으로 API 활용신청 (자동 승인)
3. Swagger UI에서 엔드포인트 테스트
4. 응답 파싱 (JSON/XML)
5. 운영계정 전환 신청 (활용 서비스 등록 시 트래픽 확장)

## 7. TourAPI 4.0 (별도 — 한국관광 콘텐츠랩)

> 한국관광 데이터랩과 별도로 한국관광공사는 **한국관광 콘텐츠랩(api.visitkorea.or.kr)** 을 통해 관광 콘텐츠 정보 API(통칭 TourAPI)를 운영한다. 데이터랩이 통계·빅데이터 중심이라면, TourAPI는 **관광지·축제·숙박·음식 등 콘텐츠 메타데이터** 중심.

| 항목 | 내용 |
|---|---|
| 공식 URL | https://api.visitkorea.or.kr/ |
| 등록처 | https://www.data.go.kr/data/15101578/openapi.do (국문 관광정보 서비스 GW) |
| 데이터 건수 | 약 26만 건 (국문 기준) |
| 다국어 | 영문/일문/중문(간/번체)/독문/불문/스페인어/러시아어 등 |
| 라이선스 | 공공누리 제1유형 (출처표시) |

### 7.1 제공 데이터 (15종)
1. 지역코드 정보
2. 서비스분류 코드 정보
3. 법정동 코드 정보
4. 분류체계 코드 정보

## 14. 데이터랩 한계 / 주의사항 (객관적 정리)

1. **방문자 ≠ 관광객**: 통신 데이터는 방문 목적을 식별하지 못함. 통근·통학 인구가 포함될 수 있음.
2. **카드 데이터 단일 사업자 의존**: 신한카드 가입자 기준 → 시장 점유율 가중 보정이 적용되지만 100% 모집단이 아님.
3. **TMAP 데이터의 행동 의미 한계**: 검색은 의도이지 실제 방문이 아님. 검색 후 미방문 비율은 측정되지 않음.
4. **갱신 지연**: 일별 데이터도 KT 4일/신한 11일/TMAP 6일 지연 → 실시간 운영 결정에는 부적합.
5. **시군구 단위 한계**: 일부 분석은 광역만 제공, 기초지자체 그래뉼 제한.
6. **API 일 트래픽**: 개발계정 1,000건/일은 대규모 서비스에는 부족 → 운영계정 전환 필수.
7. **외부 결합 시 키 매칭 비용**: 행정구역 코드(시군구)·관광지 ID·업종코드의 표준화가 일관되지 않을 수 있음.
