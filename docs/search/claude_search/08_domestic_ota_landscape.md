## 1. 야놀자 / NOL / 놀유니버스

### 1.1 그룹 구조 (2026년 초 기준)
- **야놀자 (Yanolja Co.)** — 트래블 테크 지주격. 2005년 창업, 손정의 소프트뱅크 비전펀드 등 투자 유치, 美 나스닥 상장 추진 중.
- **놀유니버스 (NOL Universe)** — 야놀자 플랫폼 + 인터파크트리플 통합 법인 (2024년 11월 출범). 2025년 3월부터 회원·포인트 통합.
- **야놀자클라우드 (Yanolja Cloud)** — B2B SaaS. PMS(자산관리시스템)·CMS(채널관리)·키오스크. 2024년 매출 912억, 5분기 연속 40% 이상 성장.
- 인수 이력: 데이블(AI), 산하정보기술(호텔솔루션), **인터파크 여행 사업부 70%를 2,940억에 인수(2021)**, 데일리호텔, eZee, Hotelogix, Innkeeper 등.

### 1.2 NOL 슈퍼앱 통합
- 브랜드 재편: 야놀자 → **NOL**, 인터파크 티켓 → **NOL 티켓**, 인터파크 투어 → **NOL 인터파크투어**.
- NOL 포인트로 통합 (전체 플랫폼 호환).
- 인바운드 플랫폼 '놀월드(NOL World)' MAU 264만 (2026.01) — 1년 전 대비 33배.

### 1.3 비즈니스 모델
| 부문 | 2024 매출 비중 | 비고 |
|---|---|---|
| 야놀자 플랫폼 | 60.27% (3,654억) | 숙박·액티비티·교통 |
| 인터파크 | 22.68% (1,371억) | 항공·공연·쇼핑 |
| 야놀자클라우드 | 약 15%+ | 글로벌 SaaS, 흑자 전환 |

### 1.4 데이터 / API
- KTO TourAPI 직접 활용 사례는 공개되지 않았으나, 자체 호텔/숙소 인벤토리(100만+ 객실), AI(데이블) 기반 추천이 중심.
- 클라우드 SaaS로 호텔의 PMS/CMS/Channel 데이터를 보유 — 산업 수준에서는 KTO를 능가하는 호텔 운영 데이터 보유.

## 2. 여기어때 (Yeogi-Eottae) / 여기어때컴퍼니

### 2.1 개요
- 운영사: **여기어때컴퍼니** (옛 GC컴퍼니)
- 사이트: <https://www.yeogi.com/>, B2B: <https://business.yeogi.com/>
- 모회사: 영국 사모펀드 **CVC캐피탈** (2022년 인수, 신규 컨티뉴에이션 펀드로 이관 완료)
- 기업가치: 1.2조 (2022년 미래에셋캐피탈 500억 투자 시점)

### 2.2 사업 영역
- **국내**: 호텔·리조트·펜션·풀빌라·게스트하우스·캠핑·모텔. 액티비티 8,000여 상품.
- **해외**: 2022년 5월부터 해외 항공권 시작. 해외 숙소 80만+ 보유. 국내 65,000개.
- **여기어때 비즈니스 (B2B)**: 임직원 복지 솔루션. 17만 임직원 가입사 보유.
- **여기어때투어**: 2026년 4월 1일 합병 예정 (이사회 승인 2026.02.26).

### 2.3 주요 지표
- 누적 다운로드 2,970만+ (2022년 보도). 국민 5명 중 3명 사용.
- 2025년 11월 시점 이용 경험률 16% — 아고다(17%)에 이은 2위로 야놀자(11%)를 추월.
- 직원 수 1,300+ 명대 (2025/2026 기준).

### 2.4 데이터 / 차별점
- 자체 모텔·호텔 인벤토리 직거래 비중 높음 (특히 모텔 카테고리).
- "Goodchoice" 브랜드 시절부터 모텔 시장 점유 → 호텔/리조트로 확장.
- KTO TourAPI 활용은 공개 사례 없음.

## 3. 마이리얼트립 (MyRealTrip)

### 3.1 개요
- 사이트: <https://www.myrealtrip.com/>
- 창업: 2012년. 가이드-여행객 P2P 중개 플랫폼으로 출발.
- 본사 자체 흑자 전환 (2024년 첫 흑자).

### 3.2 비즈니스 모델
- 출범 모델: **가이드/현지인-여행객 직접 연결 P2P** — 거래액의 가이드 80% / 마이리얼트립 20% 분배.
- 현재: 항공/숙박/투어·액티비티/패키지를 모두 다루는 **종합 여행 플랫폼**으로 확장.
- 약 150만 개 여행 상품 (2025).
- 누적 가입자 **1,000만 명 돌파** (2025.10), MAU 500만.
- 2025년 매출 **1,120억 원** (전년 892억 대비 +26%).
- 2025 OTA 이용 경험률 7% (6위).

### 3.3 AI 도입
- 2023년 ChatGPT 연동 **'AI 여행플래너'** 출시 — 자연어 대화로 일정 계획, 맛집·명소·날씨·팁 추천. AI 결과 → 마이리얼트립 상품 페이지 직접 연동.
- 2024~2025: 고객 응대 자동화/업무 프로세스 최적화에 AI 도입 — 매출 증가 vs 고정비 감소.
- "Onde-Demand" 서비스(2025) — CTO 직접 개발, AI 기반 신규 카테고리.

### 3.4 데이터 / API
- 파트너 가이드 풀, 액티비티 상품 인벤토리 자체 운영.
- KTO TourAPI 활용은 공개 사례 없음. 주로 직접 가이드/액티비티 공급사 연동.

## 4. 트리플 (Triple) — NOL 인터파크 투어 산하

### 4.1 개요
- 사이트: <https://triple.guide/intro>
- 운영사: **놀유니버스** (야놀자 그룹). 2017년 창업, 2020년 야놀자 인수 → 2022년 인터파크와 합병.
- 포지셔닝: **AI 기반 해외 여행 가이드/일정 짜기** 앱.
- 카탈로그: **235개 도시** 가이드. 항공·호텔 최저가 비교 + 일정 자동 생성.

### 4.2 핵심 기능
- **갈 곳만 선택 → 동선/일정 자동 생성**.
- 동행인 초대 → 동시 편집 일정 짜기.
- **함께 쓰는 여행 가계부** — 여행 경비 자동 정산.
- **트리플 AI** — 사용자 데이터(취향/위치/동선) 기반 항공·숙소·투어·티켓·맛집·관광지·리뷰 추천.
- 2024년 7월 'AI 기반 개인 맞춤형 여행 홈' 개편.

### 4.3 데이터
- 235 도시 자체 가이드 콘텐츠.
- 야놀자/인터파크 항공·숙박 인벤토리 통합 사용.
- KTO TourAPI 활용 공개 사례 없음.

## 5. 인터파크 (NOL 인터파크 투어 / 인터파크 티켓)

### 5.1 개요
- 사이트: <https://tour.interpark.com/> (NOL 인터파크투어로 리브랜딩 진행)
- 모회사: 놀유니버스 (야놀자 그룹).
- 1996년 창업, 국내 1호 인터넷 쇼핑몰. 2021년 야놀자가 70%를 2,940억에 인수.

### 5.2 사업 영역
- **항공권**: 국내선·국제선 (해외 항공권 강세)
- **패키지 여행**
- **공연·티켓**: 인터파크 티켓 (NOL 티켓) — 콘서트·뮤지컬·전시 1위 사업자
- **쇼핑** (점진 축소)

### 5.3 시장 변동
- 2024년 12월 → 2025년 11월 사이 OTA 이용률 11% → **6%로 반토막**.

## 10. 시장 변동 — 2025년 핵심 변화

1. **글로벌 OTA(아고다·트립닷컴) 부상, 국내 OTA(NOL·인터파크) 하락**: 2025.11 이용률 1위가 아고다(17%)로 변경. NOL은 1위 → 4위.  
2. **놀유니버스 출범 (2024.11) + 회원/포인트 통합 (2025.03)**: 야놀자 + 인터파크 + 트리플 → 단일 슈퍼앱.  
3. **마이리얼트립 첫 흑자 + 1,120억 매출 (2025)**: 국내 OTA 중 유일하게 보합~성장 유지.  
4. **하나투어 매출 역성장 (-5%)** 했으나 점유율은 14.84%로 유지.  
5. **여기어때투어 합병 (2026.04)**: 여기어때컴퍼니가 자회사 합병.  
6. **AI 도입 가속**: 트리플 AI 홈, 마이리얼트립 ChatGPT 연동, 하나·인터파크 생성형 AI 일정 도입.

## 13. 시사점 요약 (사실 정리)

- 국내 OTA 시장은 **NOL(야놀자) 슈퍼앱**, **여기어때**, **마이리얼트립** 의 삼강 구도 + 패키지 빅4 + 글로벌 OTA의 5층 구조.
- 2025년 들어 **글로벌 OTA(아고다·트립닷컴·에어비앤비)가 점유율 상위**로 부상, 국내 OTA는 이용률 하락 추세.
- KTO TourAPI는 민간 OTA의 본 서비스에는 채택 사례가 거의 없고, **KTO 자체 채널과 스타트업/공모전 영역에서 주로 활용**.
- AI 일정 짜기 기능은 마이리얼트립(ChatGPT 연동), 트리플(자체 AI), 인터파크/하나투어 등 도입이 활발하나 여전히 초기 수준.
- 디지털 전환 속도는 **NOL·여기어때(테크 기반)** > **마이리얼트립(스타트업)** > **하나·모두·노랑(레거시)** 순으로 격차.
