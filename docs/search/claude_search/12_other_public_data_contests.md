# 타 공공데이터/문화데이터/지역 공모전 — 관광 분야 수상작

본 문서는 한국관광공사 외에 정부·지자체·산하 기관이 주관한 공공데이터/문화데이터 활용 공모전 중 관광·여행 부문 수상작 및 우수사례를 정리한 자료입니다.

---

## 1. 공공데이터 활용 창업경진대회 (행안부·NIA 주관)

### 1-1. 개요

| 항목 | 내용 |
|---|---|
| 주최 | 행정안전부 |
| 주관 | 한국지능정보사회진흥원(NIA) |
| 회차 | 13회 (2025년 기준) |
| 통합 채널 | [공공데이터포털 창업경진대회](https://www.data.go.kr/suc/startup.do) |
| 시상 | 대통령상(제품·서비스 2,300만 원, 아이디어 1,200만 원), 국무총리상, 행안부 장관상 등 |
| 누적 수상작 | 약 349건 (2013~2024 합산, 공공데이터포털 등록 기준) |

### 1-2. 관광 부문 주요 수상작/사례

공공데이터포털 수상작 갤러리에서 확인 가능한 정보 기반 (전체 명단은 첨부파일 다운로드 필요):
- 분야별 수상작이 매년 등록 / 환경부, 행안부, 해양수산부, 충청도, 제주도 등 기관별 수상내역 별도 공개
- 관광 관련 단독 카테고리는 없으나 “생활/관광/문화” 분야로 다수 출품
- 출처: [공공데이터포털 수상작 목록](https://www.data.go.kr/suc/awardWinning.do), [서울 데이터광장 수상작 통합 데이터셋(2013~2024)](https://data.seoul.go.kr/dataList/OA-22582/S/1/datasetView.do)

> 본 조사 시점 기준 “관광 단독 대상 수상작” 명단은 공식 페이지에 통합 표시되지 않으며, 연도별 수상자 hwp/pdf 파일을 개별 다운로드해야 함. 추가 자료가 필요할 경우 공공데이터포털을 직접 조회 권장.

### 1-3. 지자체 단위 — 인천광역시 공공데이터 활용 아이디어 공모전 (1회~4회)
- 운영: 인천데이터포털
- 출처: [인천데이터포털 수상작 갤러리](https://www.incheon.go.kr/data/DATA030503/2039141)

### 1-4. 지자체 단위 — 서울 열린데이터광장 공공데이터 활용 창업경진대회
- 2025년 개최 진행 / 출처: [서울시 보도자료](https://news.seoul.go.kr/gov/archives/565370)

## 2. 문화데이터 활용 경진대회 (문체부·한국문화정보원 KCISA)

### 2-1. 개요

| 항목 | 내용 |
|---|---|
| 주최 | 문화체육관광부 |
| 주관 | 한국문화정보원 |
| 회차 | 11회 (2023년 기준) |
| 데이터 범위 | 공연·전시·도서·체육·**관광**·한류 등 다양한 문화공공데이터 |
| 채널 | [문화공공데이터광장 경진대회](https://www.culture.go.kr/data/contest/main.do) |
| 시상 | 문체부 장관상 + 한국문화정보원장상 / 총 5,550만 원 (2022년 제10회 기준) |

### 2-2. 2022 제10회 — 14개팀 수상

- 시상식: 2022.11.10 밀레니엄 힐튼 서울
- 우수 수상사 사례: 딥비전스(이미지/영상 AI 기반)
- **2022 문화공공데이터 개방 우수기관**:
  - 대상: 한국정책방송원
  - 최우수상: 국립중앙도서관
  - 우수상: 국립국어원, **한국관광공사**
  - 장려상: 국립국악원, 국민체육진흥공단
- 출처: [뉴스와이어](https://www.newswire.co.kr/newsRead.php?no=955233), [엔겟뉴스](https://www.ngetnews.com/news/articleView.html?idxno=412313)

### 2-3. 2023 제11회 갤러리
- [문화공공데이터광장 갤러리](https://www.culture.go.kr/data/contest/galleryView.do?year=2023)

### 2-4. 2025 문화 디지털혁신 및 데이터 활용 공모전

## 4. 제주관광 데이터 활용 공모전 (제주관광공사)

### 4-1. 2025 수상작

| 등급 | 팀명/수상자 | 서비스명 | 컨셉 | 사용 데이터 |
|---|---|---|---|---|
| 대상 | **사실토박이** | 제주 관광 상권 위험 진단 시스템 | 생존분석을 통해 카드·이동·폐업 데이터로 상권 취약성 수치화 → 정책 자원 효율 투입 + 조기 진단 | 제주관광 빅데이터 플랫폼 카드·이동 데이터 + 제주데이터허브 폐업 데이터 |

- 출처: [미디어제주](https://www.mediajeju.com/news/articleView.html?idxno=361801), [제주관광공사 공지](https://ijto.or.kr/korean/Bd/view.php?btable=notice&bno=1327)
