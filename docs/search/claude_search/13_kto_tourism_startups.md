# 한국관광공사 지원 관광 스타트업 / 관광벤처사업 정리

본 문서는 한국관광공사가 지원·육성한 관광 분야 스타트업/벤처기업 사례를 정리한 자료입니다. 관광벤처사업 공모전, 관광 액셀러레이팅 프로그램, 관광기업지원센터, 관광 글로벌 챌린지 등 KTO의 주요 스타트업 지원 채널과 그 출신 기업을 다룹니다.

---

## 1. 한국관광공사 스타트업 지원 사업 체계

### 1-1. 주요 사업

| 사업명 | 운영 시작 | 주요 내용 | 부문 |
|---|---|---|---|
| **관광벤처사업 공모전** | 2011년 | 매년 개최, 사업화 자금(3천만~최대 1억) + 컨설팅·투자유치·교류 | 예비/초기/성장 3개 부문 |
| **관광 액셀러레이팅 프로그램** | 2017년~ | 외부 액셀러레이터 협업, 보육·IR | 관광 스타트업 |
| **관광 글로벌 챌린지** | 2020년~ | 해외 진출 자금 최대 2억 + 해외 특화 액셀러레이터 | 글로벌 진출형 |
| **관광플러스팁스 (Plus TIPS)** | - | 민간 투자 연계 R&D | 기술기반 |
| **관광기업혁신바우처** | - | 혁신 컨설팅·기술도입 바우처 | 일반 |
| **관광기업지원센터** | - | 입주공간 + 멘토링 (서울/부산/인천 등) | 입주 보육 |
| **관광플러스테크 (2026~)** | 2026년 | 첨단기술 접목 스타트업 사업자금 최대 4억 | AI/Tech |

### 1-2. 시상 체계 (2023 관광벤처의 날 기준)
- 5개 지원사업, 11개 부문, 총 34개 회사 시상
- 문체부 장관상(7개사) + 한국관광공사 사장상(27개사)
- 출처: [The Festival](https://thefestival.co.kr/news/all/3709), [한국경제](https://www.hankyung.com/article/202312209775i)

## 7. 대표 관광 스타트업 심층 정리

### 7-1. 트립비토즈 (TripBToz)
- **사업**: 영상 콘텐츠 기반 호텔 예약 플랫폼 (텍스트/이미지 위주의 기존 OTA와 차별화)
- **수상**: 2023 관광벤처의 날 성장관광벤처 부문 문체부 장관상
- **확장**: 싱가포르·일본 도쿄 관광기업지원센터 입주
- 출처: [한국경제](https://www.hankyung.com/article/202312209775i)

### 7-2. 트래블월렛 (Travel Wallet)
- **사업**: 자체 핀테크 활용 70개국 45개 통화 실시간 환전·결제 카드/앱
- **성장**: 2023년 197억 원 투자 유치, 매출 전년 대비 8배 증가
- **수상**: 2023 관광벤처의 날 관광글로벌챌린지 부문 문체부 장관상
- 출처: [한국경제](https://www.hankyung.com/article/202312209775i), [Travel Wallet 공식](https://www.travel-wallet.com/en)

### 7-3. 짐캐리 (ZIMCARRY)
- **사업**: 기차역·공항 중심 수하물 보관·운송 서비스
- **수상**:
  - 2022 관광데이터 활용 공모전 최우수상
  - 2023 관광벤처의 날 성장관광벤처(일자리창출) 부문 문체부 장관상
- **의의**: 활용 공모전 → 관광벤처 사업화 성공 모범 사례

### 7-4. 트립소다 (Tripsoda)
- **사업**: 여행 동반자 매칭 + 정보공유 + 상품구매 플랫폼
- **수상**: 2023 관광벤처의 날 관광액셀러레이팅 부문 최우수 (문체부 장관상)

### 7-5. 마이리얼트립 (MyRealTrip)
- **연혁**: 2012년 7월 정주영창업경진대회 수상으로 시작
- **확장**: 현지가이드 → 호텔(2016) → 항공권(2018) → 자유여행 종합플랫폼
- **투자**: 2024년 프랑스 VC 투자 유치
- ※ 한국관광공사 관광벤처 직접 출신은 아니나 한국 대표 트래블 스타트업
- 출처: [한국경제](https://www.hankyung.com/article/2024021277111), [모비인사이드](https://www.mobiinside.co.kr/2018/08/28/startupmkt_myrealtrip/)

### 7-6. 트립스토어 (TripStore) — 엑스트라이버
- **사업**: 패키지 여행 큐레이션
- **수상**: 2024 대한민국 중소·중견기업 혁신대상 경영혁신(고객감동) 부문
- 출처: [나무위키](https://namu.wiki/w/%ED%8A%B8%EB%A6%BD%EC%8A%A4%ED%86%A0%EC%96%B4)

### 7-7. 캐플릭스 (제주패스렌트카)
- **사업**: 제주 렌터카 비교/예약 플랫폼
- **위치**: 제주 기반 → 관광벤처 등록
- 출처: [THE VC](https://thevc.kr/collections/658cc3f1d24fe033f079e788)

### 7-8. 넥스트에디션 (캠핏)
- **사업**: 캠핑장 예약 통합 플랫폼
- **분야**: 캠핑/아웃도어 (관광벤처 등록)
