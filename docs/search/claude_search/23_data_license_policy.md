# 23. 공공데이터 라이선스 / KTO TourAPI 이용 약관 / 공공데이터법

> 2026 한국관광공사 관광데이터 활용 공모전 출품작 운영을 위한 데이터 라이선스/약관/법규 조사
> 조사 시점: 2026-05-03 (현행 법령 기준)
> 출처: 국가법령정보센터(law.go.kr), 공공데이터포털(data.go.kr), KOGL(kogl.or.kr), KTO 콘텐츠랩(api.visitkorea.or.kr)

## 1. 공공데이터법 (공공데이터의 제공 및 이용 활성화에 관한 법률)

### 1.1 법령 개요
- 정식 명칭: **공공데이터의 제공 및 이용 활성화에 관한 법률** (약칭: 공공데이터법)
- 소관 부처: 행정안전부
- 시행: 2013. 10. 31. (제정), 이후 다수 개정
- 1차 출처: https://www.law.go.kr/lsInfoP.do?lsiSeq=218743
- 시행령 개정: 행정안전부가 시행령 일부개정령안을 입법예고한 바 있음 (https://www.moleg.go.kr/lawinfo/makingInfo.mo?mid=a10104010000&lawSeq=73658)

### 1.2 핵심 조항 (출품작 운영자 관점에서 알아야 할 조문)

| 조문 | 핵심 의무 |
|------|----------|
| 제3조 | 공공데이터 제공·이용 기본원칙 (자유로운 이용, 영리 목적 이용 가능) |
| 제17조 | 공공데이터 목록의 공표 및 제공 |
| 제27조 | 공공기관의 면책 — 공공기관은 데이터의 품질, 제공 중단 등으로 인한 손해에 책임지지 않음 (※ 공공기관의 고의·중과실 제외) |
| 제28조 | 이용자의 책임 — 데이터 활용 시 위법한 결과에 대한 민·형사상 책임은 이용자에게 귀속 |
| 제35조 | 분쟁 조정 — 공공데이터 제공 거부·중단 시 분쟁조정위원회에 조정 신청 가능 |

### 1.3 기본 이용 원칙
- **무상 제공이 원칙**: 공공기관은 공공데이터를 영리/비영리 구분 없이 자유롭게 이용할 수 있도록 무상 제공
- **별도 이용허락 불필요**: 공공데이터포털에 공개된 데이터는 별도 계약/허가 절차 없이 활용 신청만으로 이용 가능 (단, 일부 신청 승인 절차 있는 데이터 제외)
- **상업적 이용 가능**: 별도 제한이 없는 한 상업적 활용 가능 (KOGL 유형별로 차이 있음, 후술)

## 2. KOGL (공공누리) — 공공저작물 자유이용허락 표시

### 2.1 KOGL 개요
- 정식 명칭: **공공누리 (Korea Open Government License)**
- 운영기관: 한국문화정보원 (문화체육관광부 산하), 공공누리 정책기관: 문화체육관광부
- 1차 출처: https://www.kogl.or.kr/info/license.do
- 한국저작권위원회 안내: https://www.copyright.or.kr/gov/nuri/rule_info/index.do
- 모든 공공저작물에 대해 출처표시는 **모든 유형 공통 필수** 의무

### 2.2 KOGL 6가지 유형 (제0유형, 제1~4유형, AI유형)

| 유형 | 정식 명칭 | 출처표시 | 상업적 이용 | 변경/2차저작물 |
|------|----------|---------|-----------|--------------|
| **제0유형** | 자유 이용 | 불필요 | 가능 | 가능 |
| **제1유형** | 출처표시 | **필수** | 가능 | 가능 |
| **제2유형** | 출처표시 + 상업적 이용금지 | **필수** | **불가** | 가능 |
| **제3유형** | 출처표시 + 변경금지 | **필수** | 가능 | **불가** |
| **제4유형** | 출처표시 + 상업적 이용금지 + 변경금지 | **필수** | **불가** | **불가** |
| **AI유형** | AI 학습/이용 허용 | 불필요 | 가능 | 가능 |

### 2.3 출처표시 표준 양식
```
"[저작물명]" 또는 "[제목]" / [작성자(예:한국관광공사)] / [라이선스 유형 예: 공공누리 제1유형]
출처: [공공기관명] 홈페이지 URL
```
- 출처표시에 포함되어야 할 항목
  1. **저작물의 명칭** (또는 제목)
  2. **저작물 작성 공공기관명** (예: 한국관광공사)
  3. **저작물의 작성자 성명** (표시된 경우)
  4. **공공기관의 홈페이지 URL** (또는 작성연도)
  5. **공공누리 유형 표시 마크/문구**

### 2.4 KTO 데이터의 KOGL 유형 적용
- **한국관광공사 저작권 보호정책 (knto.or.kr/helpdeskCopyrightguide)**: KTO가 개방한 저작물은 **공공누리 제1유형(출처표시)**으로 자유 이용 허락
- 단, **이미지/사진 콘텐츠**는 KTO가 직접 촬영/제공받은 자료로 재배포 시 출처 표기 필수, 일부는 별도 라이선스 적용 가능
- **TourAPI 데이터(텍스트 정보)는 원칙적으로 1유형 적용** (상업적 이용 가능, 출처표시 필수, 2차 가공 가능)

## 3. 공공데이터포털 (data.go.kr) 이용정책

### 3.1 데이터 활용 절차
1. 공공데이터포털(https://www.data.go.kr) 회원가입
2. 원하는 OpenAPI 또는 파일데이터 검색
3. **활용신청** 버튼 클릭 → 활용 목적, 시스템 유형, 활용 범위 등 기재
4. 자동 승인 또는 제공기관 심사 후 **인증키(서비스키) 발급**
5. 마이페이지 → 데이터 활용 → OpenAPI 인증키 발급 현황에서 키 확인

### 3.2 트래픽 정책 (KTO TourAPI 포함)
- **개발계정 (Development)**: 하루 평균 **1,000건** 트래픽 제공
- **운영계정 (Production)**: 하루 최대 **100,000건** 트래픽 제공 (활용사례 등록 시 신청)
- **트래픽 초과 시**: API 호출 시 일시적 차단, 다음 날 자동 복구
- **추가 트래픽 신청**: 운영계정 신청 시 필요한 트래픽 수치를 직접 작성 가능

### 3.3 이용자 의무 (이용약관)
| 항목 | 내용 |
|------|------|
| 출처표시 | KOGL 유형(주로 1유형)에 따른 출처표시 의무 |
| 활용목적 준수 | 활용신청서에 기재한 목적 내에서 사용 |
| 재배포 시 라이선스 동일 적용 | 가공/통합 데이터를 재배포할 때 동일 KOGL 유형 적용 |
| 책임 | 데이터 활용 결과로 발생한 분쟁/손해는 이용자 부담 (공공데이터법 제28조) |
| 시스템 보호 | 비정상적 트래픽, 어뷰징, 시스템 장애 유발 행위 금지 |

### 3.4 면책 조항
- 공공기관은 데이터의 정확성/완전성/적시성에 대해 보증하지 않음
- 데이터 제공 중단(점검/장애)으로 인한 이용자 손해에 책임지지 않음 (공공데이터법 제27조)
- 단, 공공기관의 **고의·중과실** 또는 범죄행위로 인한 손해는 예외

### 3.5 활용신청 시 입력 정보
- **활용 목적**: 웹사이트 개발, 모바일 앱, 연구, 기타 등
- **시스템 유형**: REST, SOAP, 일반 등
- **활용 범위/대상**: 영리/비영리 (TourAPI는 양쪽 모두 허용)
- **이용 약관 동의**: 공공데이터 이용약관, 보안 서약 등

## 4. 한국관광공사 TourAPI 4.0 이용 정책

### 4.1 TourAPI 4.0 개요
- 공식 사이트: https://api.visitkorea.or.kr/ (한국관광공사 콘텐츠랩)
- 공모전 대표 페이지: https://www.2025tourapi.com/sub/sub01.html
- 데이터셋 등록처: https://www.data.go.kr/data/15101578/openapi.do (한국관광공사_국문 관광정보 서비스_GW)

### 4.2 제공 데이터 종류 (약 26만 건)
- 지역기반 관광정보 (관광지/문화시설/레포츠/숙박/음식점/쇼핑/축제)
- 위치기반 관광정보 (좌표 검색)
- 키워드 검색
- 행사/축제 정보 (날짜별)
- 숙박 정보
- 공통정보, 소개정보, 반복정보 (상세 부가정보)
- 분류체계 (지역코드, 서비스분류코드, 법정동코드 등)

### 4.3 인증키 발급 절차
1. 공공데이터포털 회원가입 → 한국관광공사 API 검색
2. 활용신청 → 즉시 또는 1~3일 내 자동 승인 (TourAPI는 대체로 자동 승인)
3. 인증키(Service Key) 발급 (URL Encoded 형태로 발급되는 경우와 Decoded 형태 두 가지 모두 제공)
4. 호출 시 `serviceKey=...` 파라미터로 사용

### 4.4 영리/비영리 구분
- **TourAPI는 영리/비영리 무관 자유 이용** (공공누리 제1유형 적용)
- 단, **출처 명시 필수**, 원본 데이터의 임의 변경/조작 시 책임 부담
- 이미지·사진은 KTO가 저작권을 보유하거나 제공받은 자료이므로 **재배포 시 출처 반드시 표기**

### 4.5 출처표시 권장 양식 (TourAPI)
```
출처: 한국관광공사 TourAPI (https://api.visitkorea.or.kr/)
공공누리 제1유형 (출처표시) 조건에 따라 이용
```

### 4.6 추가 트래픽 신청 조건
- 활용사례 등록 (서비스 운영 화면, URL, 활용 범위 등 기재)
- 한국관광공사 콘텐츠랩에서 별도 협력 프로그램 신청 가능
- 공모전 출품작은 활용사례 자동 등록 대상

## 5. 공공데이터 활용 시 추가로 고려할 라이선스/약관

### 5.1 데이터셋별 라이선스 표기 차이
- 공공데이터포털 데이터셋은 각 데이터셋 상세 페이지의 "라이선스" 항목에 KOGL 유형(0~4) 중 하나가 표시됨
- **반드시 데이터셋별로 적용 유형 확인 필요** (예: KTO 텍스트 데이터는 1유형, 일부 사진은 2유형 또는 별도 정책)
- 외부 출처(예: 위키, 사용자 기여)에서 가져온 데이터는 KOGL 적용 대상 아닐 수 있음

### 5.2 다른 공공기관 API와의 결합 시 주의
- 데이터 결합 시 **각 데이터셋의 라이선스 모두 준수** 필요
- 예: KTO 1유형 + 기상청 1유형 → 출처표시 모두 명시
- 한 데이터라도 2유형(상업적 이용금지)이 포함되면 결합 산출물 전체에 비상업 제한 적용 가능

### 5.3 외부 API/데이터 활용 시 주의
- 카카오/네이버/구글 지도 API 등은 별도 약관 적용 (공공데이터법 적용 대상 아님)
  - 카카오맵 API: 일일 무료 호출 한도, 출처 표기 의무
  - 네이버 클라우드 플랫폼: 유료 전환 시 비용 발생, 약관 준수
- 외부 SaaS API는 각 사업자 약관 준수 필수

### 5.4 데이터 가공/AI 학습 시
- KOGL 1유형 데이터는 AI 학습 데이터로 활용 가능 (단, 출처표시)
- AI유형으로 명시된 데이터는 출처표시 의무 없음
- 단, 데이터 내 **개인정보가 포함된 경우** 개인정보보호법 별도 적용 (가명처리/익명처리 의무)

## 6. 출품작 운영 시 데이터 라이선스 체크리스트

| 항목 | 의무 | 비고 |
|------|------|------|
| TourAPI 인증키 발급 (운영계정) | ✅ | 공공데이터포털에서 활용사례 등록 후 신청 |
| 출처표시 (공공누리 제1유형 표기) | ✅ | 푸터, About, 또는 별도 라이선스 페이지 |
| 데이터셋별 KOGL 유형 확인 | ✅ | 결합 시 가장 강한 제한 따름 |
| 트래픽 모니터링 | ✅ | 일일 한도 초과 방지 (캐싱 권장) |
| 이미지 출처 별도 명시 | ✅ | KTO 이미지는 출처/저작권 표기 필수 |
| 외부 지도/API 약관 별도 준수 | ✅ | 카카오/네이버/구글 등 |
| 활용목적 변경 시 재신청 | ✅ | 활용신청서 기재 목적 외 사용 금지 |
| 면책 조항 사용자 고지 | 권장 | 데이터 정확성 한계 안내 |
