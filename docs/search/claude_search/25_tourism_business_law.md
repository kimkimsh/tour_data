# 25. 관광진흥법 / 여행업·숙박업 등록 / 전자상거래법 / 외환·외국인관광 규제

> 2026 한국관광공사 관광데이터 활용 공모전 출품작이 직접 예약·중개·결제·숙박 정보를 다룰 때 필요한 사업법 규제 조사
> 조사 시점: 2026-05-03 (현행 법령 기준)
> 출처: 국가법령정보센터(law.go.kr), 정부24, 문화체육관광부(mcst.go.kr), 공정거래위원회(ftc.go.kr)

## 1. 관광진흥법 — 출품작이 직접 관광 사업을 운영할 때 적용

### 1.1 법령 개요
- 정식 명칭: **관광진흥법**
- 소관 부처: 문화체육관광부
- 1차 출처: https://www.law.go.kr/법령/관광진흥법
- 시행령: https://www.law.go.kr/LSW/lsInfoP.do?lsId=002413
- 시행령 별표 1 (관광사업의 등록기준, 제5조 관련): https://www.law.go.kr/flDownload.do?flSeq=97940219

### 1.2 관광사업의 종류 (관광진흥법 제3조)
1. **여행업** — 종합여행업, 국내외여행업, 국내여행업
2. **관광숙박업** — 호텔업(관광호텔, 수상관광호텔, 한국전통호텔, 가족호텔, 호스텔, 소형호텔, 의료관광호텔), 휴양콘도미니엄업
3. **관광객 이용시설업** — 전문휴양업, 종합휴양업, 야영장업, 관광유람선업, 관광공연장업, **외국인관광 도시민박업**, 한옥체험업
4. **국제회의업** — 국제회의시설업, 국제회의기획업
5. **카지노업**
6. **유원시설업** — 종합/일반/기타
7. **관광편의시설업** — 관광유흥음식점업, 외국인전용유흥음식점업, 관광식당업, 시내순환관광업, 관광사진업, 여객자동차터미널시설업, 관광토속주판매업, **관광펜션업**, 관광궤도업 등

## 2. 여행업 등록 요건 (직접 예약·판매 시)

### 2.1 여행업 종류 및 자본금 기준 (시행령 별표 1)

| 종류 | 대상 | 자본금 (2024년 7월~2026년 6월 한시 50% 경감) |
|------|------|------------|
| **종합여행업** | 국내외 여행 내·외국인 대상 | **5천만원 이상** |
| **국내외여행업** | 국내·국외 여행 내국인 대상 | **3천만원 이상** |
| **국내여행업** | 국내 여행 내국인 대상 | **1천5백만원 이상** (한시 750만원) |

### 2.2 사무실 요건
- 모든 여행업 공통
- **소유권 또는 사용권 보유** 필수
- **건축물 용도**: 근린생활시설, 업무시설, 사무실, 소매점 등 (주거전용 불가)

### 2.3 등록 절차 (관광진흥법 제4조)
- 등록 기관: **특별자치시장·특별자치도지사·시장·군수·구청장**
- 처리 기간: 약 7~14일 (지자체별 상이)
- 발급 서류: **관광사업등록증**

#### 제출 서류
1. 관광사업등록신청서
2. 사업계획서
3. 임원·대표자 신원확인서 (결격사유 확인)
4. 자본금 증빙 (잔고증명서, 결산서 등)
5. 사무실 소유권/사용권 증빙 (등기부, 임대차계약서)
6. 보증보험 또는 영업보증금 예치증명

### 2.4 영업보증금 / 보증보험 (관광진흥법 시행규칙)
- 여행자 보호 목적의 보증보험·공제 가입 또는 영업보증금 예치 의무
- 종합여행업: 5천만원~3억원 (매출 규모별)
- 국내외여행업: 3천만원~1억원
- 국내여행업: 1천만원~5천만원

### 2.5 결격사유 (관광진흥법 제7조)
- 피성년후견인·피한정후견인
- 파산선고 후 복권되지 않은 자
- 형 집행 종료 후 2년 미경과
- 등록 취소 후 2년 미경과 등

## 3. 출품작이 여행업 등록 없이 운영 가능한 범위

### 3.1 관광 정보·콘텐츠 제공 서비스
- **단순 관광지/숙박/맛집 정보 제공** → 여행업 등록 불요 (정보 매체 성격)
- **추천 알고리즘, 큐레이션, 후기 플랫폼** → 등록 불요 (단, 광고/제휴는 별개)
- **지도, 길찾기, 위치 기반 추천** → 등록 불요 (위치정보법 적용은 별도)

### 3.2 여행업 등록이 필요한 행위
- **여행 일정 설계 + 실비 받고 판매** → 여행업 등록 필요
- **숙박/항공/현지 투어 직접 예약·중개 + 수수료 수취** → 여행업 등록 필요 (OTA 형태)
- **패키지 상품 기획·판매** → 종합여행업 또는 국내외여행업 등록 필요
- **여행자에게 여행계획 제공 + 알선** → 여행업의 핵심 정의

### 3.3 단순 송객/제휴 광고 vs 여행업 경계
- 정보 제공 + 외부 사이트 링크 → 여행업 아님 (광고)
- 자체 결제 처리, 예약 확약 → 여행업 (또는 통신판매중개업으로 보호 의무)
- **광고 수수료 vs 여행 알선 수수료** 구분이 핵심

### 3.4 처벌
- 무등록 여행업 영위 시: 1년 이하 징역 또는 1천만원 이하 벌금 (관광진흥법 제82조)

## 4. 숙박업 / 외국인관광 도시민박업 / 호스텔업

### 4.1 외국인관광 도시민박업 (시행령 별표 1, 제2호 자목)
- 1차 출처: https://www.law.go.kr/LSW/lsInfoP.do?lsId=002413
- 업무처리 가이드라인 (문체부): https://www.korea.kr/common/download.do?fileId=211387&tblKey=EDN
- **정의**: 도시지역 주민이 거주하고 있는 주택을 이용해 **외국인 관광객에게** 한국 가정문화 체험 + 숙식 제공
- 등록 기관: 시장·군수·구청장

#### 등록 기준
1. **연면적 230㎡ 미만 주택**
2. **외국어 안내 서비스 가능 체제**
3. **소화기 1개 이상 + 객실마다 단독경보형 감지기**
4. **일산화탄소 경보기** (개별 난방 시)
5. **주택 종류**: 단독주택, 다가구주택, 다세대주택, 아파트(공동주택), 연립주택 (※ 일반 주거 용도여야 함)
6. **거주자 본인이 거주**하면서 운영해야 함 (오피스텔/상업시설 불가)

#### 처리 기간
- 14일

#### 운영 시 의무
- 외국인만 숙박 허용 (내국인 숙박 불법)
- 일정 기간 미운영 시 등록 취소 가능
- 화재보험 가입 의무

### 4.2 호스텔업 (시행령 별표 1, 제2호 마목)

#### 정의
- **배낭여행객 등 개별 관광객 숙박**에 적합한 시설
- 샤워장, 취사장 등 편의시설 + 외국인·내국인 관광객 문화·정보 교류시설

#### 등록 기준
1. **욕실/샤워시설을 갖춘 객실 20실 이상 30실 미만**
   - 단, 법제처 유권해석에 따르면 단독객실 외 공동객실(도미토리)도 인정 가능
2. **부대시설 면적 합계가 건축 연면적의 50% 이하**
3. **두 종류 이상 부대시설** 보유
4. **조식 제공 + 외국어 구사 인력** 등 외국인 서비스 체제
5. **대지·건물 소유권 또는 사용권** 확보 (회원 모집 시 소유권 필수)

### 4.3 그 외 관광숙박업 종류

| 종류 | 핵심 요건 |
|------|----------|
| 관광호텔업 | 객실 30실 이상, 외국어 안내 |
| 수상관광호텔업 | 수상 시설 + 30실 이상 |
| 한국전통호텔업 | 한옥 양식 |
| 가족호텔업 | 객실 30실 이상, 가족 단위 시설 |
| 소형호텔업 | 객실 20실 이상 30실 미만 |
| 의료관광호텔업 | 의료 관광객 대상, 의료기관과 인접 |

### 4.4 농어촌민박업 (관광진흥법 X, 농어촌정비법 적용)
- **농어촌민박업**: 농어촌정비법 제86조 (별도 법령)
- 농어촌 지역 주민이 거주 주택의 **연면적 230㎡ 미만**을 이용해 숙박·취사 제공
- 시·군·구청 신고
- **농어촌민박과 외국인관광 도시민박업은 별개의 사업** (지역 기준 다름)

### 4.5 숙박업 등록제 (공중위생관리법)
- **공중위생관리법**상 숙박업 신고 (보건복지부 소관)
- 모텔, 일반 호텔, 게스트하우스 (관광 등록 안 한 경우) 등은 공중위생관리법 신고
- **에어비앤비, 비제도권 공유숙박 등은 등록 없이 운영 시 불법** (관광 도시민박업 또는 농어촌민박업 등록 필요)

### 4.6 출품작이 숙박 정보를 다룰 때 주의
- **비등록 민박/숙박 정보를 추천**하는 것 자체는 정보 매체로서 가능
- 단, **결제·예약 중개 시** 통신판매중개자 책임 (전자상거래법 제20조)
- **에어비앤비 호스트 정보, 게스트하우스 비등록 사업자 정보** 노출 시 → 사용자에게 적법 등록 여부 확인 권고 안내 권장

## 5. 관광편의시설업 / 관광펜션업 / 관광식당업

### 5.1 관광편의시설업 종류 (시행령 별표 2, 제5조의2)
- 관광유흥음식점업 (한국음식점/관광극장식당)
- 외국인전용유흥음식점업
- **관광식당업** — 한국 전통 음식점, 외국어 메뉴, 한국관광공사 지정
- 시내순환관광업
- **관광사진업**
- 여객자동차터미널시설업
- 관광토속주판매업
- **관광펜션업** — 자연·문화 체험 관광에 적합한 시설
- 관광궤도업

### 5.2 지정 절차
- 시장·군수·구청장이 **지정** (등록과 별개)
- 관광사업 등록과 달리 "지정"은 한국관광공사/지자체 인증 성격
- **관광식당업** 지정: 한국관광공사 → 외국인 친화 음식점 마크 부여

## 6. 전자상거래법 / 통신판매업 / 표시광고법

### 6.1 전자상거래 등에서의 소비자보호에 관한 법률 (전자상거래법)
- 1차 출처: https://www.law.go.kr/lsInfoP.do?lsId=009318
- 시행령: https://www.law.go.kr/법령/전자상거래등에서의소비자보호에관한법률시행령

### 6.2 통신판매업 신고 (제12조)
- 신고 기관: 특별자치시장·특별자치도지사·시장·군수·구청장
- 신고 방법: 정부24 (https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=11300000006)

#### 신고 면제 기준 (공정거래위원회 고시)
- **직전 연도 통신판매 거래횟수 50회 미만**
- **부가가치세법상 간이과세자** (연매출 약 1,012만원 미만)
- 위 둘 중 하나에 해당하면 면제

### 6.3 통신판매업자 표시·광고 의무 (제13조)
- 청약 권유 표시·광고 시 다음 표기 필수
  1. 상호 및 대표자 성명
  2. 주소
  3. 전화번호 + 전자우편 주소
  4. **통신판매업 신고번호** + 신고기관
  5. 사이버몰 주소

### 6.4 통신판매중개자 책임 (제20조, 제20조의2)
- **통신판매중개**: 자기 명의로 거래 당사자 간 통신판매를 알선
- 통신판매중개자(예: 플랫폼 운영자)도 일정 정보 제공 의무, 분쟁 조정 책임
- **자신이 통신판매업자가 아니라는 사실을 명확히 고지** 시 일부 책임 면제 (제20조의2 단서)

### 6.5 청약철회 권리 (제17조)
- 7일 이내 청약철회 가능 (단, 디지털 콘텐츠 등 예외)
- **여행 상품의 경우** 관광진흥법/약관규제법 별도 적용 — 출발일 기준 위약금 규정

### 6.6 표시·광고의 공정화에 관한 법률 (표시광고법)
- 1차 출처: https://www.ftc.go.kr/www/contents.do?key=153
- **부당한 표시·광고 금지** (제3조)
  1. 거짓·과장 광고
  2. 기만적 광고
  3. 부당하게 비교하는 광고
  4. 비방하는 광고
- **중요정보 표시 의무** — 가격, 거래 조건, 환불, 위약금 등
- **인플루언서·체험단 표시** — 경제적 이해관계 명시 필수 (공정위 가이드)

### 6.7 약관의 규제에 관한 법률 (약관규제법)
- 사업자 일방적 면책, 부당한 위약금 등 무효 조항 규제
- **약관 사전 신고** (전자상거래법 + 공정위 표준약관 권장)
- **이용약관, 개인정보 처리방침** 모두 약관규제법 적용

---

## 7. 외국환거래법 / 외화 결제 발생 시

### 7.1 외국환거래법 적용 시나리오
- 외국인 관광객이 외화로 결제 → 결제대행(PG) 통해 처리하면 외국환업무 위탁 신고는 불요
- **자체 외화 결제 처리** 시 외국환업무 등록 또는 위탁 신고 필요 (한국은행/금융감독원)

### 7.2 출품작에서의 일반적 처리
- 일반적으로 **국내 PG사 (토스페이먼츠, 카카오페이, 네이버페이 등)** 또는 글로벌 PG (Stripe, PayPal) 위탁 사용
- 위탁 사용 시 **사업자 본인의 외환 신고 의무는 면제** (PG가 처리)
- 단, **수출입 신고 대상 (관광상품권 등 유가증권 발행 시)** 별도 검토

## 8. 외국인 관광객 관련 — 택스리펀드 / K-ETA / 비자

### 8.1 택스리펀드 (사후면세제도)
- **부가가치세법 제24조** + **외국인관광객 등에 대한 부가가치세 및 개별소비세 특례규정**
- 1차 출처: http://tourinfo.or.kr/v2/info/tax_02.asp
- 운영 기관: 국세청, 관세청, 환급 사업자 (글로벌블루, 글로벌택스프리, KICC 이지택스리펀드 등)

#### 환급 대상
- 국내 소득 0원
- 최소 구매금액 **3만원** (한 가맹점 1일 1회 기준)
- 국내 체류기간 **3개월 미만**
- 출국 시 휴대 반출
- **3개월 이내 출국**

#### 환급 절차
1. 가맹점에서 구매 → 택스리펀 전표 발급
2. 출국 시 공항·항만 세관에 여권+전표+영수증 제시 → 반출 확인
3. 환급 창구에서 현금/카드 환급
4. **수하물 위탁 전 세관 확인 필수** (위탁 후 검사 불가)

#### 출품작 활용 시
- 택스리펀드 가맹점 정보 + 환급 절차 안내는 일반 정보 제공 차원에서 가능
- **사후면세 특례 혜택을 직접 처리하는 시스템 연동**은 환급 사업자(글로벌블루 등)와 별도 계약 필요

### 8.2 K-ETA (Korea Electronic Travel Authorization)
- **출입국관리법 제7조의2** + 시행령
- 운영: 법무부 (출입국·외국인정책본부)
- 비자면제 협정국 국민이 한국 무사증 입국 전 사전 신청 (24시간 내 승인)
- **유효기간 3년**
- 공식 사이트: https://www.k-eta.go.kr

### 8.3 비자 (사증) 정보
- 운영: 법무부, 외교부
- 비자 종류 매우 다양 (B-1, B-2, C-3, D, E, F, H 등)
- **비자 신청 대행은 행정사/변호사 자격** 필요 (행정사법)
- 출품작에서는 **단순 정보 제공 (비자 종류, 발급 요건 안내)**까지만 가능

### 8.4 출입국 정보 제공 시 주의
- 비자/체류 자격 정보는 **법무부 공식 정보** 출처 명시 필수
- 잘못된 정보로 인한 입국 거부/추방 발생 시 책임 회피 위해 면책 조항 명시
- **외국인등록증, 여권 정보 등 민감 정보 처리 시** 개인정보보호법 + 출입국관리법 양쪽 적용

## 9. 관광사업체 등록증과 KTO API 활용
- **TourAPI 자체는 관광사업체 등록증 없이도 누구나 활용 가능** (공공데이터 자유이용)
- 단, **API 데이터를 활용해 직접 여행업/숙박업/통신판매업 등을 영위**하는 경우 → 해당 사업법 등록 의무
- 공모전 출품작이 단순 정보 제공/추천 서비스라면 별도 사업자 등록 불요
- **상용화 단계에서 결제·예약·중개 기능 추가 시** 통신판매업 신고, 여행업 등록 등 단계별 검토 필요
