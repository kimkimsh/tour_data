## 핵심 확인 사항

한국관광공사 데이터는 공공데이터포털과 TourAPI 생태계가 중심이다. 공공데이터포털의 한국관광공사 기관별 목록은 조사 시점에 전체 101건, 파일데이터 73건, 오픈 API 28건으로 표시된다. 따라서 개발 자료 정리는 TourAPI 단일 API만이 아니라 파일데이터, 표준데이터, 데이터랩 지표 API, 문화·지역 데이터까지 같이 봐야 한다.

국문 관광정보 서비스는 국내 관광 POI, 축제, 숙박, 음식, 이미지, 상세정보, 동기화, 반려동물 정보를 포함하는 핵심 API다. 공공데이터포털 상세 페이지 기준 JSON/XML REST 형식, 무료, 실시간 갱신, 개발계정 1,000건, 운영계정은 활용사례 등록 후 트래픽 증가 신청 가능, 개발단계 자동승인/운영단계 심의승인 구조다.

2025년 5월 공지 기준 국문·다국어·무장애 API는 `KorService2`, `EngService2`, `JpnService2`, `ChsService2`, `ChtService2`, `FreService2`, `GerService2`, `SpnService2`, `RusService2`, `KorWithService2`로 서비스 URL이 변경되었다. 기존 서비스 URL은 90일 유지 후 중지되는 정책이 공지되어 있어, 개발 문서와 코드 예제는 최신 서비스 ID를 기준으로 작성해야 한다.

한국관광 데이터랩은 이동통신, 신용카드, 내비게이션, 관광통계, 실태조사, 산업·테마 분석을 제공하는 분석 포털이다. 웹·앱 서비스에서 직접 사용자 화면에 노출할 정적 관광 POI는 TourAPI가 중심이고, 지역 수요/방문/소비/검색량 기반 지표는 데이터랩과 데이터랩 기반 API가 보조한다.

사진과 이미지는 별도 주의가 필요하다. TourAPI 및 사진 API는 이미지 저작권 유형 필드(`cpyrhtDivCd`)를 제공하며, 공공데이터포털 상세 설명에는 공공누리 1유형/3유형 이미지와 피사체 권리·기업 CI/BI 이용 제한이 언급된다. 서비스에서 이미지를 저장·가공·상업 활용할 경우 데이터별 라이선스와 이미지별 유형을 반드시 분기해야 한다.

지도·경로·주소·날씨·휴일 데이터는 관광 데이터 자체는 아니지만 웹·앱 구현에 필요한 보조 데이터다. 카카오 지도/로컬, 네이버 Maps, VWorld, 도로명주소 개발자센터, 기상청 단기예보, 한국천문연구원 특일 정보, 국토교통부 TAGO 계열 API를 별도 검토해야 한다.

## 조사 한계

공공데이터포털과 TourAPI Hub는 일부 화면이 JavaScript 기반이므로, 모든 상세 명세를 웹 렌더링만으로 일괄 수집하기 어렵다. 이 문서는 공식 상세 페이지와 공지, 검색 결과, 로컬 매뉴얼을 교차 대조했다. 최종 개발 전에는 각 API의 공공데이터포털 Swagger/활용 명세에서 요청 파라미터와 응답 필드를 다시 확인해야 한다.
