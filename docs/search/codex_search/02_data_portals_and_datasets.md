## 1. 한국관광 데이터랩

URL: https://datalab.visitkorea.or.kr/

한국관광 데이터랩은 관광 빅데이터 분석 포털이다. 메인 메뉴에서 확인되는 분석 범위는 다음과 같다.

| 메뉴 | 세부 내용 |
| --- | --- |
| 지역별 분석 | 전국 현황, 인기관광지, 지역별 관광 현황, 외래객 지역별 방한현황, 중심-연관 관광지 지도, 방문자 기준 지역방문현황, 성/연령별 방문·소비 현황 |
| 인구감소지역 현황 | 인구감소지역 지도, 관광/비관광 소비, 관광대체 효과, 프로파일링 |
| 관광수요 지수 | 관광수요 지수, 지역별 수요/다양성/자원 관련 지표 |
| 관광지별 현황 | 관광지별 분석, 성/연령 방문 집중률 |
| 국가별 분석 | 방한여행 현황, 빅데이터 기반 국가별 방한현황, 항공 운항, 무슬림 방한현황, 국가별 정보 |
| 관광산업 분석 | 관광사업체 인허가, 숙박업종별 현황, 관광숙박업, 관광 VOC |
| 테마별 분석 | 문화관광축제, 행사/축제 DIY 맞춤 분석, 의료관광, MICE, 야간관광, 한류관광, 캠핑관광, 걷기여행, 해양관광 |

| 관광통계/실태조사 | 방한 외래관광객, 국민 해외관광객, 관광수지, 세계관광통계, 크루즈통계, 국민여행조사, 외래관광객조사, 잠재 방한여행객 조사 |
| 데이터랩 소개 | 서비스 활용 가이드, 활용안내, FAQ, 데이터 설명, 공지사항, 우수 활용사례 |

개발 관점에서 데이터랩은 다음 자료를 제공한다.

| 자료 유형 | 활용 위치 | 주의점 |
| --- | --- | --- |
| 이동통신 방문자수 | 지역/관광지 방문 추이, 혼잡도 추정 | 방문자는 관광객과 동일 개념이 아니며 집계 기준 확인 필요 |

| 내비게이션 검색량 | 목적지 관심도, 계절성 | 검색량은 실제 방문과 다름 |

| 관광통계/실태조사 | 시장 규모, 추세 분석 | 통계 공표 시점과 API 실시간 데이터 시점이 다름 |
| VOC/1330 자료 | 불편 신고, 상담 트렌드 | 개인정보와 원문 공개 여부 확인 필요 |

## 4. 문화공공데이터광장

URL: https://www.culture.go.kr/data/

문화공공데이터광장은 문화체육관광부 소속기관, 지자체, 타 부처 기관의 문화정보를 모아 제공하는 플랫폼이다. 데이터 소개 페이지는 문화공공데이터를 유산, 예술, 체육, 관광, 한글, 문화재 등 다양한 문화 분야 공공데이터로 정의한다.

오픈API 목록 페이지 기준 총 447건의 결과가 표시된다. 맞춤형 API는 38건이 표시되며, 관광 서비스 개발에 참고할 수 있는 데이터가 포함된다.

| API/자료 | 확인 내용 |
| --- | --- |
| 오픈API 일반 | REST, JSON/XML 형태 다수 |
| 오픈API 이용방법 | 오픈API 선택, 활용신청, 키 발급, URL+키 호출 |
| 맞춤형 API | 여러 기관 데이터를 특정 주제로 표준화해 제공 |
| 전국 다국어 가이드 제공 문화시설 | 영어, 중국어 등 다국어 가이드 제공 문화시설 데이터 |
| 전시정보(통합) | 여러 문화기관의 전시 정보를 공통 항목으로 표준화 |
| 전국 시티투어 코스와 함께하는 맛집 정보 | 전국시티투어정보표준데이터와 음식점 데이터를 결합한 맞춤형 API |

문화공공데이터광장은 TourAPI의 관광 POI를 직접 대체하기보다는 공연·전시·문화시설·문화행사·문화재 데이터를 결합할 때 필요한 보조 데이터원이다.

## 5. 문화빅데이터 플랫폼

URL: https://www.bigdata-culture.kr/

문화빅데이터 플랫폼은 한국문화정보원이 운영하는 문화·체육·관광 분야 데이터 유통/분석 플랫폼이다. 한국문화정보원 사업 안내 페이지는 문화빅데이터 플랫폼이 공공기관과 민간기업 협업으로 데이터를 생산·수집·가공·유통해 데이터 활용 생태계 조성에 기여한다고 설명한다.

플랫폼 메인과 사업 안내에서 확인되는 관련 분야:

| 분야 | 데이터 예 |
| --- | --- |
| 관광 | 관광지, 축제, 공연 등 문화 행사 정보, 지역별 관광명소, 지역 문화재, 관광 연관시설 |
| 음식 | 국내 식당 및 메뉴, 카페·디저트, 무슬림 친화식당 |
| 숙박 | 숙박·레저시설, 호텔 및 주변 편의시설 |
| 소셜 | 여행·축제·스포츠 트렌드, 문화관광시설 검색량, 후기 감성/연관어 |
| 한류 | 방한객 문화향유 행태, 해외 한류 키워드 분석 |
| 미디어 | 여행·축제·맛집 관련 방송/광고/시청률 데이터 |

개발 관점에서 문화빅데이터는 직접 API형 실시간 POI 검색보다는 리포트, 데이터 상품, 분석/시각화, 맞춤형 데이터 신청에 가까운 자료원이다. 데이터 라이선스와 유료/무료 여부가 상품별로 다를 수 있으므로 서비스에 편입하기 전 개별 상품 조건 확인이 필요하다.
