## 2. 2025 관광데이터 활용 공모전

확인 출처:

- 공공데이터포털 공지: https://www.data.go.kr/bbs/ntc/selectNotice.do?originId=NOTICE_0000000004014
- 2025 공모전 TourAPI 안내 페이지: https://www.2025tourapi.com/sub/sub01.html

공공데이터포털 공지는 2025 공모전의 공모부문을 한국관광공사 TourAPI 필수, 카카오 OpenAPI 및 각종 공공데이터 API를 활용한 웹·앱 등 신규·융복합 관광서비스로 안내한다.

2025 공모전 안내 페이지에서 확인된 개발 조건:

| 항목 | 내용 |
| --- | --- |
| 필수 API | 한국관광공사 TourAPI |
| 선택 API | 카카오 Open API, 각종 공공데이터 API |
| 키 발급 | 공공데이터포털 회원가입 후 한국관광공사 API 활용신청 |
| 상용 런칭 조건 | 1차 심사 전까지 최소 1가지 이상 공개 형태 필요 |
| 모바일 앱 인정 방식 | Google Play, Apple App Store, One Store 중 최소 1곳 등록 |
| 웹서비스 인정 방식 | 모바일 접속 가능한 공개 웹사이트 |
| SW/모듈 인정 방식 | 설명자료 또는 구동 시안 |
| TourAPI 문의 | `tourapi@knto.or.kr`, 033-738-3874 |

## 3. 2023 관광데이터 활용 공모전

확인 출처: 국민일보 기사  
URL: https://www.kmib.co.kr/article/view.asp?arcid=0018146777

기사에서 확인된 내용:

| 항목 | 내용 |
| --- | --- |
| 공동 개최 | 한국관광공사, 카카오 |
| 공모 목적 | 관광지 기본정보, 이미지, 영상, POI 등 관광데이터를 활용한 신규 관광서비스 발굴 |
| 가점 방향 | TourAPI 외 공공데이터포털의 다른 기관 API 공동 활용 시 가점 |
| 이전 선정 사례 | 부산 관광지 순위 제공 앱 `슈잉`, 여행 짐 배송 서비스 기반 주변관광정보 제공 웹페이지 `짐캐리` |
| 축적 성과 | 공모전 10년간 250개 팀 선발·지원 언급 |

조사상 의미:

TourAPI 단독 호출보다 다른 공공데이터와 매시업하는 서비스가 반복적으로 강조된다. 개발 문서에는 TourAPI 핵심 데이터와 지도·교통·날씨·휴일·문화데이터 보조 API를 같이 정리해야 한다.

## 4. 2019 스마트관광 앱 개발 공모전

확인 출처: 스타뉴스 기사  
URL: https://www.starnewskorea.com/business-life/2019/10/31/2019103109311539131

기사에서 확인된 내용:

| 항목 | 내용 |
| --- | --- |
| 공동 개최 | 한국관광공사, SK텔레콤 |
| 활용 API | TourAPI, Tmap API |
| 참가 규모 | 150개 팀 |
| 시상 규모 | 대상 1, 최우수상 1, 우수상 3 포함 총 25개 팀 |
| 대상 | 로컬 경험 공유 SNS 플랫폼 `찜` |
| 최우수상 | 이미지 검색 기반 온라인 쇼핑관광 연계 `포토샌드` |
| 우수상 예 | 외래관광객과 의료기관 연결 `코닥` |
| 공개 형태 | 웹 또는 Google Play/App Store에서 무료 이용 가능하다고 보도 |

조사상 의미:

TourAPI 활용 서비스는 위치/경로 API, 쇼핑, 의료관광, 지역 경험, 이미지 검색 등 다른 산업 데이터와 결합된 사례가 많다. 이 문서는 아이디에이션을 제외하지만, 실제 사례 분석은 데이터 결합 범위 파악에 필요하다.

## 5. 공공데이터포털 활용사례

공공데이터포털 활용사례 검색에서 확인된 사례:

| 사례 | 활용 데이터 | 서비스 형태 | 조사 내용 |
| --- | --- | --- | --- |
| creatrip 여행플랫폼 | 한국관광공사_영문 관광정보서비스_GW | 웹사이트 | 예약 가능 스팟 외 관광지/음식점 등 공공 관광정보를 지도에 제공 |
| 무장애 여행 관련 제주 서비스 사례 | 한국관광공사_무장애 여행 정보 | 웹/앱 사례 페이지 | 제주 여행지 및 유모차 대여 정보와 무장애 관광정보 API 활용 사례로 검색됨 |
| 국문 관광정보 활용 사례 | 한국관광공사_국문 관광정보 서비스_GW | 웹/앱 사례 페이지 | 관광지·음식점·숙박·축제 등 국문 POI 데이터 활용 |

활용사례 게시판은 로그인 여부와 검색 조건에 따라 표시가 달라질 수 있으므로, 최종 사례 수집 시에는 공공데이터포털 `데이터활용 > 공공데이터 활용사례`에서 데이터명으로 재검색해야 한다.
