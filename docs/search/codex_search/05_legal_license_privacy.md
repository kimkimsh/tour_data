# 라이선스·저작권·개인정보·크롤링 조사

조사 기준일: 2026-05-03  
주의: 이 문서는 개발 조사 자료이며 법률 자문이 아니다. 실제 서비스 출시 전 최신 법령, 약관, 공공데이터 제공 조건을 법무 검토해야 한다.

## 1. 공공데이터 이용허락

한국관광공사 TourAPI 상세 페이지 다수는 이용허락범위를 "제한 없음"으로 표시한다. 예를 들어 국문 관광정보 서비스, 관광빅데이터 정보서비스, 관광지 집중률 예측 정보, 관광공모전 사진 수상작 정보 페이지에서 무료, REST, JSON/XML, 이용허락범위 제한 없음 또는 공공누리 유형을 확인할 수 있다.

하지만 데이터별로 이미지, 제3자 권리, 저작권 표시 조건이 다를 수 있다. 서비스 내부에는 데이터 단위 또는 이미지 단위로 라이선스 코드를 저장해야 한다.

## 2. 공공누리 유형

공공누리 공식 안내 기준:

| 유형 | 조건 | 개발상 의미 |
| --- | --- | --- |
| 제1유형 | 출처표시 | 상업/비상업 이용과 2차적 저작물 작성 가능 |
| 제2유형 | 출처표시 + 상업적 이용 금지 | 유료 서비스/광고 모델과 충돌 가능 |
| 제3유형 | 출처표시 + 변경금지 | 이미지 크롭, 필터, 합성, 변형, 일부 AI 가공 등 금지 가능 |
| 제4유형 | 출처표시 + 상업적 이용 금지 + 변경금지 | 상업 서비스 사용에 부적합할 수 있음 |

TourAPI 이미지 응답의 `cpyrhtDivCd`는 공공누리 유형 판단에 직접 사용된다. `Type1`과 `Type3`이 대표적으로 확인되며, Type3 이미지는 변경금지 조건을 우선 적용해야 한다.

## 3. 사진·이미지 제한

공공데이터포털 국문 관광정보 서비스 설명에는 사진 자료에 대해 다음 제한 취지의 안내가 있다.

| 제한 영역 | 개발 반영 |
| --- | --- |
| 피사체 명예훼손·인격권 침해 등 일반 정서에 반하는 용도 금지 | 민감/비방/혐오/성적 맥락의 자동 배치 방지 |
| 기업 CI/BI 이용 금지 | 앱 로고, 브랜드 배너, 광고 소재로 이미지 사용 금지 |
| 공공누리 1유형/3유형 이미지 혼재 | 이미지별 `cpyrhtDivCd` 저장 및 표시 |
| 원천 URL 기반 이미지 제공 | 핫링크 허용 여부와 캐싱 정책을 개별 확인 |

이미지 처리 체크리스트:

| 항목 | 확인 |
| --- | --- |
| 출처 표시 위치 | 상세 화면, 이미지 모달, 하단 고지 등 |
| 원저작자/촬영자 | 관광사진 API는 촬영자, 촬영일, 촬영지 필드 확인 |
| 이미지 변형 여부 | 썸네일 리사이즈, 크롭, 워터마크, 필터가 Type3와 충돌하지 않는지 확인 |
| CDN 저장 | 공공누리와 원천 제공조건이 저장/재배포를 허용하는지 확인 |
| 광고 소재 사용 | CI/BI 및 홍보물 사용 제한 확인 |

## 4. 출처 표시

권장 출처 표시 데이터:

| 항목 | 예 |
| --- | --- |
| 제공기관 | 한국관광공사 |
| 데이터명 | 한국관광공사_국문 관광정보 서비스_GW |
| 원천 URL | 공공데이터포털 상세 URL 또는 TourAPI 서비스 URL |
| 저작권 유형 | 공공누리 제1유형/제3유형 또는 이용허락범위 제한 없음 |
| 수정/수집 시점 | 원천 `modifiedtime`, 내부 수집 시각 |

화면 예시는 법무/디자인 검토가 필요하지만, 최소한 상세 화면 또는 서비스 약관/오픈소스·데이터 고지 페이지에 원천 데이터명을 노출하는 구조가 필요하다.

## 6. 위치정보

관광 앱은 지도와 현재 위치 기능을 자연스럽게 요구하지만, 개인 위치를 수집·이용·제공하면 위치정보 관련 규제가 적용될 수 있다. 위치정보의 보호 및 이용 등에 관한 법률과 방송통신위원회/개인정보보호위원회 안내를 최신 기준으로 확인해야 한다.

위치정보 개발 체크리스트:

| 항목 | 확인 |
| --- | --- |
| 단말 위치 권한 | OS 권한 문구와 서비스 내 고지 일치 |
| 개인위치정보 수집 여부 | 서버 저장 여부, 실시간 처리 후 폐기 여부 |
| 위치기반서비스 사업 신고/등록 | 사업 모델별 적용 여부 확인 |
| 14세 미만 이용자 | 법정대리인 동의 등 별도 기준 확인 |
| 위치정보 보유기간 | 즉시 파기, 단기 로그, 장기 프로필 구분 |
| 제3자 제공 | 지도/경로 API에 좌표를 전달하는 경우 약관/고지 확인 |

## 7. 크롤링과 약관 준수

사용자가 "크롤링"을 요청하더라도 개발 데이터 수집은 공식 API를 우선한다. 공식 API는 데이터 제공 범위, 필드, 라이선스, 활용신청, 쿼터가 명확하다. 웹 페이지 크롤링은 메타데이터 조사와 공지 확인에 한정하는 것이 안전하다.

위험한 수집:

| 대상 | 위험 |
| --- | --- |
| VisitKorea 페이지 본문 대량 수집 | TourAPI 선별 데이터 범위를 우회할 수 있음 |
| 포토코리아 이미지 대량 다운로드 | 이미지별 공공누리/피사체 권리 확인 필요 |
| 지도 서비스 검색 결과 저장 | 공급자 약관 위반 가능성 |
| 사용자 리뷰/블로그/SNS 수집 | 개인정보, 저작권, 명예훼손, 약관 문제 |
| 비공개/로그인 영역 자동화 | 접근권한 및 서비스 약관 위반 가능성 |

허용 가능성이 높은 조사 수집:

| 대상 | 목적 |
| --- | --- |
| 공공데이터포털 API 상세 페이지 | 데이터명, 수정일, 쿼터, 라이선스 확인 |
| 공공데이터포털 공지 | API 변경/폐기/신규 오퍼레이션 확인 |
| 한국관광 데이터랩 공개 메뉴/공지 | 데이터 설명, 지표 해석, 신규 서비스 확인 |
| 공모전 안내 페이지 | 개발 조건과 필수 활용 데이터 확인 |
