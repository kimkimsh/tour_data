# 한국관광공사 Tour API 4.0 활용 가이드 및 명세

## 1. 서비스 개요
- **제공기관**: 한국관광공사 (공공데이터포털 연계)
- **데이터 내용**: 전국 관광지, 숙박, 음식점, 축제/행사, 여행 코스 등 약 26만 건 이상의 정보
- **데이터 형식**: JSON, XML
- **지원 언어**: 국문, 영문, 일문, 중문(간/번체), 독어, 불어, 서어, 노어 등
- **특징**: 위치 기반 검색, 다국어 지원, 무장애 관광 정보, 반려동물 동반 정보 포함

## 2. 주요 API 엔드포인트 (국문 서비스 기준)
**Base URL**: `http://apis.data.go.kr/B551011/KorService1/`

| 기능명 | 엔드포인트 | 설명 |
| :--- | :--- | :--- |
| **지역코드 조회** | `/areaCode1` | 시도, 시군구 지역코드 정보 조회 |
| **서비스 분류코드** | `/categoryCode1` | 대/중/소분류 코드 조회 |
| **지역기반 목록** | `/areaBasedList1` | 특정 지역의 관광정보 목록 조회 |
| **위치기반 목록** | `/locationBasedList1` | GPS 좌표 기반 주변 관광정보 거리순 조회 |
| **키워드 검색** | `/searchKeyword1` | 관광지 명칭 등 키워드로 검색 |
| **행사 정보** | `/searchFestival1` | 축제 및 행사 정보를 날짜별 조회 |
| **숙박 정보** | `/searchStay1` | 베니키아, 한옥, 굿스테이 등 숙박 정보 |
| **공통 상세정보** | `/detailCommon1` | 개요, 주소, 좌표, 홈페이지 등 기본 정보 |
| **소개 상세정보** | `/detailIntro1` | 이용시간, 휴무일, 주차시설 등 타입별 상세 정보 |
| **추가 상세정보** | `/detailInfo1` | 부가적인 반복 상세 정보 |
| **이미지 정보** | `/detailImage1` | 관광지 사진 목록 (저작권 코드 포함) |
| **반려동물 정보** | `/detailPetTour1` | 반려동물 동반 가능 여부 및 주의사항 |

## 3. 핵심 파라미터 (Request)
- `serviceKey`: 공공데이터포털 발급 인증키 (Encoding/Decoding)
- `MobileOS`: 서비스 OS (ETC, IOS, AND, WIN)
- `MobileApp`: 서비스 명칭 (App 명칭)
- `_type`: 응답 형식 (json, xml)
- `contentTypeId`: 관광 타입 구분 ID

**[관광 타입 ID (contentTypeId)]**
- 12: 관광지
- 14: 문화시설
- 15: 행사/공연/축제
- 25: 여행코스
- 28: 레포츠
- 32: 숙박
- 38: 쇼핑
- 39: 음식점

## 4. API 활용 절차
1. **공공데이터포털(data.go.kr)** 회원가입
2. 검색창에 "한국관광공사 국문 관광정보 서비스" 검색
3. 활용신청 (개발 계정 즉시 승인)
4. 마이페이지에서 인증키 확인 (Encoding/Decoding 키 환경에 맞게 사용)
5. `areaBasedList` 또는 `locationBasedList` 등 목록 API에서 `contentId` 추출
6. 추출한 `contentId`를 바탕으로 `detailCommon1`, `detailIntro1` 등 상세 API 호출

## 5. 기타 특화 API
- **Odii (오디)**: 디지털 오디오 관광 가이드 서비스 (음성, 대본, 사진 정보)
- **무장애 관광 정보**: 장애인 편의시설 정보 포함
- **고캠핑(GoCamping)**: 전국 캠핑장 정보 (위치, 시설, 예약 링크 등)
