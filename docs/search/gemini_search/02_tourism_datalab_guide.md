# 한국관광 데이터랩(DataLab) API 및 통계 데이터 명세

## 1. 플랫폼 개요
**한국관광 데이터랩(Korea Tourism Data Lab)**은 한국관광공사에서 운영하는 관광 특화 빅데이터 플랫폼입니다. 단순 관광지 정보(Tour API)를 넘어, 민간 빅데이터(통신, 신용카드, 내비게이션)와 공공 데이터를 결합한 분석/통계 데이터를 제공합니다.

## 2. 주요 제공 데이터 카테고리
1. **방문자 데이터 (이동통신 기반)**
   - 소스: KT(내국인), SKT(외국인) 데이터
   - 내용: 광역 및 기초지자체별 방문자 수, 유입지별 방문자 수, 연령/성별 방문자 분포
2. **관광소비 데이터 (신용카드 기반)**
   - 소스: BC카드, 신한카드
   - 내용: 업종별(숙박, 식음료, 쇼핑, 레저 등) 관광 소비 지출액, 소비 패턴 분석
3. **내비게이션 데이터**
   - 소스: T-map 등 내비게이션 검색 데이터
   - 내용: 목적지 검색 트렌드, 인기 관광지 순위
4. **관광통계**
   - 소스: 출입국 통계, 관광사업체 통계
   - 내용: 방한 관광객, 국민 해외여행객, 관광수지 등
5. **지역관광진단**
   - 내용: 지역별 관광 경쟁력을 평가하는 지표 (관광 다양성 지수 등)

## 3. 공공데이터포털 연계 API 명세
**Base URL**: `http://apis.data.go.kr/B551011/DataLabService/`

| 기능명 | 엔드포인트 | 주요 파라미터 / 내용 |
| :--- | :--- | :--- |
| **광역지자체 방문자 수** | `/metabolicVisitIsmList` | 시도 단위 통계 |
| **기초지자체 방문자 수** | `/locVisitIsmList` | 시군구 단위 통계 |
| **지역별 소비 지출 통계** | `/locSpendList` | 신용카드 기반 지역/업종별 지출액 |
| **관광지 검색 순위** | `/getSearchKeywordList` | 내비게이션 기반 인기 검색어 순위 |
| **방한 관광객 통계** | `/방한 관광객 통계 관련 API` | 국가별, 성별, 연령별 관광객 수 |
| **지역별 관광 다양성** | `/관광 다양성 API` | 방문객, 소비, 국제적 다양성 지수 |

## 4. 활용 시 유의사항
- **집계 기준의 차이**: 데이터랩의 방문자는 일상생활권을 벗어나 특정 장소에 머문 사람으로 정의되므로, 관광객의 정의에 따라 수치 해석에 주의가 필요.
- **용도 구분**:
  - 앱/웹 서비스 내 **단순 명소 노출, 정보 제공**: `Tour API (콘텐츠랩)` 사용
  - 앱/웹 서비스 내 **혼잡도, 소비 트렌드, 추천 알고리즘 로직 활용**: `데이터랩 API` 사용
