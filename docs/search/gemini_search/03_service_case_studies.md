# 관광데이터 활용 공모전 수상작 및 서비스 개발 사례

한국관광공사와 카카오가 공동 주최하는 '관광데이터 활용 공모전'을 통해 발굴된 주요 서비스 사례를 분석하여, 관광데이터를 어떻게 웹/앱 서비스로 구현하고 있는지 조사한 자료입니다.

## 1. 2025년 주요 수상작
### 대상: 투어딩 (Tourding)
- **플랫폼**: 모바일 앱
- **타겟**: 자전거 여행객
- **데이터 활용**: Tour API (관광지 정보) + 이동 데이터 매시업
- **주요 기능**: 자전거 여행 코스 추천, 주변 관광지 제안, 사용자 맞춤형 코스 생성 및 길 안내.

### 최우수상: 부산스럽다
- **플랫폼**: 모바일 앱
- **타겟**: 부산 방문 관광객
- **데이터 활용**: Tour API + 부산광역시 축제 정보 API + 위치 기반 실시간 혼잡도 데이터 (카카오맵 연계)
- **주요 기능**: 실시간 인구 혼잡도를 시각화하여 혼잡을 피할 수 있는 쾌적한 관광지, 맛집 추천 및 사용자 간 실시간 채팅 기능 지원.

## 2. 2023년 주요 수상작
### 대상: 비트리비 (BitReview)
- **플랫폼**: 웹 / 모바일 앱
- **데이터 활용**: Tour API 상세 정보 + AI 영상 분석 기술
- **주요 기능**: 유튜브 등 여행 관련 영상에서 AI가 장소를 자동 추출하여 해당 위치, 리뷰, 시설 정보를 연동해 보여주고 바로 여행 코스로 저장 가능.

### 최우수상: 워크 트립 (Work Trip)
- **플랫폼**: B2B 웹 플랫폼
- **타겟**: 기업 워크숍 기획자
- **주요 기능**: 사용자 취향 기반 워크숍 코스 제공, 예산 관리, 숙소 예약, 레크리에이션 연계.

### 최우수상: 그린이 (GREENEY)
- **플랫폼**: 모바일 앱
- **타겟**: 친환경/비건 여행객
- **주요 기능**: 국내 친환경 관광지, 제로웨이스트 샵, 비건 식당 등을 큐레이션 제공.

## 3. 2021년 주요 수상작
### 최우수상: 카핑 (Carping)
- **플랫폼**: 모바일 앱
- **타겟**: 차박/캠핑 여행객
- **데이터 활용**: 한국관광공사 '고캠핑(GoCamping)' API + Tour API
- **주요 기능**: 카테고리별 차박지 필터링, 위치 기반 주변 캠핑장/관광지 정보 연동.

## 4. 서비스 기획 및 개발 트렌드 분석
1. **데이터 매시업 (Mashup)**
   - 단순 KTO 관광 정보 노출을 넘어, 실시간 혼잡도(SKT/KT 데이터), 날씨, AI 분석 결과, 내비게이션(T-map/카카오내비) API를 혼합하여 고부가가치 창출.
2. **니치 마켓 (Micro-targeting) 공략**
   - 불특정 다수가 아닌 '자전거', '차박', '비건', '워크숍', '무장애' 등 뾰족한 타겟층의 페인포인트를 해결하는 형태.
3. **플랫폼 전략**
   - **모바일 앱 (React Native, Flutter)**: 현장(여행지)에서 실시간 위치(GPS) 정보와 혼잡도를 확인해야 하는 서비스 위주.
   - **웹 서비스 (React, Vue)**: 여행 전 계획을 수립하거나, PC 환경에서 다량의 정보를 탐색해야 하는 서비스 위주.
