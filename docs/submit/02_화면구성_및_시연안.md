## 1. 양식과 페이지 구성

## 2. 중심 사례

휠체어를 이용하는 여행자가 공산성 방문을 준비한다. 공산성의 ‘주의 필요’와 출입통로·관람 동선의 조건을 읽고, 원문·출처·확인일을 확인한다. 같은 조건의 국립공주박물관은 ‘방문 가능’ 대안으로 제시된다. 이 사례를 소개·지역 특화·핵심 기능에서 일관되게 사용했다.

‘정보 없음’은 시설이 없다는 뜻으로 바꾸지 않았다. 구드래조각공원은 휠체어 기준 4개 핵심 항목 중 3개 미확인으로 직접 확인했으며 보조 캡처를 보관했다. 휠체어와 청각 조건을 함께 고른 공산성도 별도 보조 화면으로 남겼다.

## 3. 캡처 원칙과 상태

- 모든 삽입 화면은 사용자가 라이트 모드로 바꾼 뒤 직접 브라우저에서 촬영했다.
- 조건·판정·원문·수치를 수정하거나 비어 있는 정보를 채워 합성하지 않았다.
- 원본 캡처에서 기능 영역을 PowerPoint의 이미지 자르기로 발췌했다. 버튼이나 문구만 떼어내지 않고 제목·입력·판정·다음 행동이 함께 보이도록 구성했다. 7쪽의 원문과 출처는 같은 출입통로 항목이다.
- 여행 기록의 메모는 ‘시연용 기록’으로 표시했고 방문 완료 체크는 해제했다.
- 현장 제보는 입력 양식과 공개 방식 안내만 촬영했다. 허구의 제보를 운영 서비스에 등록하지 않았다.
- 전체 페이지 캡처의 반복 구간은 사용하지 않았다. 각 기능 화면의 온전한 영역을 확인한 뒤 사용했다.
- 15쪽 CSV 표는 운영 서비스에서 내려받은 실제 168행 가운데 4행과 주요 5열을 발췌한 편집 가능한 표다. 내려받기 화면과 결과물을 함께 보여준다.

## 5. 핵심 기능별 네 단계

### 6~7쪽: 동행 조건에 따른 방문 판단

1. **동행 조건 선택** — 본인과 동행에게 필요한 조건을 고릅니다. 여러 개 선택할 수 있습니다.
2. **방문 전 확인사항** — 공산성은 출입통로와 관람 동선에 조건이 있어 ‘주의 필요’로 안내합니다.
3. **판정의 근거 확인** — ‘흙 구간 및 일부 구간 접근 어려움’이라는 원문과 출처·확인일을 읽습니다.
4. **같은 조건의 대안** — ‘방문 가능’으로 안내한 국립공주박물관을 함께 살펴봅니다.

### 8~9쪽: 시간에 맞춘 코스와 사전 경로 안내

1. **여행 시간 선택** — 반나절·당일·1박 2일 가운데 여행 일정에 맞는 코스를 고릅니다.
2. **체류·이동 시간 확인** — 동행 조건에 맞춘 체류 시간과 관광지별 판정, 긴 이동 구간을 확인합니다.
3. **진입 과정 미리 보기** — 공산성·부소산성의 주차장과 화장실, 진입 구간을 5단계로 살펴봅니다.
4. **한 번에 한 단계** — 현재 단계의 설명과 노면을 읽고 이전·다음 버튼으로 이동합니다.

### 10~11쪽: 백제 해설과 여행 기록

1. **해설 듣기·대본 읽기** — 한국관광공사 오디의 백제 해설을 듣거나 대본으로 읽습니다.
2. **관광지 담기** — 기록에 남길 관광지를 고르고, 방문 여부와 경로 단계를 체크합니다.
3. **메모 남기기** — 기억할 내용과 이동 관련 메모를 적습니다. 기록은 브라우저에 보관합니다.
4. **인쇄물·파일로 보관** — 인쇄 화면에서 PDF로 저장하거나 텍스트·GPX 파일로 내려받습니다.

### 12~13쪽: 현장 상황 제보

1. **관광지에서 제보 진입** — 관광지 상세의 ‘제보하기’로 해당 장소의 양식을 엽니다.
2. **상황과 목격일 입력** — 경사로 막힘·공사 등 유형과 목격 날짜를 입력합니다.
3. **설명 작성·공개 동의** — 설명을 적고, 즉시 공개된다는 안내에 동의한 뒤 등록합니다.
4. **제보의 공개·관리 원칙** — 방문자 제보는 별도 영역에 공개합니다. 판정에 넣지 않고, 신고가 들어오면 관리합니다.

### 14~15쪽: 무장애 정보 갭 리포트

1. **관광지별 현황 확인** — 한국관광공사 확인, 별도 자료 확인, 정보 없음을 나누어 봅니다.
2. **우선 확인할 항목** — 판정 기준이 되는 미확인 항목과 해당 관광지 수를 먼저 확인합니다.
3. **이용 제한 별도 확인** — 이용 불가로 확인된 항목은 미확인 정보와 나누어 살펴봅니다.
4. **CSV로 확인 목록 저장** — 관광지·항목·상태·출처·확인일을 내려받아 보완할 정보를 검토합니다.

## 6. 90초 시연안

공식 발표 시간을 가정한 자료가 아니라, 핵심 흐름을 짧게 확인시키기 위한 자체 시연안이다.

| 구간 | 조작 | 설명 |
|---|---|---|
| 0~15초 | 홈에서 휠체어 조건 선택 | “휠체어를 이용하는 사람과 공주 여행을 준비해 보겠습니다.” |
| 15~35초 | 공산성 판정 요약 | “공산성은 출입통로와 관람 동선에 조건이 있습니다. 주의할 항목을 먼저 보여줍니다.” |
| 35~55초 | 출입통로 원문·출처 | “흙 구간과 일부 구간은 접근이 어렵다는 원문을 확인할 수 있습니다. 자료가 없는 항목은 방문 전에 물어볼 내용으로 남깁니다.” |
| 55~65초 | 국립공주박물관 대안 | “같은 조건으로 확인한 국립공주박물관도 함께 살펴볼 수 있습니다.” |
| 65~90초 | 갭 리포트·CSV | “여행자가 확인해야 했던 정보는 이 목록에도 모입니다. 담당자는 관광지별 추가 확인 항목과 출처를 내려받을 수 있습니다.” |

핵심 흐름을 마친 뒤 코스·단계 안내·해설·기록을 보여준다. 코스의 소요시간은 체류·이동 예상치이며 추가 휴식은 별도다. 경로 GPX는 정밀 길찾기의 증거로 사용하지 않는다.

## 7. 제작 결과

최신 파일은 `모두의백제_기능설명서_김성현_최종_보완본.pptx`다. PPT의 본문·표는 편집 가능한 요소로 작성했고, 서비스 화면은 직접 캡처한 이미지로 삽입했다. 출처와 설명 범위는 발표자 메모에 남겼다. 제출 포털 업로드는 수행하지 않았다.
