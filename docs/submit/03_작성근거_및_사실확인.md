이 문서는 원고의 사실관계를 확인하기 위한 내부 참고자료다. 개발 과정이나 검토 기록을 PPT 본문에 옮기기 위한 자료가 아니다.

## 1. 적용한 자료와 우선순위

| [워크로그](../work_log/00_README.md) 00~18 | 구현·검토·정책 변경·검증 기록 | 후속 회차에서 바뀐 판단을 반영 |

| 제출용 PPTX와 미리보기 PDF 9장 | 모든 작성 항목, 이미지 수, 핵심 기능 수와 복제 지침 | 원본 순서를 유지한 18장으로 구성 |

공고문 두 파일은 동일한 내용이다. `format.hwp`와 ‘양식1’ HWP도 동일 파일이다. 원제안서 HWP·PDF·텍스트에는 같은 본문이 들어 있다. PPTX의 텍스트와 9장 미리보기 PDF를 함께 확인했다.

`docs/plan/_research`는 초기 조사와 폐기된 옛 명세의 검토 기록이다. 종합·수렴 문서와 주요 리뷰의 결론도 확인했지만, 원본 로그에 반복 인용된 옛 기능·숫자를 현행 구현으로 채택하지 않았다. 조사 초안의 다국어 4종, GPS 자동재생, AI 코스, 시설 인증 가산점 등은 후속 구현과 다르다.

## 2. 심사 항목과 원고의 대응

제공된 공고문 6쪽 기준이다. 별도 전달된 최신 일정·접수 안내가 있다면 실제 제출 시 그 안내를 함께 적용한다.

| 1차 심사 항목 | 배점 | 제출 원고에서 보여줄 근거 |
|---|---:|---|
| 서비스 기획력 | 30 | 공산성 사례, 동행 조건별 확인사항, 정보 없음과 이용 불가의 구분 |
| 서비스 완성도 | 30 | 5개 기능의 실제 화면 흐름, 기록 내보내기, 제보 관리, 키보드·스크린리더 관련 구현과 검증 |
| 데이터 활용 적절성 | 20 | API별 사용 화면, 판정의 원문·출처, 갭 리포트의 출처별 집계 |
| 서비스 발전성 | 20 | 운영 주체와 정보 수정 담당자 협의, 현장 확인, 충남 관광지 확장 계획 |
| 지역 특화 가점 | 해당 시 2 | 현재 서비스 범위를 충청남도 공주·부여로 명시하고 실제 지역 기능 제시 |

최종 PT 기준은 서비스 적정성 30, 완성도 30, 실용성 25, 발표 15다. 이번 자료는 우선 기능설명서 양식을 채우는 원고이며, 공식 PT 시간은 가정하지 않았다.

아래는 저장소 데이터와 구현을 대조한 값이다. 실사용자 수, 관광 만족도, 이동 시간 절감, 시설 개선 실적을 뜻하지 않는다.

| 코스 | 3개 | 반나절·당일·1박 2일 템플릿. 본문에 사용 |

| 사진 | 174개 | 관광정보 사진 91개·관광사진갤러리 83개. 방문자가 올린 사진 수가 아님 |
| 시설 연결 | 48건 | 같은 시설이 여러 관광지에 연결되므로 고유 시설 48곳이 아님 |

관광지 목록은 [관광지 설정](../../content/pois.json), 실제 수집본은 [관광지 스냅샷](../../content/generated/pois.json), 항목 정의는 [capabilities.ts](../../src/domain/capabilities.ts), 대본은 [docent.json](../../content/generated/docent.json)에 있다.

### 갭 리포트의 분모

갭 리포트는 한국관광공사 항목만 집계하며, 각 관광지에 해당하지 않는 객실 관련 2개 항목을 제외한다. 현재 적용 항목은 관광지당 21개, 전체 273칸이다.

| 집계 구분 | 현재 저장본 값 |
|---|---:|
| 한국관광공사 응답으로 상태 확인 | 46 |
| 별도 공개자료로 상태 확인 | 67 |
| 정보 없음 | 160 |
| 합계 | 273 |

‘상태 확인’에는 이용 가능뿐 아니라 일부 가능과 이용 불가도 포함된다. 67은 현재 별도 공개자료를 출처로 삼는 칸 수이며, 새로 채운 빈칸의 순증량이나 지자체의 개선 실적이 아니다. 근거는 [gap.ts](../../src/domain/gap.ts)와 [접근성 스냅샷](../../content/generated/accessibility.json)이다.

홈의 390행 집계와 갭 리포트의 273칸은 분모가 다르다. 배포 홈은 확인된 항목 165개, 로컬 저장본은 166개로 1개 차이가 있어 해당 수치를 본문에 넣지 않았다. 촬영본과 다른 숫자를 원고로 고정하지 않기 위해서다.

## 6. 완성도·접근성 근거

현재 코드에는 본문·메뉴 바로가기, 화면 전환 후 제목으로 초점 이동, 조건 변경 알림, 입력 오류 안내, 대본, 지도와 나란히 제공하는 목록이 있다. [자동 접근성 검사](../../tests/e2e/a11y.spec.ts), [초점 검사](../../tests/e2e/focus.spec.ts), [발화용 문구 회귀 검사](../../tests/e2e/spoken-names.spec.ts)도 저장되어 있다.

[워크로그 18](../work_log/18_nvda_manual_verification.md)은 Windows 11·Chrome·NVDA 환경에서 5개 경로, 46단계의 키보드 과업과 발화 로그를 확인한 기록이다. 같은 문서에는 단위 검사 269건, E2E 47건, 대비 검사 58쌍의 통과 기록이 있다.

이번 작업에서는 단위 검사 9개 파일·269개 테스트와 색상 대비 58쌍·CSS 토큰 54개 대조를 다시 실행해 통과했다. E2E 47건과 NVDA 5개 경로·46단계는 기존 작업기록의 결과이며 이번에 다시 실행하지 않았다. NVDA 기록은 silence 합성기와 발화 로그 캡처 방식으로, 실제 음성 청취나 장애 당사자 사용성 평가·공인 인증과 다르다. 그 회차의 지도 마커 검증은 완료되지 않았다.

본문과 설명에서 사용할 표현:

## 8. PPT 제작 직전 확인할 사실

1. **캡처와 본문의 조건을 맞춘다.** 공산성 비교 사례는 ‘휠체어 이용’ 단독 선택 기준이다. 조건이 바뀌면 라벨도 달라질 수 있다.
2. **날짜·변동 수치는 촬영 화면을 따른다.** 로컬 파일과 배포본의 확인 항목 수가 다르므로 총 확인 수를 임의로 맞추지 않는다.
3. **제보 화면은 사용 실적과 구분한다.** 테스트나 예시 제보를 실제 일반 여행자의 제보 실적으로 설명하지 않는다.
4. **현장자료가 필요한 구간은 범위를 유지한다.** 단계 안내가 있는 곳은 공산성·부소산성이다. 13곳 전부의 정밀 경로가 있는 것처럼 캡처 제목을 붙이지 않는다.
5. **실제로 필요한 제출 정보는 별도로 확인한다.** 개인 참가 팀명 ‘김성현’은 확인됐다. 서비스 URL·최종 팀원 정보·추가 파일 형식과 업로드 제한은 제출 포털의 해당 안내와 맞춘다.

기존 PPTX·PDF, 프로젝트 코드, 원제안서는 수정하지 않았다. 공식 PPTX를 가져와 편집한 별도 18장 기능설명서와 개선한 원고·제작 참고자료를 `docs/submit`에 작성했다.

## 9. 이번 대조에서 추가로 확인한 내용

- 구드래조각공원의 `rest_seating`은 최신 `curated-facts.json` 입력이 `unknown`, 현재 생성 스냅샷은 `supported`로 다르다. 입력 상태를 생성본에 적용하는 읽기 계산은 알려진 항목 165개를 반환한다. 다만 실제 배포 DB가 그 적용 결과라고 단정할 근거는 없어, 배포 화면 165와 로컬 생성본 166은 계속 구분했다. PPT의 대표 규모는 13곳만 사용했다.
- 갭 리포트의 CSV는 현재 미확인 160행과 확인된 이용 불가 8행, 총 168행이다. 두 상태는 CSV에서도 구분한다.
- 두 사전 경로는 각각 첫 단계에만 좌표가 있다. GPX는 저장된 좌표를 내보내는 기능이며 실제 이동 궤적·정밀 무장애 경로가 아니다.
- 연관관광지는 현재 이름 목록이다. 항목을 클릭해 상세로 탐색하는 기능으로 소개하지 않았다.
- 오디는 한국어 대본 156건 중 원음 URL이 75건이다. 영어·쉬운 대본은 현재 없다.
- 제보가 판정에 자동 반영되거나, CSV가 이미 기관의 정보 개선 실적으로 연결됐다는 표현을 사용하지 않았다.
